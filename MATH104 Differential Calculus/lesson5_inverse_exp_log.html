Core Theory (Lecture 5 Slides + Ashraful's Notes)

2.1 Composite Functions & Domain of $f \circ g$

Given two functions $f$ and $g$, the composite function $f \circ g$ is defined by: $$(f \circ g)(x) = f(g(x))$$ Domain Rule: The domain of $f \circ g$ consists of all $x$ in the domain of $g$ such that $g(x)$ is in the domain of $f$.

Ashraful's Machine Analogy: Composite function $(f \circ g)(x)$ হলো একটা দুই ধাপের মেশিনের মতো (যেমন: ধান → চাল → পলিশ করা চাল): প্রথমে $g$ কাজ করে, তারপর তার output যায় $f$-এর ভেতরে। আর Inverse function হলো উল্টো মেশিন: ধান → চাল → আবার ধান! অর্থাৎ $(f^{-1} \circ f)(x) = x$।

2.2 Inverse Functions, Cancellation Equations & HLT

Definition 0.4.1 & Cancellation Equations: $f$ and $g$ are inverses ($g = f^{-1}$) if and only if: $$f^{-1}(f(x)) = x \;\;\text{for all } x \in D_f \qquad \text{and} \qquad f(f^{-1}(x)) = x \;\;\text{for all } x \in D_{f^{-1}}$$

Key Property Mathematical Statement Exam / Graphing Takeaway
Domain & Range Swap $\text{Domain}(f^{-1}) = \text{Range}(f)$
$\text{Range}(f^{-1}) = \text{Domain}(f)$		 Always restrict the domain of $f^{-1}$ to match $\text{Range}(f)$! (See Example 4 below.)
Horizontal Line Test (Thm 0.4.4) Invertible $\iff$ every horizontal line cuts the graph at most once (one-to-one). $y = x^2$ fails HLT (not invertible on $\mathbb{R}$); $y = x^3$ passes HLT.
Mirror Reflection (Thm 0.4.5) Graphs of $f$ and $f^{-1}$ are mirror reflections about the line $y = x$. Every point $(a, b)$ on $f$ reflects to $(b, a)$ on $f^{-1}$.
4-Step Algebraic Procedure 1. Write $y = f(x)$ → 2. Solve for $x$ in terms of $y$ → 3. Write $x = f^{-1}(y)$ → 4. Swap $x \leftrightarrow y$. Check if $\pm$ appears when taking even roots — use the domain of $f$ to pick the right sign!
Ashraful's Line-Test Cheat Sheet: • Vertical line ২ জায়গায় cut করলে → function-ই না!
• Horizontal line ২ জায়গায় cut করলে → invertible (one-to-one) না! ১ জায়গায় cut করলে invertible।

2.3 Exponential & Logarithmic Functions + Laws of Logarithms

For any base $a > 0, a \ne 1$, the exponential function $f(x) = a^x$ and logarithmic function $f^{-1}(x) = \log_a x$ are exact inverses: $$y = a^x \iff x = \log_a y \qquad\qquad \text{and for base } e: \quad e^{\ln x} = x \;(x > 0), \quad \ln(e^x) = x \;(\forall x \in \mathbb{R})$$

Logarithm Law Formula Proof Idea (Ashraful's Notes)
Product Rule $\log_b(ac) = \log_b a + \log_b c$ Let $M = \log_b a \implies a = b^M$, $N = \log_b c \implies c = b^N$. Then $\log_b(ac) = \log_b(b^{M+N}) = M + N$.
Quotient Rule $\log_b\!\left(\dfrac{a}{c}\right) = \log_b a - \log_b c$ $\log_b(b^{M-N}) = M - N = \log_b a - \log_b c$.
Power Rule $\log_b(a^r) = r \log_b a$ $\log_b((b^M)^r) = \log_b(b^{rM}) = rM = r \log_b a$.
Change of Base $\log_b x = \dfrac{\ln x}{\ln b}$ Let $y = \log_b x \implies b^y = x \implies y \ln b = \ln x$.

Lecture 5 Slide • Composite Domain

Example 1: Domain of $f \circ g$ for $f(x) = \dfrac{1}{x+2}$ and $g(x) = \dfrac{4}{x-1}$

Find the exact domain of $(f \circ g)(x)$ without falling into the simplification trap.

Step 1 — Inner Domain ($D_g$): $g(x) = \dfrac{4}{x - 1}$ requires $x \ne 1$. So $x = 1$ is immediately excluded.
Step 2 — Outer Domain Restriction ($g(x) \in D_f$): $f(u) = \dfrac{1}{u + 2}$ requires $u \ne -2$, so we must exclude any $x$ where $g(x) = -2$.
Step 3 — Solve $g(x) = -2$: $\dfrac{4}{x - 1} = -2 \implies 4 = -2(x - 1) = -2x + 2 \implies 2x = -2 \implies x = -1$.
Step 4 — Final Domain: Exclude both $1$ and $-1$: $\text{Domain}(f \circ g) = \{x \mid x \ne -1,\; x \ne 1\} = \mathbb{R} - \{-1, 1\}$.
Lecture 5 • Example 4

Example 2: Inverse & Domain of $f(x) = \sqrt{3x - 2}$

Find $f^{-1}(x)$ and state its explicit domain.

Step 1 — Write $y = f(x)$ and note Range: $y = \sqrt{3x - 2}$. Since a square root is never negative, $\text{Range}(f) = [0, \infty)$.
Step 2 — Solve for $x$: Square both sides: $y^2 = 3x - 2 \implies 3x = y^2 + 2 \implies x = \dfrac{1}{3}(y^2 + 2)$.
Step 3 — Swap $x \leftrightarrow y$: $f^{-1}(x) = \dfrac{1}{3}(x^2 + 2)$.
Step 4 — Enforce Domain Restriction: Even though $\frac{1}{3}(x^2+2)$ works for all real $x$, $\text{Domain}(f^{-1}) = \text{Range}(f) = [0, \infty)$. Final answer: $f^{-1}(x) = \dfrac{1}{3}(x^2 + 2),\; x \ge 0$.
Ashraful's Notes • Real-World Exp & Log

Example 3: Satellite Power Supply & Space Shuttle Decibels

(a) A satellite needs $7\text{ W}$ to operate at full capacity; its radioisotope supply outputs $P(t) = 75e^{-t/125}$ watts after $t$ days. How long can it operate at full capacity?
(b) Using $\beta = 10\log_{10}(I/I_0)$, how many times more intense is a $150\text{ dB}$ space shuttle launch than a $110\text{ dB}$ sound?

Part (a) — Set $P = 7$: $7 = 75e^{-t/125} \implies e^{-t/125} = \dfrac{7}{75}$.
Part (a) — Take $\ln$ of both sides: $-\dfrac{t}{125} = \ln\!\left(\dfrac{7}{75}\right) \implies t = -125 \ln\!\left(\dfrac{7}{75}\right) \approx \mathbf{296.4\text{ days}}$.
Part (b) — Subtract Decibels: $\beta_1 - \beta_2 = 150 - 110 = 40\text{ dB}$. Using log subtraction: $10\log_{10}(I_1/I_0) - 10\log_{10}(I_2/I_0) = 10\log_{10}(I_1/I_2) = 40$.
Part (b) — Solve Ratio: $\log_{10}(I_1/I_2) = 4 \implies \dfrac{I_1}{I_2} = 10^4 = \mathbf{10{,}000\text{ times}}$ more intense!

1st In-course Exam 2024 • Q4 3 Marks

Question: Find a formula for $f^{-1}(x)$, and state the domain of the function $f^{-1}$, where $$f(x) = (x + 2)^4, \qquad x \ge 0$$

Hint: Since $x \ge 0$, what is the smallest possible value of $(x + 2)^4$? Plug in $x = 0$: $(0 + 2)^4 = 16$! That gives $\text{Range}(f) = \text{Domain}(f^{-1})$. Also, since $x + 2 \ge 2 > 0$, take the positive 4th root!
Full Solution:
1. Find $\text{Range}(f)$: Since $x \ge 0 \implies x + 2 \ge 2 \implies (x + 2)^4 \ge 2^4 = 16$. Thus $\text{Range}(f) = [16, \infty)$.
2. Let $y = (x + 2)^4$. Taking the 4th root (positive branch because $x + 2 \ge 2 > 0$): $$x + 2 = y^{1/4} \implies x = y^{1/4} - 2$$ 3. Swap $x \leftrightarrow y$: $$f^{-1}(x) = x^{1/4} - 2 = \sqrt[4]{x} - 2$$ 4. Domain of $f^{-1}$: Equal to $\text{Range}(f) = \mathbf{[16, \infty)}$ (or $x \ge 16$).
Year Final Exam 2024 • Q2(c) 2 + 2 = 4 Marks

Question: Find a formula for $f^{-1}(x)$:
(i) $f(x) = \sqrt{5/2 - x},\quad x \le 5/2$      (ii) $f(x) = \begin{cases} 1/x, & x < 0 \\ x^2, & x \ge 0 \end{cases}$

Part (i):
$y = \sqrt{\frac{5}{2} - x}$ has range $y \ge 0$. Squaring gives $y^2 = \frac{5}{2} - x \implies x = \frac{5}{2} - y^2$.
Swapping $x \leftrightarrow y$: $$f^{-1}(x) = \frac{5}{2} - x^2, \qquad x \ge 0$$ Part (ii) (Piecewise Inverse — Invert Each Branch Separately!):
• Branch 1 ($x < 0$): $y = 1/x$. When $x < 0$, outputs are $y < 0$. Solving gives $x = 1/y$. Swapping gives $f^{-1}(x) = 1/x$ for $x < 0$.
• Branch 2 ($x \ge 0$): $y = x^2$. When $x \ge 0$, outputs are $y \ge 0$. Solving gives $x = +\sqrt{y}$. Swapping gives $f^{-1}(x) = \sqrt{x}$ for $x \ge 0$.
Combining both non-overlapping ranges: $$f^{-1}(x) = \begin{cases} \dfrac{1}{x}, & x < 0 \\[6pt] \sqrt{x}, & x \ge 0 \end{cases}$$
1st In-course Exam 2025 • Q4 1 + 4 + 2 = 7 Marks

Question: Suppose that the speed $v$ (in ft/s) of a skydiver $t$ seconds after leaping from a plane is given by $$v(t) = 190\left(1 - e^{-0.168t}\right)$$ (a) Graph $v$ versus $t$. (b) By evaluating an appropriate limit, show that the graph has a horizontal asymptote $v = c$ for an appropriate constant $c$. (c) What is the physical significance of $c$?

(a) Graph: Starts at $(0, 0)$ since $v(0) = 190(1 - 1) = 0$, rises rapidly at first (concave down), and levels off just below $v = 190$. *(Interact with this exact curve in Tab 3 of the Sandbox!)*

(b) Horizontal Asymptote: $$\lim_{t \to \infty} v(t) = \lim_{t \to \infty} 190\left(1 - e^{-0.168t}\right) = 190\left(1 - \lim_{t \to \infty} \frac{1}{e^{0.168t}}\right) = 190(1 - 0) = 190$$ Therefore, $v = 190$ is a horizontal asymptote ($c = 190$).

(c) Physical Significance: The constant $c = 190\text{ ft/s}$ represents the skydiver's terminal velocity — the maximum constant speed the skydiver approaches as air resistance balances gravitational pull.
