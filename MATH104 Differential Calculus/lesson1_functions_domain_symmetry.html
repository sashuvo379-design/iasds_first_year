Core Theory (Slides + Handwritten Notes)

2.1 Definition of a Function & Vertical Line Test

A function $f$ is a rule that assigns to each element $x$ in a set $D$ (called the domain) exactly one element, called $f(x)$, in a set $E$ (the codomain). The set of all possible output values $f(x)$ as $x$ varies throughout the domain is called the range.

Ashraful's Class Note Shortcut: Vertical line test: যদি কোনো vertical line গ্রাফকে ২ বা ততোধিক জায়গায় cut করে, তবে সেটি function-ই না! Similarly, a curve symmetric about the $x$-axis (like $x = y^2$ or $x^2 + y^2 = r^2$) is not a function of $x$, though it is a valid equation.

2.2 Natural Domain & Finding Range (Two Methods)

When a function is given by a formula without an explicit domain, its natural domain is the largest set of real numbers $x$ for which $f(x)$ produces a real number.

Expression Type Domain Restriction Course / Exam Example
Fraction $\dfrac{p(x)}{q(x)}$ Denominator cannot be zero: $q(x) \ne 0$ $g(x) = \dfrac{3x}{x^2 - 4} \implies x \ne \pm 2$, so $D = \mathbb{R} - \{-2, 2\}$
Even Root $\sqrt[2n]{g(x)}$ Inside must be non-negative: $g(x) \ge 0$ $h(t) = \sqrt{4 - 3t} \implies 4 - 3t \ge 0 \implies D = \left(-\infty, \frac{4}{3}\right]$
Root in Denominator $\dfrac{1}{\sqrt{g(x)}}$ Strictly positive: $g(x) > 0$ $f(x) = \dfrac{1}{\sqrt{x-1}} \implies x > 1 \implies D = (1, \infty)$
Tangent $\tan x = \dfrac{\sin x}{\cos x}$ $\cos x \ne 0 \implies x \ne (2n+1)\dfrac{\pi}{2},\; n \in \mathbb{Z}$ Year Final 2024 Q2(a)(iii): $D = \mathbb{R} - \left\{ \frac{(2n+1)\pi}{2} : n \in \mathbb{Z} \right\}$
Two Ways to Find the Range: 1. Direct Bound Method: Start from a known inequality (e.g., $\sqrt{x-1} \ge 0$) and build $f(x)$ step-by-step ($2 + \sqrt{x-1} \ge 2 \implies \text{Range} = [2, \infty)$).
2. Inverse Method: Write $y = f(x)$, solve for $x$ in terms of $y$, and find the domain of that inverse expression. Watch out! Always record any hidden restriction before squaring (e.g., $y - 2 = \sqrt{x-1}$ forces $y \ge 2$ before you square both sides!).

2.3 Symmetry Tests: Even, Odd & Neither

Classification Algebraic Condition Geometric Symmetry Classic Examples
Even Function $f(-x) = f(x)$ for all $x \in D$ Symmetric about the $y$-axis (mirror reflection) $y = x^2,\; y = x^4,\; y = |x|,\; y = \cos x$
Odd Function $f(-x) = -f(x)$ for all $x \in D$ Symmetric about the origin ($180^\circ$ rotational symmetry) $y = x^3,\; y = x,\; y = \frac{1}{x},\; y = \sin x$
Neither $f(-x) \ne f(x)$ and $f(-x) \ne -f(x)$ No $y$-axis or origin symmetry $y = (x - 2)^2,\; y = x + 1,\; y = e^x$
Ashraful's Visual Check for Odd Functions: Origin সাপেক্ষে প্রতিসম মানে গ্রাফটিকে $180^\circ$ ঘুরালে একই থাকে — এক কোণায় (Quadrant I) যা আছে, উল্টো কোণায় (Quadrant III) ঠিক তার বিপরীত থাকে!
Common Exam Trap: Not every function is either even or odd — most functions are neither. Also, if a function is odd and defined at $x = 0$, it must pass through the origin $(0,0)$ because $f(0) = -f(0) \implies f(0) = 0$.

Ashraful's Class Notes

Example 1: Domain & Intercepts of $f(x) = \dfrac{x + 1}{x + 2}$

Find (a) the domain, (b) whether $(1, 2)$ lies on the graph, (c) the point on the graph where $x = 2$, and (d) the $x$- and $y$-intercepts.

Step 1 — Domain: Set the denominator $\ne 0$: $x + 2 \ne 0 \implies x \ne -2$. Thus $\text{Domain} = \mathbb{R} - \{-2\}$.
Step 2 — Point Check $(1, 2)$: Compute $f(1) = \dfrac{1+1}{1+2} = \dfrac{2}{3} \ne 2$. So No, $(1, 2)$ is not on the graph.
Step 3 — Value at $x = 2$: $f(2) = \dfrac{2+1}{2+2} = \dfrac{3}{4}$. The point on the graph is $\left(2, \dfrac{3}{4}\right)$.
Step 4 — Intercepts: For $x$-intercept set $y = 0 \implies x + 1 = 0 \implies (-1, 0)$. For $y$-intercept set $x = 0 \implies y = \dfrac{1}{2} \implies \left(0, \dfrac{1}{2}\right)$.

Example 2: Domain & Range of $f(x) = 2 + \sqrt{x - 1}$

Find both the natural domain and the range using the Inverse Method (and verify with the Direct Method).

Step 1 — Domain: Inside the square root must be $\ge 0$: $x - 1 \ge 0 \implies x \ge 1$. So $\text{Domain} = [1, \infty)$.
Step 2 — Isolate the Radical: Let $y = 2 + \sqrt{x - 1}$. Subtract 2 from both sides: $y - 2 = \sqrt{x - 1}$.
Step 3 — Capture the Hidden Restriction: Since a principal square root is always non-negative ($\sqrt{x - 1} \ge 0$), we must have $y - 2 \ge 0 \implies y \ge 2$.
Step 4 — Solve for $x$ & Conclude: Squaring gives $x = (y - 2)^2 + 1$, which is defined for all $y$, subject to our restriction $y \ge 2$. Therefore, $\text{Range} = [2, \infty)$.

Example 3: Domain & Range of $f(x) = \dfrac{x + 1}{x - 1}$

Determine the natural domain and range of the rational function $f(x) = \dfrac{x + 1}{x - 1}$.

Step 1 — Domain: Denominator $x - 1 \ne 0 \implies x \ne 1$. Thus $\text{Domain} = \mathbb{R} - \{1\} = (-\infty, 1) \cup (1, \infty)$.
Step 2 — Set $y = f(x)$ and Cross-Multiply: $y = \dfrac{x + 1}{x - 1} \implies y(x - 1) = x + 1 \implies xy - y = x + 1$.
Step 3 — Collect $x$-terms: $xy - x = y + 1 \implies x(y - 1) = y + 1 \implies x = \dfrac{y + 1}{y - 1}$.
Step 4 — Range: For $x$ to be a real number, the denominator $y - 1 \ne 0 \implies y \ne 1$. Hence $\text{Range} = \mathbb{R} - \{1\}$.

1st In-course Exam 2024 • Q3 2 + 2 = 4 Marks

Question: Suppose that the function $f$ has domain all real numbers. Determine whether each function can be classified as even or odd. Explain.
(i) $g(x) = \dfrac{f(x) + f(-x)}{2}$      (ii) $h(x) = \dfrac{f(x) - f(-x)}{2}$

Hint: Replace $x$ with $-x$ in $g(x)$ and $h(x)$ directly. Remember that $-(-x) = x$. Compare the result with the original function!
Full Solution:
(i) Substitute $-x$ into $g$: $$g(-x) = \frac{f(-x) + f(-(-x))}{2} = \frac{f(-x) + f(x)}{2} = \frac{f(x) + f(-x)}{2} = g(x)$$ Since $g(-x) = g(x)$ for all $x \in \mathbb{R}$, $g(x)$ is an EVEN function.

(ii) Substitute $-x$ into $h$: $$h(-x) = \frac{f(-x) - f(-(-x))}{2} = \frac{f(-x) - f(x)}{2} = -\frac{f(x) - f(-x)}{2} = -h(x)$$ Since $h(-x) = -h(x)$ for all $x \in \mathbb{R}$, $h(x)$ is an ODD function.
Bonus Insight: Notice $f(x) = g(x) + h(x)$, which proves every function on $\mathbb{R}$ is the sum of an even part and an odd part!
Year Final Exam 2024 • Q2(a) 4.5 Marks

Question: Find the natural domain of:
(i) $f(x) = \dfrac{1}{(x - 1)(x - 3)}$     (ii) $f(x) = \tan x$     (iii) $f(x) = \sqrt{x^2 - 5x + 6}$

Hint: For (iii), factor the quadratic $x^2 - 5x + 6 = (x - 2)(x - 3)$ and test the signs on $(-\infty, 2)$, $(2, 3)$, and $(3, \infty)$.
Full Solution:
(i) Denominator $(x - 1)(x - 3) \ne 0 \implies x \ne 1, 3$.
Domain: $\mathbb{R} - \{1, 3\} = (-\infty, 1) \cup (1, 3) \cup (3, \infty)$.

(ii) $\tan x = \dfrac{\sin x}{\cos x}$ is undefined whenever $\cos x = 0$, i.e., $x = \dfrac{(2n+1)\pi}{2}$ for $n \in \mathbb{Z}$.
Domain: $\left\{ x \in \mathbb{R} : x \ne \dfrac{(2n+1)\pi}{2},\; n \in \mathbb{Z} \right\}$.

(iii) Need $x^2 - 5x + 6 \ge 0 \implies (x - 2)(x - 3) \ge 0$.
Critical values are $x = 2$ and $x = 3$. Testing intervals shows $(x-2)(x-3) \ge 0$ when $x \le 2$ or $x \ge 3$.
Domain: $(-\infty, 2] \cup [3, \infty)$.
Year Final Exam 2024 • Q1(a) & Q2(b) 4.5 Marks

Question: (a) Write down the definition of a Function with an example. (b) State the symmetry tests and explain using examples.

Model Answer (Exam-Ready):
(a) Function: A function $f$ from a set $D$ to a set $E$ is a rule that assigns to each element $x \in D$ a unique element $f(x) \in E$. Example: $f(x) = x^2$ assigns each real number to its square (e.g., $f(3) = 9$).

(b) Symmetry Tests:
  • $y$-axis symmetry (Even): Replacing $x$ by $-x$ yields an equivalent equation ($f(-x) = f(x)$). Example: $y = x^2$ since $(-x)^2 = x^2$.
  • Origin symmetry (Odd): Replacing $x$ by $-x$ and $y$ by $-y$ yields an equivalent equation ($f(-x) = -f(x)$). Example: $y = x^3$ since $(-x)^3 = -x^3$.
  • $x$-axis symmetry (Relations only): Replacing $y$ by $-y$ yields an equivalent equation. Example: $x = y^2$ (not a function of $x$ because it fails the Vertical Line Test).
