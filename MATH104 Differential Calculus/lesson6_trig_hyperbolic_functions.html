Trigonometric, Inverse Trig, Hyperbolic & Inverse Hyperbolic Functions

Bridge circular geometry ($x^2 + y^2 = 1$) with hyperbolic geometry ($x^2 - y^2 = 1$). Rotate angles on the unit circle, see why $\sin x, \cos x, \tan x$ need restricted domains to become invertible, and watch $\frac{1}{2}e^x$ and $\frac{1}{2}e^{-x}$ combine into the hanging catenary curve $\cosh x$.

Core Theory (Lecture 6 Slides + Ashraful's Notes)

2.1 Angles, Radians & The Six Trigonometric Functions

Two distinct points $A, B$ determine a line, line segment, or ray (starting at endpoint $A$). An angle is formed by rotating a ray from its initial side to its terminal side around a vertex: counterclockwise rotation generates a positive angle, while clockwise generates a negative angle.

Ashraful's Radian Definition: ১ রেডিয়ান = বৃত্তের ব্যাসার্ধের ($r$) সমান চাপ (arc length $s = r$) কেন্দ্রে যে কোণ উৎপন্ন করে। Conversion: $\pi\text{ rad} = 180^\circ$.

For any point $P(x, y)$ at distance $r = \sqrt{x^2 + y^2} > 0$ from the origin:

$$\sin\theta = \frac{y}{r}, \quad \cos\theta = \frac{x}{r}, \quad \tan\theta = \frac{y}{x}\;(x\ne 0), \quad \csc\theta = \frac{r}{y}, \quad \sec\theta = \frac{r}{x}, \quad \cot\theta = \frac{x}{y}$$

2.2 Restricted Domains for Inverse Trigonometric Functions

Because trig functions are periodic, they fail the Horizontal Line Test on $\mathbb{R}$. We restrict each function to a specific one-to-one interval so its inverse exists:

Inverse Function Restricted Domain of Original Domain of Inverse Range of Inverse (Principal Values)
$y = \sin^{-1} x$ ($\arcsin x$) $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ $[-1, 1]$ $\left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ (Quadrants IV & I)
$y = \cos^{-1} x$ ($\arccos x$) $[0, \pi]$ $[-1, 1]$ $[0, \pi]$ (Quadrants I & II)
$y = \tan^{-1} x$ ($\arctan x$) $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ $(-\infty, \infty)$ $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ (HA at $y = \pm\frac{\pi}{2}$)

2.3 Hyperbolic & Inverse Hyperbolic Functions

While circular trig functions trace the unit circle $x^2 + y^2 = 1$, hyperbolic functions are built from $e^x$ and $e^{-x}$ and trace the unit hyperbola $x^2 - y^2 = 1$: $$\sinh x = \frac{e^x - e^{-x}}{2}, \qquad \cosh x = \frac{e^x + e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$ $$\operatorname{csch} x = \frac{1}{\sinh x}, \qquad \operatorname{sech} x = \frac{1}{\cosh x}, \qquad \coth x = \frac{\cosh x}{\sinh x}$$

The Catenary Curve (বাস্তব প্রয়োগ): $y = \cosh x$ এর গ্রাফকে Catenary বলা হয়। দুটি খুঁটির মাঝে ঝুলে থাকা বৈদ্যুতিক তার, চেইন বা সাসপেনশন ব্রিজের (ঝুলন্ত সেতু) আকৃতি নিখুঁতভাবে $\cosh x$ দিয়ে মডেল করা হয়!
Circular Trig Identity Hyperbolic Analog (Watch the Sign Flip!) Inverse Hyperbolic Logarithmic Formula
$\cos^2 x + \sin^2 x = 1$ $\cosh^2 x - \sinh^2 x = 1$ $\sinh^{-1} x = \ln\!\left(x + \sqrt{x^2 + 1}\right),\; x \in \mathbb{R}$
$1 + \tan^2 x = \sec^2 x$ $1 - \tanh^2 x = \operatorname{sech}^2 x$ $\cosh^{-1} x = \ln\!\left(x + \sqrt{x^2 - 1}\right),\; x \ge 1$
$\cot^2 x + 1 = \csc^2 x$ $\coth^2 x - 1 = \operatorname{csch}^2 x$ $\tanh^{-1} x = \dfrac{1}{2}\ln\!\left(\dfrac{1 + x}{1 - x}\right),\; |x| < 1$

Guided Worked Examples (Lecture 6 & Class Notes)

Ashraful's Class Notes

Example 1: All Six Trig Ratios from $P(8, 15)$ (or $\csc\theta = \frac{17}{15}$)

The terminal side of an angle $\theta$ in standard position passes through $P(8, 15)$ in Quadrant I. Find all six trigonometric function values.

Step 1 — Compute Radius $r$: $r = \sqrt{x^2 + y^2} = \sqrt{8^2 + 15^2} = \sqrt{64 + 225} = \sqrt{289} = 17$.
Step 2 — Primary Ratios: $\sin\theta = \dfrac{y}{r} = \dfrac{15}{17}$,   $\cos\theta = \dfrac{x}{r} = \dfrac{8}{17}$,   $\tan\theta = \dfrac{y}{x} = \dfrac{15}{8}$.
Step 3 — Reciprocal Ratios: $\csc\theta = \dfrac{17}{15}$,   $\sec\theta = \dfrac{17}{8}$,   $\cot\theta = \dfrac{8}{15}$.
Hyperbolic Identity Application

Example 2: Given $\sinh x = \dfrac{3}{4}$, Find All Other 5 Hyperbolic Functions

Use the fundamental hyperbolic identity $\cosh^2 x - \sinh^2 x = 1$ to compute $\cosh x, \tanh x, \coth x, \operatorname{sech} x,$ and $\operatorname{csch} x$.

Step 1 — Find $\cosh^2 x$: $\cosh^2 x = 1 + \sinh^2 x = 1 + \left(\dfrac{3}{4}\right)^2 = 1 + \dfrac{9}{16} = \dfrac{25}{16}$.
Step 2 — Pick the Positive Root: Because $\cosh x = \frac{e^x + e^{-x}}{2} \ge 1$ is always positive for all real $x$, $\cosh x = +\dfrac{5}{4}$.
Step 3 — Compute Remaining 4 Ratios: $\tanh x = \dfrac{3/4}{5/4} = \dfrac{3}{5}$,   $\coth x = \dfrac{5}{3}$,   $\operatorname{sech} x = \dfrac{4}{5}$,   $\operatorname{csch} x = \dfrac{4}{3}$.

Example 3: Solve $\dfrac{e^x - e^{-x}}{2} = 1$ for $x$ (Exact Value of $\sinh^{-1}(1)$)

Solve $\sinh x = 1$, i.e. $\dfrac{e^x - e^{-x}}{2} = 1$, algebraically for $x$.

Step 1 — Clear Denominator & Multiply by $e^x$: $e^x - e^{-x} = 2 \implies e^{2x} - 1 = 2e^x \implies (e^x)^2 - 2e^x - 1 = 0$.
Step 2 — Solve Quadratic in $u = e^x$: $u^2 - 2u - 1 = 0 \implies u = \dfrac{2 \pm \sqrt{4 + 4}}{2} = 1 \pm \sqrt{2}$.
Step 3 — Reject Negative Root & Take $\ln$: Since $e^x > 0$ always and $1 - \sqrt{2} < 0$, we must take $e^x = 1 + \sqrt{2}$. Thus $x = \ln(1 + \sqrt{2}) \approx 0.8814$. (This matches $\sinh^{-1}(1) = \ln(1 + \sqrt{1^2+1})$!)

Course & Slide Problem Vault (Lecture 6)

Core Proof • Frequently Tested 3 Marks

Question: Prove directly from exponential definitions that (a) $\cosh^2 x - \sinh^2 x = 1$, and (b) $1 - \tanh^2 x = \operatorname{sech}^2 x$.

Hint: Expand $(e^x + e^{-x})^2 = e^{2x} + 2 + e^{-2x}$ and $(e^x - e^{-x})^2 = e^{2x} - 2 + e^{-2x}$, then subtract! For (b), divide (a) by $\cosh^2 x$.
Full Proof:
(a) $$\cosh^2 x - \sinh^2 x = \left(\frac{e^x + e^{-x}}{2}\right)^2 - \left(\frac{e^x - e^{-x}}{2}\right)^2 = \frac{(e^{2x} + 2 + e^{-2x}) - (e^{2x} - 2 + e^{-2x})}{4} = \frac{4}{4} = 1$$ (b) Since $\cosh x \ge 1 > 0$ for all $x$, divide both sides of $\cosh^2 x - \sinh^2 x = 1$ by $\cosh^2 x$: $$\frac{\cosh^2 x}{\cosh^2 x} - \frac{\sinh^2 x}{\cosh^2 x} = \frac{1}{\cosh^2 x} \implies 1 - \tanh^2 x = \operatorname{sech}^2 x$$
Inverse Hyperbolic Derivation 4 Marks

Question: Derive the logarithmic formula $\sinh^{-1} x = \ln\!\left(x + \sqrt{x^2 + 1}\right)$ for all $x \in \mathbb{R}$.

Derivation:
Let $y = \sinh^{-1} x \iff x = \sinh y = \dfrac{e^y - e^{-y}}{2}$.
Multiply by $2e^y$: $2x e^y = e^{2y} - 1 \implies (e^y)^2 - 2x(e^y) - 1 = 0$.
Apply the quadratic formula to $e^y$: $$e^y = \frac{2x \pm \sqrt{4x^2 + 4}}{2} = x \pm \sqrt{x^2 + 1}$$ Since $\sqrt{x^2 + 1} > |x| \ge x$, the minus branch $x - \sqrt{x^2 + 1}$ is strictly negative, which is impossible because $e^y > 0$. Taking the positive branch and applying $\ln$: $$y = \sinh^{-1} x = \ln\!\left(x + \sqrt{x^2 + 1}\right)$$
Inverse Trig Principal Value Traps Quick Drill

Question: Evaluate the exact values: (a) $\sin^{-1}\!\left(\sin\dfrac{5\pi}{6}\right)$, (b) $\cos^{-1}\!\left(-\dfrac{1}{2}\right)$, and (c) $\tan\!\left(\sin^{-1}\dfrac{3}{5}\right)$.

  • (a) Trap! Do NOT cancel directly to $\frac{5\pi}{6}$ because $\frac{5\pi}{6} \notin \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$. Instead: $\sin\frac{5\pi}{6} = \frac{1}{2}$, so $\sin^{-1}\!\left(\frac{1}{2}\right) = \mathbf{\dfrac{\pi}{6}}$.
  • (b) Range of $\cos^{-1}$ is $[0, \pi]$. In Quadrant II, $\cos\frac{2\pi}{3} = -\frac{1}{2}$, so $\cos^{-1}\!\left(-\frac{1}{2}\right) = \mathbf{\dfrac{2\pi}{3}}$.
  • (c) Let $\theta = \sin^{-1}\!\left(\frac{3}{5}\right) \in (0, \frac{\pi}{2})$. In a right triangle with opposite $= 3$, hypotenuse $= 5$, adjacent $= \sqrt{25 - 9} = 4$. Thus $\tan\theta = \mathbf{\dfrac{3}{4}}$.
