Core Theory (Lecture 11 Slides + Ashraful's Notes)

2.1 Local Quadratic, Maclaurin (Def 9.7.2) & Taylor (Def 9.7.3) Polynomials

To approximate $f(x)$ near $x = x_0$, we match its value and first $n$ derivatives at $x_0$: $$p_n(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(x_0)}{2!}(x - x_0)^2 + \cdots + \frac{f^{(n)}(x_0)}{n!}(x - x_0)^n$$ Setting $x_0 = 0$ gives the $n$-th Maclaurin polynomial (Definition 9.7.2). Taking $n = 2$ gives the local quadratic approximation.

Function $f(x)$ Maclaurin Series Expansion (Memorize!) Convergence Interval
$e^x$ $1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \cdots = \displaystyle\sum_{k=0}^{\infty} \frac{x^k}{k!}$ $(-\infty, \infty)$
$\sin x$ (Odd powers) $x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \dfrac{x^7}{7!} + \cdots = \displaystyle\sum_{k=0}^{\infty} (-1)^k \frac{x^{2k+1}}{(2k+1)!}$ $(-\infty, \infty)$
$\cos x$ (Even powers) $1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \dfrac{x^6}{6!} + \cdots = \displaystyle\sum_{k=0}^{\infty} (-1)^k \frac{x^{2k}}{(2k)!}$ $(-\infty, \infty)$
$\dfrac{1}{1 - x}$ (Geometric) $1 + x + x^2 + x^3 + \cdots = \displaystyle\sum_{k=0}^{\infty} x^k$ $(-1, 1)$
$\ln(1 + x)$ $x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \dfrac{x^4}{4} + \cdots = \displaystyle\sum_{k=1}^{\infty} (-1)^{k-1}\frac{x^k}{k}$ $(-1, 1]$

2.2 Remainder Estimation & Convergence (Method 1 vs. Method 2)

If $f(x) = p_n(x) + R_n(x)$ and $|f^{(n+1)}(t)| \le M$ for all $t$ between $x_0$ and $x$, then the Lagrange Remainder Bound (Method 1) guarantees: $$|R_n(x)| \le \frac{M}{(n + 1)!}|x - x_0|^{n+1}$$

Ashraful's Shortcut — Method 1 vs. Method 2 (Alternating Series Error Bound): • Method 1 (Lagrange Bound): যেকোনো bounded-derivative function-এর জন্য খাটে। Squeeze theorem দিয়ে $0 \le |R_n(x)| \le \frac{M|x-x_0|^{n+1}}{(n+1)!} \to 0$ দেখিয়ে convergence প্রমাণ করা হয়।
• Method 2 (Alternating Series): চিহ্ন পালাবদল ($+ - + -$) হলে এবং পদগুলো কমে $0$-তে গেলে, error প্রথম বাদ পড়া পদের (first omitted term) পরমমানের চেয়ে ছোট বা সমান!

2.3 Successive Differentiation & Leibnitz's Theorem

Leibnitz's Theorem generalizes the Product Rule to the $n$-th derivative of $y = u \cdot v$: $$(uv)_n = u_n v + \binom{n}{1} u_{n-1} v_1 + \binom{n}{2} u_{n-2} v_2 + \cdots + \binom{n}{r} u_{n-r} v_r + \cdots + u v_n$$ Pro Tip: Always choose the polynomial factor (like $x$, $x^2$, or $1+x^2$) as $v$ so that $v_2$ or $v_3$ becomes $0$ and the sum terminates in 2–3 terms!

Standard Function $y$ Exact $n$-th Derivative $y_n$
$y = \ln(ax + b)$ $y_n = (-1)^{n-1}\dfrac{(n-1)!\,a^n}{(ax+b)^n}$
$y = \sin(ax + b)$  /  $\cos(ax + b)$ $y_n = a^n\sin\!\left(ax + b + \dfrac{n\pi}{2}\right)$  /  $a^n\cos\!\left(ax + b + \dfrac{n\pi}{2}\right)$
$y = e^{ax}\sin(bx + c)$ $y_n = (a^2 + b^2)^{n/2} e^{ax}\sin\!\left(bx + c + n\tan^{-1}\dfrac{b}{a}\right)$

Example 1: Local Quadratic Approximation of $\sqrt{x}$ at $x_0 = 1$

Find the local quadratic approximation of $f(x) = \sqrt{x}$ at $x_0 = 1$ and use it to approximate $\sqrt{1.1}$.

Step 1 — Derivatives at $x_0 = 1$: $f(x) = x^{1/2} \implies f(1) = 1$;   $f'(x) = \frac{1}{2}x^{-1/2} \implies f'(1) = \frac{1}{2}$;   $f''(x) = -\frac{1}{4}x^{-3/2} \implies f''(1) = -\frac{1}{4}$.
Step 2 — Plug into Quadratic Taylor Formula: $p_2(x) = f(1) + f'(1)(x-1) + \dfrac{f''(1)}{2!}(x-1)^2 = 1 + \dfrac{1}{2}(x - 1) - \dfrac{1}{8}(x - 1)^2$.
Step 3 — Approximate $\sqrt{1.1}$: Substitute $x = 1.1$ ($x - 1 = 0.1$): $p_2(1.1) = 1 + 0.5(0.1) - 0.125(0.01) = 1 + 0.05 - 0.00125 = \mathbf{1.04875}$. (Calculator exact: $1.048809$ — much tighter than linear $1.05$!)

Example 2: Prove Maclaurin Series for $\cos x$ Converges for All $x \in \mathbb{R}$

Show that $\lim_{n \to \infty} R_n(x) = 0$ for $f(x) = \cos x$ and every real number $x$.

Step 1 — Bound All Derivatives: Every derivative $f^{(n+1)}(t)$ of $\cos x$ is $\pm\sin t$ or $\pm\cos t$, so $|f^{(n+1)}(t)| \le 1$ everywhere. Take $M = 1$.
Step 2 — Apply Remainder Bound + Lower Bound: Since an absolute value is never negative, $0 \le |R_n(x)| \le \dfrac{1 \cdot |x|^{n+1}}{(n + 1)!}$.
Step 3 — Limit & Squeeze Theorem: For any fixed $x \in \mathbb{R}$, factorial $(n+1)!$ grows faster than $|x|^{n+1}$, so $\lim_{n \to \infty} \dfrac{|x|^{n+1}}{(n+1)!} = 0$. By the Squeeze Theorem, $\lim_{n \to \infty} |R_n(x)| = 0 \implies \cos x = \sum_{k=0}^\infty (-1)^k \frac{x^{2k}}{(2k)!}$ for all $x \in \mathbb{R}$. $\blacksquare$

Example 3: If $y = \ln\!\left(x + \sqrt{x^2 + 1}\right)$, Show $(x^2+1)y_{n+2} + (2n+1)xy_{n+1} + n^2 y_n = 0$

Use successive differentiation to build a second-order ODE, then apply Leibnitz's Theorem $n$ times.

Step 1 — Find $y_1$ and Clear the Square Root: $y_1 = \dfrac{1 + \frac{x}{\sqrt{x^2+1}}}{x + \sqrt{x^2+1}} = \dfrac{1}{\sqrt{x^2 + 1}} \implies (x^2 + 1)y_1^2 = 1$.
Step 2 — Differentiate Again & Divide by $2y_1$: $2(x^2 + 1)y_1 y_2 + 2x y_1^2 = 0 \implies (x^2 + 1)y_2 + x y_1 = 0$.
Step 3 — Apply Leibnitz's Theorem $n$ Times: • $[(x^2+1)y_2]_n = (x^2+1)y_{n+2} + n(2x)y_{n+1} + \frac{n(n-1)}{2}(2)y_n$.
• $[x y_1]_n = x y_{n+1} + n(1) y_n$.
Step 4 — Combine Like Derivatives: $(x^2+1)y_{n+2} + (2n + 1)x y_{n+1} + [n(n-1) + n]y_n = 0 \implies \mathbf{(x^2+1)y_{n+2} + (2n+1)xy_{n+1} + n^2 y_n = 0}$. $\blacksquare$

Question: Use the Maclaurin series for $\sin x$ to approximate $\sin 3^\circ$ to five decimal place accuracy.

Hint: Convert $3^\circ$ to radians FIRST ($x = \frac{\pi}{60} \approx 0.05236$). Five decimal place accuracy means error $\le 0.000005 = 5 \times 10^{-6}$. Test $\frac{x^{n+1}}{(n+1)!}$ for $n = 1, 2, 3$!
Full Solution:
1. Convert to radians: $3^\circ = 3 \times \dfrac{\pi}{180} = \dfrac{\pi}{60} \approx 0.0523599\text{ rad}$.
2. For $f(x) = \sin x$, all derivatives satisfy $|f^{(n+1)}(t)| \le 1$ ($M = 1$). We need $|R_n(x)| \le \dfrac{|x|^{n+1}}{(n+1)!} \le 0.000005$:
• $n = 1$: $\dfrac{(0.05236)^2}{2!} \approx 0.00137 > 0.000005$ (too big).
• $n = 2$: $\dfrac{(0.05236)^3}{3!} \approx 0.0000239 > 0.000005$ (still too big).
• $n = 3$: $\dfrac{(0.05236)^4}{4!} \approx 3.13 \times 10^{-7} < 0.000005$ ✓ (Sufficient!)
3. Evaluate $p_3(x) = x - \dfrac{x^3}{3!}$ at $x = \dfrac{\pi}{60}$: $$\sin 3^\circ \approx 0.0523599 - \frac{(0.0523599)^3}{6} = 0.0523599 - 0.0000239 = \mathbf{0.05234} \;\;(\text{to 5 dec. places})$$ *(Verify this live in Tab 2 of the Sandbox!)*
Year Final Exam 2025 • Q4(c) 3 Marks

Question: If $y = \sin ax + \cos ax$, then show that $y_n = a^n\left[1 + (-1)^n \sin 2ax\right]^{1/2}$.

Full Proof:
Apply the standard $n$-th derivative formulas: $$y_n = a^n \sin\!\left(ax + \frac{n\pi}{2}\right) + a^n \cos\!\left(ax + \frac{n\pi}{2}\right) = a^n\left[\sin\!\left(ax + \frac{n\pi}{2}\right) + \cos\!\left(ax + \frac{n\pi}{2}\right)\right]$$ Rewrite the bracket as $\left[\left(\sin\theta + \cos\theta\right)^2\right]^{1/2}$ where $\theta = ax + \frac{n\pi}{2}$: $$(\sin\theta + \cos\theta)^2 = \sin^2\theta + \cos^2\theta + 2\sin\theta\cos\theta = 1 + \sin(2\theta) = 1 + \sin(2ax + n\pi)$$ Since $\sin(2ax + n\pi) = (-1)^n \sin 2ax$ for every integer $n \ge 0$, we obtain: $$y_n = a^n\left[1 + (-1)^n \sin 2ax\right]^{1/2} \quad \blacksquare$$

(a) Find the $n$-th derivative of $y = x \ln x$ using Leibnitz's Theorem.
(b) If $y = \tan^{-1} x$, prove that $(1 + x^2)y_{n+2} + 2(n + 1)x y_{n+1} + n(n + 1)y_n = 0$.

Part (a): Let $u = \ln x$ and $v = x$ (so $v_1 = 1$, $v_2 = 0$). Recall $u_n = (-1)^{n-1}\dfrac{(n-1)!}{x^n}$:
$$(x\ln x)_n = u_n v + n u_{n-1} v_1 + 0 = (-1)^{n-1}\frac{(n-1)!}{x^n}\cdot x + n(-1)^{n-2}\frac{(n-2)!}{x^{n-1}}\cdot 1$$ Factor out $\dfrac{(-1)^{n-2}(n-2)!}{x^{n-1}}$: $$(x\ln x)_n = \frac{(-1)^{n-2}(n-2)!}{x^{n-1}}[-(n-1) + n] = \mathbf{\frac{(-1)^{n-2}(n-2)!}{x^{n-1}}} \;\;(n \ge 2)$$ Part (b): $y_1 = \dfrac{1}{1+x^2} \implies (1+x^2)y_1 = 1$. Differentiate once: $(1+x^2)y_2 + 2x y_1 = 0$.
Apply Leibnitz's Theorem $n$ times:
$[(1+x^2)y_{n+2} + 2nx y_{n+1} + n(n-1)y_n] + [2x y_{n+1} + 2n y_n] = 0$
Combine terms: $\mathbf{(1 + x^2)y_{n+2} + 2(n + 1)x y_{n+1} + n(n + 1)y_n = 0}$. $\blacksquare$
