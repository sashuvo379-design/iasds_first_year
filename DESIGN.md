# IASDS Study Archive — Design System Specification

This document defines the visual language, color tokens, typography scale, spacing grid, and component rules for the IASDS First-Year Study Archive. The aesthetic is intentionally calm, literary, and scholarly—built for multi-hour reading and problem-solving sessions without decorative clutter, neon gradients, or visual noise.

---

## 1. Color Palette & WCAG AA Contrast Audit

Both themes are designed independently (dark mode is never generated by inverting colors). Color is used with restraint: neutrals carry >90% of every page, while deep teal marks interactive links/actions, ochre marks progress and highlights, sage marks completion, and terracotta marks warning/note callouts.

## 2. Typography

- **Headings:** `Newsreader` (Google Fonts, optical size, weights 400 / 500 / 600), fallback `Source Serif 4`, `Georgia`, serif.
- **Body text:** `Source Sans 3` (weights 400 / 500 / 600 / 700), 17px on mobile and 17.5px default on desktop (`--reading-font-size`), default line-height `1.72`.
- **Code & course codes:** `JetBrains Mono` (weights 400 / 500 / 600).
- **Mathematics:** KaTeX `0.16.11` default Computer Modern math fonts (loaded only on courses containing LaTeX).

### Modular Type Scale (1.250 Major Third)

| Token | Size | Usage |
| --- | --- | --- |
| `--text-xs` | `0.8rem` (12.8px) | Metadata, badges, TOC links, table labels |
| `--text-sm` | `0.875rem` (14px) | Navigation, buttons, secondary descriptions |
| `--text-base` | `1.0625rem` (17px) | Base UI text; lesson body defaults to `1.09375rem` (17.5px) |
| `--text-md` | `1.25rem` (20px) | Course card titles, dialog headers, `h4` |
| `--text-lg` | `1.563rem` (25px) | Section headings, `h3` |
| `--text-xl` | `1.953rem` (31.25px) | `h2` lesson section headings |
| `--text-2xl` | `2.441rem` (39px) | Page `h1` (fluid `clamp(1.75rem, 3.2vw, 2.441rem)`) |

### Reading Controls
- **Font size (3 steps):** `sm` (`15.5px`), `md` (`17.5px`), `lg` (`19.5px`).
- **Line height (3 steps):** `compact` (`1.55`), `normal` (`1.72`), `relaxed` (`1.92`).
- **Measure:** Lesson prose is constrained to `~60–75ch` (`max-width: 720px` for narrative text, up to `820px` for interactive laboratory canvases and data tables).

## 3. Spacing Grid & Layout

All spacing derives from an **8px base grid**:
- `--space-1`: `4px` (half-step)
- `--space-2`: `8px`
- `--space-3`: `12px`
- `--space-4`: `16px`
- `--space-5`: `24px`
- `--space-6`: `32px`
- `--space-7`: `48px`
- `--space-8`: `64px`

### Responsive Breakpoints
- **Mobile (`375px–767px`):** Single-column flow; course navigation is a slide-in left drawer; TOC is a collapsible `<details>` block above lesson content.
- **Tablet (`768px–1023px`):** Two-column course grid on Home; slide-in drawer + collapsible TOC on lessons.
- **Small desktop (`1024px–1279px`):** Persistent collapsible left sidebar (`272px`) + centered lesson column; collapsible TOC at top of lesson.
- **Desktop (`1280px–1440px+`):** Full 3-column academic shell: left course sidebar (`272px`) + centered content column + right sticky TOC (`236px`). Focus Mode hides both sidebars.

## 4. Component Rules

- **Corners:** `4px` (`--radius-sm`) on buttons, inputs, chips, and code blocks; `6px` (`--radius-md`) on cards, callouts, and dialogs. No pill-shaped everything.
- **Elevation:** Prefer `1px solid var(--color-border)` over shadows. Shadows are reserved strictly for floating popovers and modal dialogs.
- **Buttons:** Solid deep teal (`btn--primary`) for primary actions; 1px bordered (`btn--secondary`) for secondary actions; subtle hover (`btn--ghost`) for toolbar icon buttons. Every interactive element has a visible `2px` `:focus-visible` ring.
- **Icons:** Inline Lucide line SVGs (`stroke-width: 1.9`). No emoji as UI chrome icons.
- **Progress bars:** Thin `4px` height, ochre fill (`--color-ochre`) on `--color-border` track.
- **Callouts:** `3px` solid left border in the semantic accent color with a low-opacity tinted surface—never saturated boxes.
- **Status indicators:** Never conveyed by color alone; every status badge pairs a distinct icon with explicit text (`Not started`, `In progress`, `Completed`).
- **Motion:** All transitions are `≤ 150ms ease` and automatically disabled under `@media (prefers-reduced-motion: reduce)`.
