Orthogonality, Gram-Schmidt & Orthogonal Matrices

Perpendicular unit axes turn hard matrix inversions into simple dot products and transposes. In this lesson, you will straighten skewed frames via the Gram-Schmidt process, factor matrices as $A = QR$, and master orthogonal matrices ($Q^{-1} = Q^T$)—the rigid-motion backbone of numerical linear algebra, PCA, and SVD.

Lecture Intuition: “Orthogonality is about direction; normalizing fixes the length. Gram-Schmidt straightens a skewed frame by subtracting off each previous shadow; division by the norm scales every axis to length $1$.”

ALGORITHM 2. Orthonormal Bases, Projections & Gram-Schmidt

2.1 Orthogonal vs. Orthonormal Sets

A set $\{\mathbf{q}_1, \dots, \mathbf{q}_k\}$ is orthonormal if every pair is perpendicular AND every vector has length $1$:

$$\mathbf{q}_i \cdot \mathbf{q}_j = \begin{cases} 0 & \text{if } i \neq j \\ 1 & \text{if } i = j \end{cases} \iff Q^T Q = I_k$$
  • Instant Coordinates (No Row Reduction!): If $\{\mathbf{q}_1,\dots,\mathbf{q}_n\}$ is an orthonormal basis, then $$\mathbf{v} = (\mathbf{q}_1^T\mathbf{v})\mathbf{q}_1 + (\mathbf{q}_2^T\mathbf{v})\mathbf{q}_2 + \dots + (\mathbf{q}_n^T\mathbf{v})\mathbf{q}_n.$$
  • Projection onto Subspace $W = \text{span}\{\mathbf{q}_1,\dots,\mathbf{q}_k\}$: $$\text{proj}_W(\mathbf{b}) = (\mathbf{q}_1^T\mathbf{b})\mathbf{q}_1 + \dots + (\mathbf{q}_k^T\mathbf{b})\mathbf{q}_k = QQ^T\mathbf{b}.$$

2.2 The Gram-Schmidt Process

Given any linearly independent basis $\{\mathbf{u}_1, \mathbf{u}_2, \mathbf{u}_3\}$:

$$\mathbf{v}_1 = \mathbf{u}_1$$ $$\mathbf{v}_2 = \mathbf{u}_2 - \frac{\mathbf{u}_2 \cdot \mathbf{v}_1}{\|\mathbf{v}_1\|^2}\mathbf{v}_1$$ $$\mathbf{v}_3 = \mathbf{u}_3 - \frac{\mathbf{u}_3 \cdot \mathbf{v}_1}{\|\mathbf{v}_1\|^2}\mathbf{v}_1 - \frac{\mathbf{u}_3 \cdot \mathbf{v}_2}{\|\mathbf{v}_2\|^2}\mathbf{v}_2$$ $$\text{Normalize at the end: } \mathbf{q}_i = \frac{\mathbf{v}_i}{\|\mathbf{v}_i\|}$$
Exam Speed Hack: Always check the pairwise dot products $\mathbf{u}_i \cdot \mathbf{u}_j$ first! If any pair is already $0$, that projection term vanishes immediately (just like DU 2nd Incourse 2025 Q1b!).

MATRICES 3. Orthogonal Matrices ($Q^{-1} = Q^T$) & $A = QR$

3.1 Orthogonal Matrices (Rigid Motions)

A square matrix $Q \in \mathbb{R}^{n\times n}$ is orthogonal if $Q^T Q = QQ^T = I$, i.e. $\mathbf{Q^{-1} = Q^T}$.

  • Rows & Columns: Both rows and columns form orthonormal sets (not merely orthogonal!).
  • Length & Angle Preservation: $\|Q\mathbf{x}\| = \|\mathbf{x}\|$ and $(Q\mathbf{x})\cdot(Q\mathbf{y}) = \mathbf{x}\cdot\mathbf{y}$.
  • Determinant: $\det(Q) = +1$ (rotation) or $\det(Q) = -1$ (reflection).
  • Closed under Products & Inverses: $Q_1 Q_2$, $Q^T$, and $Q^{-1}$ are all orthogonal.
Why Numerical Algorithms Love $Q$: Because $\|Q\mathbf{x} - Q\hat{\mathbf{x}}\| = \|\mathbf{x} - \hat{\mathbf{x}}\|$, orthogonal matrices never magnify roundoff error!

3.2 Gram-Schmidt in Matrix Form: $A = QR$

If $A = [\mathbf{a}_1 \cdots \mathbf{a}_n]$ has linearly independent columns and $Q = [\mathbf{q}_1 \cdots \mathbf{q}_n]$ holds their Gram-Schmidt orthonormal vectors:

$$A = QR, \qquad R = Q^T A = \begin{bmatrix} \mathbf{q}_1^T\mathbf{a}_1 & \mathbf{q}_1^T\mathbf{a}_2 & \mathbf{q}_1^T\mathbf{a}_3 \\ 0 & \mathbf{q}_2^T\mathbf{a}_2 & \mathbf{q}_2^T\mathbf{a}_3 \\ 0 & 0 & \mathbf{q}_3^T\mathbf{a}_3 \end{bmatrix}$$

$R$ is invertible and upper triangular because each $\mathbf{a}_j$ is a linear combination only of $\mathbf{q}_1, \dots, \mathbf{q}_j$ (so $\mathbf{q}_i^T \mathbf{a}_j = 0$ for $i > j$).

Interactive Exam Proof: Orthonormal Sets Are Independent & $\det(Q) = \pm 1$ Anton Thm 6.3.1 & 7.1.2 · Strang 4.4 Q10
Part A: Every orthonormal set $\{\mathbf{q}_1, \dots, \mathbf{q}_k\}$ is linearly independent
Assume $c_1\mathbf{q}_1 + c_2\mathbf{q}_2 + \dots + c_k\mathbf{q}_k = \mathbf{0}$. Take the dot product of both sides with $\mathbf{q}_i$: $$c_1(\mathbf{q}_1\cdot\mathbf{q}_i) + \dots + c_i(\mathbf{q}_i\cdot\mathbf{q}_i) + \dots + c_k(\mathbf{q}_k\cdot\mathbf{q}_i) = \mathbf{0}\cdot\mathbf{q}_i = 0 \implies c_i(1) = 0 \implies c_i = 0.$$
Part B: Orthogonal matrices preserve lengths ($\|Q\mathbf{x}\| = \|\mathbf{x}\|$)
$$\|Q\mathbf{x}\|^2 = (Q\mathbf{x})^T(Q\mathbf{x}) = \mathbf{x}^T(Q^T Q)\mathbf{x} = \mathbf{x}^T I \mathbf{x} = \mathbf{x}^T\mathbf{x} = \|\mathbf{x}\|^2 \implies \|Q\mathbf{x}\| = \|\mathbf{x}\|.$$
Part C: If $Q$ is orthogonal, then $\det(Q) = +1$ or $-1$
Since $Q^T Q = I$, taking determinants gives $\det(Q^T)\det(Q) = \det(I) = 1$. Since $\det(Q^T) = \det(Q)$, we obtain $(\det Q)^2 = 1 \implies \mathbf{\det(Q) = \pm 1}$. $\blacksquare$

Problem 1: Gram-Schmidt Speed Trap (Already Orthogonal!) 2nd Incourse 2025 Q1(b) (2 Marks)

Let $\mathbb{R}^3$ have the Euclidean inner product. Use the Gram-Schmidt process to transform the basis $\mathbf{u}_1 = (0, 2, 0)$, $\mathbf{u}_2 = (3, 0, 3)$, $\mathbf{u}_3 = (-4, 0, 4)$ into an orthonormal basis.

Hint: Compute $\mathbf{u}_1\cdot\mathbf{u}_2$, $\mathbf{u}_1\cdot\mathbf{u}_3$, and $\mathbf{u}_2\cdot\mathbf{u}_3$ first—all three dot products are $0$!
Solution:
1. Check dot products: $\mathbf{u}_1\cdot\mathbf{u}_2 = 0$, $\mathbf{u}_1\cdot\mathbf{u}_3 = 0$, $\mathbf{u}_2\cdot\mathbf{u}_3 = -12 + 0 + 12 = 0$. Thus Gram-Schmidt leaves all three vectors unchanged: $\mathbf{v}_1 = \mathbf{u}_1$, $\mathbf{v}_2 = \mathbf{u}_2$, $\mathbf{v}_3 = \mathbf{u}_3$.
2. Normalize each vector ($\|\mathbf{v}_1\| = 2$, $\|\mathbf{v}_2\| = \sqrt{18} = 3\sqrt{2}$, $\|\mathbf{v}_3\| = \sqrt{32} = 4\sqrt{2}$): $$\mathbf{q}_1 = (0, 1, 0), \qquad \mathbf{q}_2 = \left(\frac{1}{\sqrt{2}}, 0, \frac{1}{\sqrt{2}}\right), \qquad \mathbf{q}_3 = \left(-\frac{1}{\sqrt{2}}, 0, \frac{1}{\sqrt{2}}\right).$$
Problem 2: Classic $\mathbb{R}^3$ Gram-Schmidt Transformation 2nd Incourse 2020 Q3 (5 Marks) · Anton 6.3 Q29

Apply the Gram-Schmidt process to transform $\mathbf{u}_1 = (1, 1, 1)$, $\mathbf{u}_2 = (-1, 1, 0)$, $\mathbf{u}_3 = (1, 2, 1)$ into an orthonormal basis for $\mathbb{R}^3$.

Solution:
1. $\mathbf{v}_1 = \mathbf{u}_1 = (1, 1, 1)$, $\|\mathbf{v}_1\|^2 = 3$.
2. $\mathbf{u}_2 \cdot \mathbf{v}_1 = -1 + 1 + 0 = 0 \implies \mathbf{v}_2 = \mathbf{u}_2 = (-1, 1, 0)$, $\|\mathbf{v}_2\|^2 = 2$.
3. $\mathbf{u}_3 \cdot \mathbf{v}_1 = 1 + 2 + 1 = 4$, and $\mathbf{u}_3 \cdot \mathbf{v}_2 = -1 + 2 + 0 = 1$: $$\mathbf{v}_3 = (1, 2, 1) - \frac{4}{3}(1, 1, 1) - \frac{1}{2}(-1, 1, 0) = \left(\frac{1}{6}, \frac{1}{6}, -\frac{1}{3}\right) \propto (1, 1, -2).$$ 4. Normalize ($\|\mathbf{v}_1\|=\sqrt{3}$, $\|\mathbf{v}_2\|=\sqrt{2}$, $\|(1,1,-2)\|=\sqrt{6}$): $$\mathbf{q}_1 = \left(\frac{1}{\sqrt{3}}, \frac{1}{\sqrt{3}}, \frac{1}{\sqrt{3}}\right), \quad \mathbf{q}_2 = \left(-\frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}}, 0\right), \quad \mathbf{q}_3 = \left(\frac{1}{\sqrt{6}}, \frac{1}{\sqrt{6}}, -\frac{2}{\sqrt{6}}\right).$$
Problem 3: Full Gram-Schmidt with Scaling Trick Final 2024 (6 Marks)

Transform $\mathbf{u}_1 = (1, 2, 3)$, $\mathbf{u}_2 = (3, 7, 10)$, $\mathbf{u}_3 = (0, 1, 0)$ into an orthonormal basis for $\mathbb{R}^3$.

Hint: After computing $\mathbf{v}_2 = (-\frac{5}{14}, \frac{4}{14}, -\frac{1}{14})$, multiply it by $14$ to clear fractions before Step 3—scaling an orthogonal vector does not change its direction or orthogonality!
Solution:
1. $\mathbf{v}_1 = (1, 2, 3)$, $\|\mathbf{v}_1\|^2 = 14$.
2. $\mathbf{u}_2 \cdot \mathbf{v}_1 = 3 + 14 + 30 = 47$: $$\mathbf{v}_2 = (3, 7, 10) - \frac{47}{14}(1, 2, 3) = \frac{1}{14}(-5, 4, -1).$$ Clear denominator: use $\tilde{\mathbf{v}}_2 = (-5, 4, -1)$, $\|\tilde{\mathbf{v}}_2\|^2 = 25 + 16 + 1 = 42$.
3. $\mathbf{u}_3 \cdot \mathbf{v}_1 = 2$ and $\mathbf{u}_3 \cdot \tilde{\mathbf{v}}_2 = 4$: $$\mathbf{v}_3 = (0, 1, 0) - \frac{2}{14}(1, 2, 3) - \frac{4}{42}(-5, 4, -1) = \left(\frac{1}{3}, \frac{1}{3}, -\frac{1}{3}\right) \propto (1, 1, -1).$$ 4. Orthonormal basis: $$\mathbf{q}_1 = \frac{1}{\sqrt{14}}(1, 2, 3), \qquad \mathbf{q}_2 = \frac{1}{\sqrt{42}}(-5, 4, -1), \qquad \mathbf{q}_3 = \frac{1}{\sqrt{3}}(1, 1, -1).$$
Problem 4: Proving a Householder Matrix $H = I_n - \frac{2}{\mathbf{x}^T\mathbf{x}}\mathbf{x}\mathbf{x}^T$ Is Orthogonal & Symmetric Anton 7.1 Q25 · Strang 4.4 Eq. (2)

Prove that for any nonzero column vector $\mathbf{x} \in \mathbb{R}^n$, the Householder reflection matrix $H = I_n - \dfrac{2}{\mathbf{x}^T\mathbf{x}}\mathbf{x}\mathbf{x}^T$ is both symmetric ($H^T = H$) and orthogonal ($H^T H = I_n$).

Solution:
Let $c = \mathbf{x}^T\mathbf{x} > 0$ (a scalar).
1. Symmetry: Since $(\mathbf{x}\mathbf{x}^T)^T = (\mathbf{x}^T)^T\mathbf{x}^T = \mathbf{x}\mathbf{x}^T$: $$H^T = I_n^T - \frac{2}{c}(\mathbf{x}\mathbf{x}^T)^T = I_n - \frac{2}{c}\mathbf{x}\mathbf{x}^T = H. \quad \checkmark$$ 2. Orthogonality: Using $H^T = H$ and $(\mathbf{x}\mathbf{x}^T)(\mathbf{x}\mathbf{x}^T) = \mathbf{x}(\mathbf{x}^T\mathbf{x})\mathbf{x}^T = c\,\mathbf{x}\mathbf{x}^T$: $$H^T H = H^2 = \left(I_n - \frac{2}{c}\mathbf{x}\mathbf{x}^T\right)^2 = I_n - \frac{4}{c}\mathbf{x}\mathbf{x}^T + \frac{4}{c^2}(c\,\mathbf{x}\mathbf{x}^T) = I_n. \quad \blacksquare$$
