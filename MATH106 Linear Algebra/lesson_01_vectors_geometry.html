THEORY 2. Core Definitions & Fundamental Theorems

2.1 Vectors & Linear Combinations in $\mathbb{R}^n$

A vector in $\mathbb{R}^n$ is an ordered $n$-tuple of real numbers, written as a column or row:

$$\mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix} \in \mathbb{R}^n, \qquad c\mathbf{v} + d\mathbf{w} = \begin{bmatrix} cv_1 + dw_1 \\ \vdots \\ cv_n + dw_n \end{bmatrix}$$
  • Addition: Component-wise (geometrically: tip-to-tail / parallelogram diagonal).
  • Scalar Multiplication: Scales length by $|c|$; flips direction if $c < 0$.
  • Unit Vector (Normalizing): $\hat{\mathbf{u}} = \dfrac{\mathbf{v}}{\|\mathbf{v}\|}$ has length $1$ in the direction of $\mathbf{v}$ (for $\mathbf{v} \neq \mathbf{0}$).

2.2 Norm, Dot Product, Distance & Angle

The Euclidean inner product (dot product) turns algebraic coordinates into geometry:

$$\mathbf{u}\cdot\mathbf{v} = \sum_{i=1}^n u_i v_i = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$$ $$\|\mathbf{v}\| = \sqrt{\mathbf{v}\cdot\mathbf{v}} = \sqrt{v_1^2 + \dots + v_n^2}, \quad d(\mathbf{u},\mathbf{v}) = \|\mathbf{u}-\mathbf{v}\|$$
  • $\mathbf{u}\cdot\mathbf{v} > 0 \iff \theta$ is acute ($0^\circ \le \theta < 90^\circ$).
  • $\mathbf{u}\cdot\mathbf{v} = 0 \iff \mathbf{u} \perp \mathbf{v}$ (orthogonal, $\theta = 90^\circ$).
  • $\mathbf{u}\cdot\mathbf{v} < 0 \iff \theta$ is obtuse ($90^\circ < \theta \le 180^\circ$).
  • Orthogonal Projection of $\mathbf{v}$ onto $\mathbf{u}$: $\text{proj}_{\mathbf{u}}\mathbf{v} = \dfrac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|^2}\mathbf{u}$.

2.3 Cauchy-Schwarz, Triangle Inequality & Parallelogram Law

Cauchy-Schwarz Inequality: $$|\mathbf{u}\cdot\mathbf{v}| \le \|\mathbf{u}\|\|\mathbf{v}\|$$
Guarantees $-1 \le \frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|} \le 1$ so $\cos\theta$ is well-defined in $\mathbb{R}^n$. Equality holds iff one vector is a scalar multiple of the other.
Parallelogram Equation: $$\|\mathbf{u}+\mathbf{v}\|^2 + \|\mathbf{u}-\mathbf{v}\|^2 = 2\left(\|\mathbf{u}\|^2 + \|\mathbf{v}\|^2\right)$$
The sum of squares of the two diagonals equals the sum of squares of all four sides.
Interactive Exam Proof: Triangle Inequality DU Finals 2019, 2023, 2025

Theorem: For all $\mathbf{u}, \mathbf{v} \in \mathbb{R}^n$, $\|\mathbf{u}+\mathbf{v}\| \le \|\mathbf{u}\| + \|\mathbf{v}\|$.

Step 1: Expand $\|\mathbf{u}+\mathbf{v}\|^2$ using the dot product
$$\|\mathbf{u}+\mathbf{v}\|^2 = (\mathbf{u}+\mathbf{v})\cdot(\mathbf{u}+\mathbf{v}) = \mathbf{u}\cdot\mathbf{u} + 2(\mathbf{u}\cdot\mathbf{v}) + \mathbf{v}\cdot\mathbf{v} = \|\mathbf{u}\|^2 + 2(\mathbf{u}\cdot\mathbf{v}) + \|\mathbf{v}\|^2$$
Step 2: Apply property of absolute value ($a \le |a|$)
$$\|\mathbf{u}+\mathbf{v}\|^2 \le \|\mathbf{u}\|^2 + 2|\mathbf{u}\cdot\mathbf{v}| + \|\mathbf{v}\|^2$$
Step 3: Apply the Cauchy-Schwarz Inequality ($|\mathbf{u}\cdot\mathbf{v}| \le \|\mathbf{u}\|\|\mathbf{v}\|$)
$$\|\mathbf{u}+\mathbf{v}\|^2 \le \|\mathbf{u}\|^2 + 2\|\mathbf{u}\|\|\mathbf{v}\| + \|\mathbf{v}\|^2 = \left(\|\mathbf{u}\| + \|\mathbf{v}\|\right)^2$$
Step 4: Take nonnegative square roots of both sides
$$\text{Since } \|\mathbf{u}+\mathbf{v}\| \ge 0 \text{ and } \|\mathbf{u}\|+\|\mathbf{v}\| \ge 0, \quad \|\mathbf{u}+\mathbf{v}\| \le \|\mathbf{u}\| + \|\mathbf{v}\|. \quad \blacksquare$$

3D GEOMETRY 3. Planes & Distances in $\mathbb{R}^3$

Point-Normal Form & Plane Relationships

A plane through $P_0(x_0, y_0, z_0)$ with normal vector $\mathbf{n} = (a, b, c)$ satisfies $\mathbf{n}\cdot(P - P_0) = 0$, giving:

$$ax + by + cz = d \qquad \text{with normal } \mathbf{n} = (a, b, c)$$
  • Parallel Planes: $\mathbf{n}_1 = k\mathbf{n}_2$ for some nonzero scalar $k$.
  • Perpendicular Planes: $\mathbf{n}_1 \cdot \mathbf{n}_2 = 0$.
Exam Trap Alert: Exams often scramble the plane equation (e.g., $2y = 8x - 4z + 5$). Always rewrite into $ax + by + cz = d$ before reading $\mathbf{n}$ or computing distances!

Distance Formulas

1. Point $P_0(x_0, y_0, z_0)$ to Plane $ax + by + cz = d$:

$$D = \frac{|ax_0 + by_0 + cz_0 - d|}{\sqrt{a^2 + b^2 + c^2}}$$

2. Parallel Planes $ax + by + cz = d_1$ and $ax + by + cz = d_2$:

$$D = \frac{|d_1 - d_2|}{\sqrt{a^2 + b^2 + c^2}}$$
Requirement: The coefficients $(a, b, c)$ of both planes must be scaled to match before using $|d_1 - d_2|$. Alternatively, pick any easy point on Plane 1 (like setting $y=0, z=0$) and use the Point-to-Plane formula.

Part B: Written Exam Problems (Hints & Full Solutions)

Problem 1: Finding $\lambda$ for Orthogonality Final 2022 Q2(b) · Final 2024 Q3(c) · Final 2025 Q3(b)

Determine $\lambda$ so that the vectors $\mathbf{x} = (1, \lambda, 3)$ and $\mathbf{y} = (3, -5, 4)$ are orthogonal.

Hint: Two vectors are orthogonal if and only if their dot product is zero: $\mathbf{x}\cdot\mathbf{y} = 0$.
Solution:
Set $\mathbf{x}\cdot\mathbf{y} = 0$: $$(1)(3) + (\lambda)(-5) + (3)(4) = 0 \implies 3 - 5\lambda + 12 = 0 \implies 15 - 5\lambda = 0 \implies \mathbf{\lambda = 3}.$$
Problem 2: Verifying Cauchy-Schwarz in $\mathbb{R}^5$ 1st Incourse 2023 Q1(b)

Verify that the Cauchy-Schwarz inequality holds for $\mathbf{u} = (2, -1, 1, 0, -2)$ and $\mathbf{v} = (1, 2, 2, 2, 1)$.

Hint: Compute $|\mathbf{u}\cdot\mathbf{v}|$, $\|\mathbf{u}\|$, and $\|\mathbf{v}\|$ separately, then confirm $|\mathbf{u}\cdot\mathbf{v}| \le \|\mathbf{u}\|\|\mathbf{v}\|$.
Solution:
1. Dot product: $\mathbf{u}\cdot\mathbf{v} = (2)(1) + (-1)(2) + (1)(2) + (0)(2) + (-2)(1) = 2 - 2 + 2 + 0 - 2 = 0$.
2. Norms: $\|\mathbf{u}\| = \sqrt{4+1+1+0+4} = \sqrt{10}$, and $\|\mathbf{v}\| = \sqrt{1+4+4+4+1} = \sqrt{14}$.
3. Check: $|\mathbf{u}\cdot\mathbf{v}| = 0 \le \sqrt{10}\sqrt{14} = \sqrt{140} \approx 11.83$.
Thus, the Cauchy-Schwarz inequality holds (in fact, $\mathbf{u} \perp \mathbf{v}$).
Problem 3: Parallel Planes & Distance 2nd Incourse 2020 · Final 2023 Q1(d) · Final 2025 Q1(b)

Determine whether the planes $2y = 8x - 4z + 5$ and $x = \dfrac{1}{2}z + \dfrac{1}{4}y$ are parallel. If so, find the distance between them.

Hint: Rewrite both equations in standard form $ax + by + cz = d$ and check if their normal vectors are scalar multiples.
Solution:
1. Rewrite Plane 1: $8x - 2y - 4z = -5 \implies$ divide by $2$: $4x - y - 2z = -\frac{5}{2}$, normal $\mathbf{n}_1 = (4, -1, -2)$.
2. Rewrite Plane 2: $x - \frac{1}{4}y - \frac{1}{2}z = 0 \implies$ multiply by $4$: $4x - y - 2z = 0$, normal $\mathbf{n}_2 = (4, -1, -2)$.
3. Since $\mathbf{n}_1 = \mathbf{n}_2$, the planes are parallel.
4. Distance using $d_1 = -\frac{5}{2}$ and $d_2 = 0$: $$D = \frac{|d_1 - d_2|}{\sqrt{4^2 + (-1)^2 + (-2)^2}} = \frac{|-\frac{5}{2} - 0|}{\sqrt{16 + 1 + 4}} = \frac{5}{2\sqrt{21}} \approx 0.5455.$$
Problem 4: Distance Between Two Parallel Planes 2nd Incourse 2019 Q2 · Final 2022 Q1(d)

Find the distance between the parallel planes $2x - y - z = 5$ and $-4x + 2y + 2z = 12$.

Hint: Divide the second equation by $-2$ so both planes share the exact same normal vector $(2, -1, -1)$.
Solution:
1. Plane 1: $2x - y - z = 5$ ($d_1 = 5$).
2. Divide Plane 2 by $-2$: $2x - y - z = -6$ ($d_2 = -6$).
3. Distance: $$D = \frac{|5 - (-6)|}{\sqrt{2^2 + (-1)^2 + (-1)^2}} = \frac{11}{\sqrt{6}} \approx 4.4907.$$
Problem 5: Distance & Angle Classification in $\mathbb{R}^4$ 2nd Incourse 2020 Q1(a)

For $\mathbf{u} = (1, 2, -3, 0)$ and $\mathbf{v} = (5, 1, 2, -2)$, find the Euclidean distance $d(\mathbf{u}, \mathbf{v})$ and $\cos\theta$. State whether the angle is acute, obtuse, or $90^\circ$.

Solution:
1. $\mathbf{u} - \mathbf{v} = (-4, 1, -5, 2) \implies d(\mathbf{u},\mathbf{v}) = \sqrt{16 + 1 + 25 + 4} = \sqrt{46} \approx 6.782$.
2. $\mathbf{u}\cdot\mathbf{v} = 5 + 2 - 6 + 0 = 1$.
3. $\|\mathbf{u}\| = \sqrt{1+4+9+0} = \sqrt{14}$, $\|\mathbf{v}\| = \sqrt{25+1+4+4} = \sqrt{34}$.
4. $\cos\theta = \dfrac{1}{\sqrt{14}\sqrt{34}} = \dfrac{1}{2\sqrt{119}} \approx 0.0458 > 0$. Since $\mathbf{u}\cdot\mathbf{v} > 0$, the angle is acute ($\approx 87.37^\circ$).
Problem 6: Nested Norm Expression 2nd Incourse 2021 Q1(b)

Evaluate $\big\|\|\mathbf{u} - \mathbf{v}\|\mathbf{w}\big\|$ for $\mathbf{u} = (-2, -1, 4, 5)$, $\mathbf{v} = (3, 1, -5, 7)$, and $\mathbf{w} = (6, 2, 1, 1)$.

Hint: $\|\mathbf{u}-\mathbf{v}\|$ is a positive scalar $k$. Use $\|k\mathbf{w}\| = |k|\|\mathbf{w}\|$ so you don't multiply out huge numbers!
Solution:
1. $\mathbf{u} - \mathbf{v} = (-5, -2, 9, -2) \implies \|\mathbf{u}-\mathbf{v}\| = \sqrt{25 + 4 + 81 + 4} = \sqrt{114}$.
2. $\|\mathbf{w}\| = \sqrt{36 + 4 + 1 + 1} = \sqrt{42}$.
3. By scalar homogeneity: $\big\|\|\mathbf{u}-\mathbf{v}\|\mathbf{w}\big\| = \|\mathbf{u}-\mathbf{v}\|\|\mathbf{w}\| = \sqrt{114}\sqrt{42} = \sqrt{4788} = 6\sqrt{133} \approx 69.20$.
Problem 7: Distance from a Point to a Plane Final 2019 Q1(a)

Find the distance between the point $(3, 1, -2)$ and the plane $x + 2y - 2z = 4$.

Solution:
Here $(a, b, c) = (1, 2, -2)$, $d = 4$, and $(x_0, y_0, z_0) = (3, 1, -2)$: $$D = \frac{|1(3) + 2(1) - 2(-2) - 4|}{\sqrt{1^2 + 2^2 + (-2)^2}} = \frac{|3 + 2 + 4 - 4|}{\sqrt{9}} = \frac{5}{3} \approx 1.667.$$
