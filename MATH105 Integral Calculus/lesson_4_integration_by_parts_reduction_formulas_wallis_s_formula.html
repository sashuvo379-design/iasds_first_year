Why $\int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx$:
By King's Property ($u = \frac{\pi}{2} - x$), $\sin(\frac{\pi}{2}-u) = \cos u$, so the two curves are exact mirror reflections across $x = \frac{\pi}{4}$ with identical enclosed area!
Section 3 • Exam-Ready Theory

Core Theory, Derivation Blueprints & ISRT Exam Traps

The LIATE hierarchy, the 3 IBP archetypes, every reduction & Wallis formula in one table, and the 4 classic ISRT exam traps.

1. IBP Formula & LIATE Priority Ladder

$$\int u\,dv = uv - \int v\,du, \qquad \int_a^b u\,dv = \big[uv\big]_a^b - \int_a^b v\,du$$

Choose $u$ from the highest category in LIATE (and $dv$ as the remainder):

LLogarithmic: $\ln x,\; \log_a x$
IInverse Trig: $\tan^{-1}x,\; \sin^{-1}x,\; \sec^{-1}x$
AAlgebraic: $x^n,\; x^2 - 2x + 2$
TTrigonometric: $\sin x,\; \cos 3x,\; \sec^2 x$
EExponential: $e^x,\; e^{2x},\; e^{-x}$

Hidden "$1$" Trick: For solo integrands like $\int \ln x\,dx$ or $\int \tan^{-1}x\,dx$, set $u = \ln x$ (or $\tan^{-1}x$) and $dv = 1\cdot dx \implies v = x$.

2. The 3 IBP Archetypes

Archetype 1 — Terminating (Tabular IBP):
$\int P(x)\,g(x)\,dx$ where $P(x)$ is a polynomial and $g(x)$ is $e^{ax}, \sin ax,$ or $\cos ax$. Differentiate $P(x)$ down to $0$ while integrating $g(x)$ repeatedly, alternating $+, -, +, -$.
Archetype 2 — Circular / Boomerang IBP:
$\int e^{ax}\cos bx\,dx$ or $\int \cos(\ln x)\,dx$. Apply IBP twice with a consistent choice of $u$, recover $-k\,I$ on the right-hand side, and solve algebraically: $(1 + k)I = \dots$.
Archetype 3 — Reduction Formulas:
Split off one integrable factor (e.g., $\sin^n x = \sin^{n-1}x\cdot\sin x$ or $\sec^n x = \sec^{n-2}x\cdot\sec^2 x$), apply IBP, use a Pythagorean identity ($\cos^2 x = 1 - \sin^2 x$), and collect $I_n$ on the left.

3. Master Reduction Formulas & Wallis's Formula Cheat Sheet

Integral $I_n$ General Reduction Formula Base Case(s)
$\displaystyle \int \sin^n x\,dx$ $$-\frac{1}{n}\sin^{n-1}x\cos x + \frac{n-1}{n}\int \sin^{n-2}x\,dx$$ $I_0 = x,\; I_1 = -\cos x$
$\displaystyle \int \cos^n x\,dx$ $$\frac{1}{n}\cos^{n-1}x\sin x + \frac{n-1}{n}\int \cos^{n-2}x\,dx$$ $I_0 = x,\; I_1 = \sin x$
$\displaystyle \int \sec^n x\,dx$ $$\frac{1}{n-1}\sec^{n-2}x\tan x + \frac{n-2}{n-1}\int \sec^{n-2}x\,dx$$ $I_0 = x,\; I_1 = \ln|\sec x + \tan x|$
$\displaystyle \int \tan^n x\,dx$ $$\frac{1}{n-1}\tan^{n-1}x - \int \tan^{n-2}x\,dx$$ $I_0 = x,\; I_1 = \ln|\sec x|$
$\displaystyle \int x^n e^x\,dx$ $$x^n e^x - n\int x^{n-1}e^x\,dx$$ $I_0 = e^x$
Wallis's Formula
$\displaystyle \int_0^{\pi/2}\sin^n x\,dx = \int_0^{\pi/2}\cos^n x\,dx$		 $$\text{Even } n \ge 2:\quad \frac{1\cdot 3\cdot 5\cdots(n-1)}{2\cdot 4\cdot 6\cdots n}\cdot\frac{\pi}{2} \qquad\qquad \text{Odd } n \ge 3:\quad \frac{2\cdot 4\cdot 6\cdots(n-1)}{3\cdot 5\cdot 7\cdots n}\cdot 1$$

⚠ 4 High-Yield ISRT Exam Traps

Trap 1: Missing Boundary Term $[uv]_a^b$

In definite IBP, always evaluate $[uv]_a^b$. Notice that Wallis's Formula works precisely because the boundary term $\left[-\frac{1}{n}\sin^{n-1}x\cos x\right]_0^{\pi/2} = 0 - 0 = 0$!

Trap 2: Tabular Signs & Chain-Rule Factors

Don't forget alternating diagonal signs $+, -, +, -$ AND repeated chain-rule denominators when integrating $e^{3x}$ ($\frac{1}{3}, \frac{1}{9}, \frac{1}{27}$) or $e^{-x}$ ($-1, +1, -1$).

Trap 3: Switching $u$ & $dv$ in Circular IBP

In $\int e^{ax}\cos bx\,dx$, if you set $u = e^{ax}$ on Pass 1, you must set $u = e^{ax}$ again on Pass 2. Switching $u$ and $dv$ on Pass 2 undoes Pass 1 and yields the useless identity $I = I$ ($0 = 0$).

Trap 4: Algebraic Split in $\int x^n\sqrt{a-x}\,dx$

In Final 2023 Q2(c), after integrating $dv = \sqrt{a-x}\,dx$, you must split $(a-x)^{3/2} = (a - x)\sqrt{a-x}$ to express $\int x^{n-1}(a-x)^{3/2}\,dx = aI_{n-1} - I_n$, then collect $\left(1 + \frac{2n}{3}\right)I_n = \frac{2n+3}{3}I_n$.

1st Incourse 2024 Q5(b) 3 Marks • Reduction Formula
Derive the reduction formula for $\displaystyle \int \sin^n x\,dx$, where $n \in \mathbb{N}$ and $n \ge 2$.
Hint: Split $\sin^n x = \sin^{n-1}x \cdot \sin x$, set $u = \sin^{n-1}x$ and $dv = \sin x\,dx$, then replace $\cos^2 x = 1 - \sin^2 x$ and move the $I_n$ term to the left side.
Step 1: Split integrand and assign $u, dv$
Let $I_n = \int \sin^n x\,dx = \int \sin^{n-1}x \cdot \sin x\,dx$. Set: $$u = \sin^{n-1}x \implies du = (n-1)\sin^{n-2}x\cos x\,dx, \qquad dv = \sin x\,dx \implies v = -\cos x.$$
Step 2: Apply IBP and Pythagorean identity
$$I_n = -\sin^{n-1}x\cos x + (n-1)\int \sin^{n-2}x\cos^2 x\,dx$$ Replace $\cos^2 x = 1 - \sin^2 x$: $$I_n = -\sin^{n-1}x\cos x + (n-1)\int \sin^{n-2}x\,dx - (n-1)\int \sin^n x\,dx$$ $$I_n = -\sin^{n-1}x\cos x + (n-1)I_{n-2} - (n-1)I_n.$$
Step 3: Collect $I_n$ and divide by $n$
$$n I_n = -\sin^{n-1}x\cos x + (n-1)I_{n-2} \implies \int \sin^n x\,dx = -\frac{1}{n}\sin^{n-1}x\cos x + \frac{n-1}{n}\int \sin^{n-2}x\,dx.$$
2nd Incourse 2022 Q2 5 Marks • Reduction Formula
Use integration by parts to derive the reduction formula for $\displaystyle \int \cos^n x\,dx$. Hence find $\displaystyle \int \cos^3 x\,dx$.
Hint: Set $u = \cos^{n-1}x$ and $dv = \cos x\,dx \implies v = \sin x$. Use $\sin^2 x = 1 - \cos^2 x$, solve for $I_n$, and substitute $n = 3$.
Step 1: Derive reduction formula for $I_n = \int \cos^n x\,dx$
Write $I_n = \int \cos^{n-1}x\cdot\cos x\,dx$ with $u = \cos^{n-1}x$, $dv = \cos x\,dx \implies du = -(n-1)\cos^{n-2}x\sin x\,dx$, $v = \sin x$: $$I_n = \cos^{n-1}x\sin x + (n-1)\int \cos^{n-2}x\sin^2 x\,dx$$ $$I_n = \cos^{n-1}x\sin x + (n-1)\int \cos^{n-2}x(1 - \cos^2 x)\,dx = \cos^{n-1}x\sin x + (n-1)I_{n-2} - (n-1)I_n.$$ Adding $(n-1)I_n$ to both sides and dividing by $n$: $$\int \cos^n x\,dx = \frac{1}{n}\cos^{n-1}x\sin x + \frac{n-1}{n}\int \cos^{n-2}x\,dx.$$
Step 2: Evaluate $\int \cos^3 x\,dx$ ($n = 3$)
$$\int \cos^3 x\,dx = \frac{1}{3}\cos^2 x\sin x + \frac{2}{3}\int \cos x\,dx = \frac{1}{3}\cos^2 x\sin x + \frac{2}{3}\sin x + C.$$
1st Incourse 2023 Q5(c) 3.5 Marks • Tabular IBP
Evaluate $\displaystyle \int (x^2 - 2x + 2)e^{3x}\,dx$ using Tabular Integration by Parts.
Hint: Differentiate $x^2 - 2x + 2 \to 2x - 2 \to 2 \to 0$ and integrate $e^{3x} \to \frac{1}{3}e^{3x} \to \frac{1}{9}e^{3x} \to \frac{1}{27}e^{3x}$, alternating signs $+, -, +$.
Step 1: Construct the D & I columns
• D: $x^2 - 2x + 2 \;\to\; 2x - 2 \;\to\; 2 \;\to\; 0$
• I: $e^{3x} \;\to\; \frac{1}{3}e^{3x} \;\to\; \frac{1}{9}e^{3x} \;\to\; \frac{1}{27}e^{3x}$
Step 2: Assemble diagonal products & simplify
$$\int (x^2 - 2x + 2)e^{3x}\,dx = +(x^2 - 2x + 2)\frac{e^{3x}}{3} - (2x - 2)\frac{e^{3x}}{9} + 2\cdot\frac{e^{3x}}{27} + C$$ $$= e^{3x}\left(\frac{9x^2 - 18x + 18 - 6x + 6 + 2}{27}\right) + C = \frac{e^{3x}}{27}\left(9x^2 - 24x + 26\right) + C.$$
Year Final 2023 Q2(c) 4 Marks • Algebraic Reduction
Prove that $$I_n = \int x^n\sqrt{a - x}\,dx = \frac{2an}{2n + 3}I_{n-1} - \frac{2x^n(a - x)^{3/2}}{2n + 3}, \qquad n \ge 1.$$ Hence evaluate $I_1$.
Hint: Set $u = x^n$ and $dv = \sqrt{a-x}\,dx \implies v = -\frac{2}{3}(a-x)^{3/2}$. Rewrite $(a-x)^{3/2} = (a - x)\sqrt{a-x}$ to pull out $aI_{n-1} - I_n$.
Step 1: Apply IBP with $u = x^n$ and $dv = (a-x)^{1/2}\,dx$
We have $du = nx^{n-1}\,dx$ and $v = -\frac{2}{3}(a-x)^{3/2}$. Thus: $$I_n = -\frac{2}{3}x^n(a - x)^{3/2} + \frac{2n}{3}\int x^{n-1}(a - x)^{3/2}\,dx.$$
Step 2: Split $(a-x)^{3/2} = (a-x)\sqrt{a-x}$ and collect $I_n$
$$\int x^{n-1}(a-x)\sqrt{a-x}\,dx = a\int x^{n-1}\sqrt{a-x}\,dx - \int x^n\sqrt{a-x}\,dx = aI_{n-1} - I_n.$$ Substituting back: $$I_n = -\frac{2}{3}x^n(a - x)^{3/2} + \frac{2an}{3}I_{n-1} - \frac{2n}{3}I_n$$ $$\left(1 + \frac{2n}{3}\right)I_n = \frac{2an}{3}I_{n-1} - \frac{2}{3}x^n(a - x)^{3/2} \implies \frac{2n + 3}{3}I_n = \frac{2an}{3}I_{n-1} - \frac{2}{3}x^n(a - x)^{3/2}.$$ Multiplying by $\frac{3}{2n+3}$ proves: $$I_n = \frac{2an}{2n + 3}I_{n-1} - \frac{2x^n(a - x)^{3/2}}{2n + 3}. \qquad \blacksquare$$
Step 3: Evaluate $I_1$
First find $I_0 = \int \sqrt{a-x}\,dx = -\frac{2}{3}(a-x)^{3/2}$. Setting $n = 1$: $$I_1 = \frac{2a}{5}I_0 - \frac{2x(a-x)^{3/2}}{5} = -\frac{4a}{15}(a-x)^{3/2} - \frac{2x}{5}(a-x)^{3/2} + C = -\frac{2}{15}(2a + 3x)(a-x)^{3/2} + C.$$
Year Final 2023 Q3(b)(iv) 3 Marks • Circular IBP
Evaluate $\displaystyle \int_0^{\pi/6} e^{2x}\cos 3x\,dx$.
Hint: Find the indefinite integral $I = \int e^{2x}\cos 3x\,dx$ using two passes of IBP (keeping $u = e^{2x}$ both times), solve $\frac{13}{9}I = \dots$, then apply limits $[0, \pi/6]$.
Step 1: Two passes of Circular IBP
Let $I = \int e^{2x}\cos 3x\,dx$. Pass 1 ($u = \cos 3x$, $dv = e^{2x}\,dx$): $$I = \frac{1}{2}e^{2x}\cos 3x + \frac{3}{2}\int e^{2x}\sin 3x\,dx.$$ Pass 2 ($u = \sin 3x$, $dv = e^{2x}\,dx$): $$I = \frac{1}{2}e^{2x}\cos 3x + \frac{3}{2}\left[\frac{1}{2}e^{2x}\sin 3x - \frac{3}{2}\int e^{2x}\cos 3x\,dx\right] = \frac{1}{2}e^{2x}\cos 3x + \frac{3}{4}e^{2x}\sin 3x - \frac{9}{4}I.$$
Step 2: Solve for $I$ and evaluate on $[0, \pi/6]$
$$\frac{13}{4}I = \frac{e^{2x}}{4}(2\cos 3x + 3\sin 3x) \implies I = \frac{e^{2x}}{13}(2\cos 3x + 3\sin 3x).$$ Evaluating from $0$ to $\frac{\pi}{6}$ (where $3\cdot\frac{\pi}{6} = \frac{\pi}{2}$): $$\left[\frac{e^{2x}}{13}(2\cos 3x + 3\sin 3x)\right]_0^{\pi/6} = \frac{e^{\pi/3}}{13}(0 + 3) - \frac{1}{13}(2 + 0) = \frac{3e^{\pi/3} - 2}{13}.$$
Year Final 2024 Q2(b)(iii) 3 Marks • Definite IBP
Evaluate $\displaystyle \int_1^e x^2 \ln x\,dx$.
Hint: By LIATE, Logarithmic beats Algebraic: choose $u = \ln x$ and $dv = x^2\,dx$.
Step 1: Set $u = \ln x$ and $dv = x^2\,dx$
Then $du = \frac{1}{x}\,dx$ and $v = \frac{x^3}{3}$. Applying definite IBP: $$\int_1^e x^2 \ln x\,dx = \left[\frac{x^3}{3}\ln x\right]_1^e - \int_1^e \frac{x^3}{3}\cdot\frac{1}{x}\,dx.$$
Step 2: Simplify and evaluate bounds
$$= \left(\frac{e^3}{3}\cdot 1 - 0\right) - \frac{1}{3}\int_1^e x^2\,dx = \frac{e^3}{3} - \left[\frac{x^3}{9}\right]_1^e = \frac{e^3}{3} - \frac{e^3 - 1}{9} = \frac{2e^3 + 1}{9}.$$
Year Final 2024 Q6(b) & Final 2025 Q2(b) 7 Marks • Tabular IBP Pair
Evaluate both integrals:
(i) $\displaystyle \int (3x^2 - x + 2)e^{-x}\,dx$ &qquad (ii) $\displaystyle \int (x^2 + x + 1)\sin x\,dx$.
Hint: Both are Degree-2 polynomials multiplied by $e^{-x}$ or $\sin x$. Use Tabular IBP with 3 diagonal arrows ($+, -, +$).
Part (i): $\int (3x^2 - x + 2)e^{-x}\,dx$
D: $3x^2 - x + 2 \to 6x - 1 \to 6 \to 0$.   I: $e^{-x} \to -e^{-x} \to e^{-x} \to -e^{-x}$. $$= +(3x^2 - x + 2)(-e^{-x}) - (6x - 1)(e^{-x}) + 6(-e^{-x}) + C = -e^{-x}(3x^2 + 5x + 7) + C.$$
Part (ii): $\int (x^2 + x + 1)\sin x\,dx$
D: $x^2 + x + 1 \to 2x + 1 \to 2 \to 0$.   I: $\sin x \to -\cos x \to -\sin x \to \cos x$. $$= +(x^2 + x + 1)(-\cos x) - (2x + 1)(-\sin x) + 2(\cos x) + C = (-x^2 - x + 1)\cos x + (2x + 1)\sin x + C.$$
Year Final 2017 Q8(c) 6 Marks • Definite Reduction
If $\displaystyle I_n = \int_0^1 x^n \tan^{-1}x\,dx$, then prove that $$(n + 1)I_n + (n - 1)I_{n-2} = \frac{\pi}{2} - \frac{1}{n}.$$
Hint: Use IBP with $u = \tan^{-1}x$ and $dv = x^n\,dx$ to express $(n+1)I_n$, write the same equation with $n$ replaced by $n - 2$, then add both equations so $(1 + x^2)$ cancels!
Step 1: Apply IBP to $I_n$
Set $u = \tan^{-1}x \implies du = \frac{dx}{1+x^2}$ and $dv = x^n\,dx \implies v = \frac{x^{n+1}}{n+1}$: $$I_n = \left[\frac{x^{n+1}}{n+1}\tan^{-1}x\right]_0^1 - \frac{1}{n+1}\int_0^1 \frac{x^{n+1}}{1+x^2}\,dx = \frac{\pi}{4(n+1)} - \frac{1}{n+1}\int_0^1 \frac{x^{n+1}}{1+x^2}\,dx.$$ Multiply both sides by $(n + 1)$: $$(n + 1)I_n = \frac{\pi}{4} - \int_0^1 \frac{x^{n+1}}{1+x^2}\,dx. \qquad \text{(1)}$$
Step 2: Replace $n$ by $n - 2$ and add
$$(n - 1)I_{n-2} = \frac{\pi}{4} - \int_0^1 \frac{x^{n-1}}{1+x^2}\,dx. \qquad \text{(2)}$$ Adding (1) and (2): $$(n + 1)I_n + (n - 1)I_{n-2} = \frac{\pi}{2} - \int_0^1 \frac{x^{n+1} + x^{n-1}}{1 + x^2}\,dx = \frac{\pi}{2} - \int_0^1 \frac{x^{n-1}(x^2 + 1)}{1 + x^2}\,dx$$ $$= \frac{\pi}{2} - \int_0^1 x^{n-1}\,dx = \frac{\pi}{2} - \left[\frac{x^n}{n}\right]_0^1 = \frac{\pi}{2} - \frac{1}{n}. \qquad \blacksquare$$
