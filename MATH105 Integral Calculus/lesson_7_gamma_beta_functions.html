Section 3 • Exam-Ready Reference

3. Core Theory, Master Identities & ISRT Exam Traps

Every definition, reduction formula, Beta representation, and exam pitfall required for ISRT 2nd In-course and Year Final exams.

1. Gamma Function Master Card

Definition ($n > 0$): $$\Gamma(n) = \int_0^\infty e^{-x} x^{n-1}\,dx$$
Base & Reduction: $$\Gamma(1) = 1, \qquad \Gamma(n + 1) = n\,\Gamma(n)$$
Factorial & Half-Integer Anchor: $$\Gamma(n + 1) = n!\; (n \in \mathbb{Z}_{\ge 0}), \qquad \Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}$$
Scaling Identity ($k > 0, n > 0$): $$\int_0^\infty x^{n-1} e^{-kx}\,dx = \frac{\Gamma(n)}{k^n}$$
Euler's Reflection Formula ($0 < m < 1$): $$\Gamma(m)\,\Gamma(1 - m) = \frac{\pi}{\sin(m\pi)}$$

2. Beta Function 3-Form Master Table ($m, n > 0$)

Form Formula & Derivation Key
Standard $[0,1]$ Form $B(m,n) = \displaystyle\int_0^1 x^{m-1}(1-x)^{n-1}\,dx = B(n,m)$
Adib's Probability Intuition: Placing $m$ red, $n$ blue, and $1$ gray ball randomly on $[0,1]$, the probability all $m$ red land left of the gray ball and $n$ blue land right of it is $B(m+1, n+1) = \frac{m!\,n!}{(m+n+1)!}$.
Infinite-Limit (2nd Kind) $B(m,n) = \displaystyle\int_0^\infty \frac{x^{m-1}}{(1+x)^{m+n}}\,dx$
Via $y = \frac{1}{1+x}$ (or $x = \frac{y}{1-y}$).
Trigonometric Form $B(m,n) = \displaystyle 2\int_0^{\pi/2} \sin^{2m-1}\theta \cos^{2n-1}\theta\,d\theta$
Via $x = \sin^2\theta,\; dx = 2\sin\theta\cos\theta\,d\theta$.
Fundamental Bridge & Shortcut $B(m,n) = \dfrac{\Gamma(m)\Gamma(n)}{\Gamma(m+n)}$
$\displaystyle \int_0^{\pi/2}\sin^p\theta\cos^q\theta\,d\theta = \frac{\Gamma\!\left(\frac{p+1}{2}\right)\Gamma\!\left(\frac{q+1}{2}\right)}{2\,\Gamma\!\left(\frac{p+q+2}{2}\right)}$

3. Class Notes Bonus: Gaussian Integral & Feynman's Technique

Gaussian Integral → Polar $I^2$ Trick
Let $I = \displaystyle\int_{-\infty}^\infty e^{-x^2}\,dx = 2\int_0^\infty e^{-x^2}\,dx$. Squaring: $$I^2 = \int_{-\infty}^\infty \int_{-\infty}^\infty e^{-(x^2+y^2)}\,dx\,dy = \int_0^{2\pi}\int_0^\infty e^{-r^2} r\,dr\,d\theta = 2\pi\left(\frac{1}{2}\right) = \pi.$$ $$\therefore\; I = \sqrt{\pi} \quad \text{and} \quad \int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2} \implies \Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}.$$
Feynman's Technique (2nd Incourse Syllabus)
To evaluate the Dirichlet integral $\displaystyle\int_0^\infty \frac{\sin x}{x}\,dx$, introduce parameter $b \ge 0$: $$I(b) = \int_0^\infty \frac{\sin x}{x} e^{-bx}\,dx \implies I'(b) = -\int_0^\infty e^{-bx}\sin x\,dx = -\frac{1}{1+b^2}.$$ Integrating back: $I(b) = -\tan^{-1}b + C$. Since $\lim_{b\to\infty} I(b) = 0$, $C = \frac{\pi}{2}$. Setting $b = 0$: $$\int_0^\infty \frac{\sin x}{x}\,dx = I(0) = \frac{\pi}{2}.$$

⚠ 4 High-Yield ISRT Exam Traps

Trap 1: The $n - 1$ Shift Trap

In $\Gamma(n) = \int_0^\infty e^{-x} x^{n-1}\,dx$, the argument is one more than the exponent! Thus $\int_0^\infty x^3 e^{-x}\,dx = \Gamma(4) = 3! = 6$, NOT $\Gamma(3) = 2$.

Trap 2: Missing Factor of $2$ in Trig Beta

Since $B(m, n) = \mathbf{2}\int_0^{\pi/2}\sin^{2m-1}\theta\cos^{2n-1}\theta\,d\theta$, a standalone trig integral is $\int_0^{\pi/2}\sin^p\theta\cos^q\theta\,d\theta = \mathbf{\frac{1}{2}}B\!\left(\frac{p+1}{2}, \frac{q+1}{2}\right)$. Forgetting the $\frac{1}{2}$ doubles your answer!

Trap 3: The Scaling Exponent Trap

In $\int_0^\infty x^{n-1} e^{-kx}\,dx$, setting $u = kx$ yields $x^{n-1} = u^{n-1}/k^{n-1}$ AND $dx = du/k$, combining to $\dfrac{\Gamma(n)}{k^n}$ (not $k^{n-1}$). Example: $\int_0^\infty x^{2019}e^{-2020x}dx = \frac{2019!}{2020^{2020}}$.

Trap 4: Domain Condition ($n \le 0$)

$\Gamma(n)$ diverges at $n = 0, -1, -2, \dots$! Always explicitly write "$n > 0$" when defining $\Gamma(n)$ and "$m, n > 0$" when defining $B(m, n)$ on ISRT exams to earn full definition marks.

Final 2025 Q3(a) Gamma Definition & Substitutions
Define the Gamma function. Use it to evaluate:
(i) $\displaystyle \int_0^1 \left(\ln\frac{1}{x}\right)^2 dx$ &qquad (ii) $\displaystyle \int_0^\infty x^3 e^{-2x}\,dx$.
Hint: For (i), set $u = \ln(1/x) \implies x = e^{-u}, dx = -e^{-u}du$. For (ii), set $u = 2x$ and watch the denominator $2^4 = 16$.
Definition
For any real $n > 0$, the Gamma function is defined by the improper integral $\displaystyle \Gamma(n) = \int_0^\infty e^{-x} x^{n-1}\,dx$.
Part (i): $\int_0^1 (\ln(1/x))^2\,dx = 2$
Let $u = \ln(1/x) = -\ln x \implies x = e^{-u}$ and $dx = -e^{-u}\,du$.
Limits: $x \to 0^+ \Rightarrow u \to \infty$; $x = 1 \Rightarrow u = 0$: $$\int_\infty^0 u^2 (-e^{-u}\,du) = \int_0^\infty e^{-u} u^{3-1}\,du = \Gamma(3) = 2! = 2.$$
Part (ii): $\int_0^\infty x^3 e^{-2x}\,dx = 3/8$
Let $u = 2x \implies x = \frac{u}{2}$ and $dx = \frac{du}{2}$ (limits remain $0$ to $\infty$): $$\int_0^\infty \left(\frac{u}{2}\right)^3 e^{-u}\frac{du}{2} = \frac{1}{2^4}\int_0^\infty e^{-u} u^{4-1}\,du = \frac{\Gamma(4)}{16} = \frac{3!}{16} = \frac{6}{16} = \frac{3}{8}.$$
Final 2025 Q3(b) Beta Trig Form & $B(3/2, 1/2)$
Define the Beta function $B(m, n)$ for $m, n > 0$. Using the substitution $x = \sin^2\theta$, show that $$B(m, n) = 2\int_0^{\pi/2} \sin^{2m-1}\theta \cos^{2n-1}\theta\,d\theta,$$ and hence evaluate $B\!\left(\frac{3}{2}, \frac{1}{2}\right)$.
Hint: With $x = \sin^2\theta$, $1-x = \cos^2\theta$ and $dx = 2\sin\theta\cos\theta\,d\theta$. For $m = 3/2, n = 1/2$, you get $2\int_0^{\pi/2} \sin^2\theta\,d\theta$.
Step 1: Definition & Substitution $x = \sin^2\theta$
For $m, n > 0$, $\displaystyle B(m, n) = \int_0^1 x^{m-1}(1-x)^{n-1}\,dx$.
Let $x = \sin^2\theta \implies 1 - x = \cos^2\theta$ and $dx = 2\sin\theta\cos\theta\,d\theta$.
Limits: $x = 0 \Rightarrow \theta = 0$; $x = 1 \Rightarrow \theta = \frac{\pi}{2}$. $$B(m, n) = \int_0^{\pi/2} (\sin^2\theta)^{m-1}(\cos^2\theta)^{n-1}\cdot 2\sin\theta\cos\theta\,d\theta = 2\int_0^{\pi/2} \sin^{2m-1}\theta\cos^{2n-1}\theta\,d\theta.$$
Step 2: Evaluate $B(3/2, 1/2)$
Setting $m = \frac{3}{2}$ ($2m-1 = 2$) and $n = \frac{1}{2}$ ($2n-1 = 0$): $$B\!\left(\frac{3}{2}, \frac{1}{2}\right) = 2\int_0^{\pi/2} \sin^2\theta\,d\theta = \int_0^{\pi/2} (1 - \cos 2\theta)\,d\theta = \left[\theta - \frac{\sin 2\theta}{2}\right]_0^{\pi/2} = \frac{\pi}{2}.$$ Check via Gamma bridge: $\dfrac{\Gamma(3/2)\Gamma(1/2)}{\Gamma(2)} = \dfrac{\frac{1}{2}\sqrt{\pi}\cdot\sqrt{\pi}}{1!} = \dfrac{\pi}{2}$.
2nd Incourse 2024 Q1(a) Beta–Gamma Fundamental Proof
Define Gamma and Beta functions. Prove the fundamental relation $$B(m, n) = \frac{\Gamma(m)\Gamma(n)}{\Gamma(m + n)}, \qquad m, n > 0.$$
Hint: Write $\Gamma(m)\Gamma(n) = \int_0^\infty\int_0^\infty e^{-(x+y)}x^{m-1}y^{n-1}\,dx\,dy$ and transform via $x = u^2, y = v^2$ then polar coordinates $(r, \theta)$ in the first quadrant!
Step 1: Rewrite $\Gamma(m)$ and $\Gamma(n)$ via $x = u^2$ and $y = v^2$
Using $x = u^2$ ($dx = 2u\,du$): $\Gamma(m) = 2\int_0^\infty e^{-u^2} u^{2m-1}\,du$. Similarly $\Gamma(n) = 2\int_0^\infty e^{-v^2} v^{2n-1}\,dv$. Multiplying: $$\Gamma(m)\Gamma(n) = 4\int_0^\infty\int_0^\infty e^{-(u^2+v^2)} u^{2m-1} v^{2n-1}\,du\,dv.$$
Step 2: Switch to Polar Coordinates ($u = r\cos\theta, v = r\sin\theta$, $du\,dv = r\,dr\,d\theta$)
Over the first quadrant ($0 \le r < \infty,\; 0 \le \theta \le \frac{\pi}{2}$): $$\Gamma(m)\Gamma(n) = 4\int_0^{\pi/2}\int_0^\infty e^{-r^2} r^{2m-1}\cos^{2m-1}\theta \cdot r^{2n-1}\sin^{2n-1}\theta \cdot r\,dr\,d\theta$$ $$= \left(2\int_0^\infty e^{-r^2} r^{2(m+n)-1}\,dr\right)\left(2\int_0^{\pi/2} \sin^{2n-1}\theta \cos^{2m-1}\theta\,d\theta\right).$$
Step 3: Recognize $\Gamma(m+n)$ and $B(m, n)$
The first factor is $\Gamma(m+n)$ (setting $t = r^2$) and the second factor is $B(n, m) = B(m, n)$: $$\Gamma(m)\Gamma(n) = \Gamma(m+n)\,B(m, n) \implies B(m, n) = \frac{\Gamma(m)\Gamma(n)}{\Gamma(m+n)}. \qquad \blacksquare$$
Final 2024 Q3(b) Beta Infinite-Limit Form
Define the Beta function and show that $$B(m, n) = \int_0^\infty \frac{x^{m-1}}{(1 + x)^{m+n}}\,dx, \qquad m, n > 0.$$
Hint: Start from $B(m, n) = \int_0^1 y^{m-1}(1-y)^{n-1}\,dy$ and substitute $y = \frac{x}{1+x}$ (or $y = \frac{1}{1+x}$ + symmetry $B(m,n)=B(n,m)$).
Step 1: Substitute $y = \frac{x}{1+x}$ into $B(m, n)$
Start from $\displaystyle B(m, n) = \int_0^1 y^{m-1}(1 - y)^{n-1}\,dy$. Set: $$y = \frac{x}{1 + x} \implies 1 - y = \frac{1}{1 + x}, \qquad dy = \frac{(1+x) - x}{(1+x)^2}\,dx = \frac{dx}{(1+x)^2}.$$
Step 2: Transform limits and combine powers of $(1+x)$
When $y = 0$, $x = 0$; as $y \to 1^-$, $x \to \infty$: $$B(m, n) = \int_0^\infty \left(\frac{x}{1+x}\right)^{m-1}\left(\frac{1}{1+x}\right)^{n-1}\frac{dx}{(1+x)^2} = \int_0^\infty \frac{x^{m-1}}{(1+x)^{(m-1)+(n-1)+2}}\,dx = \int_0^\infty \frac{x^{m-1}}{(1+x)^{m+n}}\,dx. \qquad \blacksquare$$
2nd Incourse 2024 Q1(b) & Final 2024 Q3(a) Gamma Scaling Formula
Evaluate both integrals using the Gamma function:
(i) $\displaystyle \int_0^\infty x^{2019} e^{-2020x}\,dx$ &qquad (ii) $\displaystyle \int_0^\infty x^{2018} e^{-2019x}\,dx$.
Hint: Use the scaling identity $\int_0^\infty x^{n-1} e^{-kx}\,dx = \frac{\Gamma(n)}{k^n}$ (watch the $n-1$ shift!).
Part (i): $\int_0^\infty x^{2019} e^{-2020x}\,dx$
Let $u = 2020x \implies x = \frac{u}{2020}$, $dx = \frac{du}{2020}$: $$\int_0^\infty \left(\frac{u}{2020}\right)^{2019} e^{-u}\frac{du}{2020} = \frac{1}{2020^{2020}}\int_0^\infty e^{-u} u^{2020-1}\,du = \frac{\Gamma(2020)}{2020^{2020}} = \frac{2019!}{2020^{2020}}.$$
Part (ii): $\int_0^\infty x^{2018} e^{-2019x}\,dx$
Similarly, setting $u = 2019x$ ($n = 2019, k = 2019$): $$\int_0^\infty x^{2018} e^{-2019x}\,dx = \frac{\Gamma(2019)}{2019^{2019}} = \frac{2018!}{2019^{2019}}.$$
Class Notes — Proof Gamma Reduction & Beta Symmetry
(a) Prove the Gamma reduction formula $\Gamma(n+1) = n\Gamma(n)$ ($n > 0$) using Integration by Parts and L'Hôpital's Rule.
(b) Prove Beta symmetry $B(m, n) = B(n, m)$.
Hint: For (a), set $u = x^n$ and $dv = e^{-x}dx$ in $\int_0^b e^{-x}x^n\,dx$. For (b), substitute $y = 1 - x$ in $B(m, n)$.
Part (a): Proof of $\Gamma(n+1) = n\Gamma(n)$
$$\Gamma(n+1) = \lim_{b\to\infty}\int_0^b x^n e^{-x}\,dx.$$ Integrate by parts with $u = x^n$ ($du = nx^{n-1}dx$) and $dv = e^{-x}dx$ ($v = -e^{-x}$): $$\Gamma(n+1) = \lim_{b\to\infty}\left[-x^n e^{-x}\right]_0^b + n\int_0^\infty e^{-x} x^{n-1}\,dx = -\lim_{b\to\infty}\frac{b^n}{e^b} + 0 + n\Gamma(n).$$ Repeated application of L'Hôpital's Rule shows $\lim_{b\to\infty}\frac{b^n}{e^b} = 0$, leaving $\Gamma(n+1) = n\Gamma(n)$.
Part (b): Proof of $B(m, n) = B(n, m)$
In $B(m, n) = \int_0^1 x^{m-1}(1-x)^{n-1}\,dx$, let $y = 1 - x \implies x = 1 - y$, $dx = -dy$ (limits flip $1 \to 0$): $$B(m, n) = \int_1^0 (1-y)^{m-1} y^{n-1}(-dy) = \int_0^1 y^{n-1}(1-y)^{m-1}\,dy = B(n, m). \qquad \blacksquare$$
Class Notes — Trig & Half-Integer Beta Shortcut & Fractional Gamma
Evaluate:
(i) $\displaystyle \int_0^{\pi/2} \sin^5\theta \cos^7\theta\,d\theta$ &qquad (ii) $\displaystyle \int_0^\infty e^{-\sqrt{x}} x^{1/4}\,dx$.
Hint: For (i), use $\frac{\Gamma((p+1)/2)\Gamma((q+1)/2)}{2\Gamma((p+q+2)/2)}$. For (ii), let $u = \sqrt{x} \implies x = u^2, dx = 2u\,du$.
Part (i): $\int_0^{\pi/2}\sin^5\theta\cos^7\theta\,d\theta = 1/120$
With $p = 5$ ($m = \frac{5+1}{2} = 3$) and $q = 7$ ($n = \frac{7+1}{2} = 4$): $$\int_0^{\pi/2}\sin^5\theta\cos^7\theta\,d\theta = \frac{1}{2}B(3, 4) = \frac{\Gamma(3)\Gamma(4)}{2\Gamma(7)} = \frac{2!\cdot 3!}{2\cdot 6!} = \frac{2\cdot 6}{2\cdot 720} = \frac{1}{120}.$$
Part (ii): $\int_0^\infty e^{-\sqrt{x}} x^{1/4}\,dx = \frac{3}{2}\sqrt{\pi}$
Let $u = \sqrt{x} \implies x = u^2$, $x^{1/4} = u^{1/2}$, $dx = 2u\,du$: $$2\int_0^\infty e^{-u} u^{3/2}\,du = 2\,\Gamma\!\left(\frac{5}{2}\right) = 2\cdot\frac{3}{2}\cdot\frac{1}{2}\Gamma\!\left(\frac{1}{2}\right) = \frac{3}{2}\sqrt{\pi}.$$
Class Notes — Bonus Proof $\Gamma(1/2) = \sqrt{\pi}$ via Gaussian / Reflection
Prove that $\displaystyle \Gamma\!\left(\frac{1}{2}\right) = \sqrt{\pi}$ using the Gaussian integral $I = \int_{-\infty}^\infty e^{-x^2}\,dx$ in polar coordinates (and verify using Euler's Reflection Formula).
Hint: Substitute $x = t^2$ in $\Gamma(1/2) = \int_0^\infty e^{-x} x^{-1/2}\,dx$ to obtain $2\int_0^\infty e^{-t^2}\,dt = \int_{-\infty}^\infty e^{-t^2}\,dt$.
Step 1: Connect $\Gamma(1/2)$ to the Gaussian Integral
$$\Gamma\!\left(\frac{1}{2}\right) = \int_0^\infty e^{-x} x^{-1/2}\,dx.$$ Let $x = t^2 \implies dx = 2t\,dt$ and $x^{-1/2} = 1/t$: $$\Gamma\!\left(\frac{1}{2}\right) = 2\int_0^\infty e^{-t^2}\,dt = \int_{-\infty}^\infty e^{-t^2}\,dt = I.$$
Step 2: Evaluate $I^2$ in Polar Coordinates
$$I^2 = \left(\int_{-\infty}^\infty e^{-x^2}\,dx\right)\left(\int_{-\infty}^\infty e^{-y^2}\,dy\right) = \int_0^{2\pi}\int_0^\infty e^{-r^2} r\,dr\,d\theta = 2\pi\left[-\frac{1}{2}e^{-r^2}\right]_0^\infty = \pi.$$ Since $I > 0$, $\Gamma\!\left(\frac{1}{2}\right) = I = \sqrt{\pi}$.
Reflection check ($m = 1/2$): $\Gamma(\frac{1}{2})\Gamma(\frac{1}{2}) = \frac{\pi}{\sin(\pi/2)} = \pi \implies \Gamma(\frac{1}{2}) = \sqrt{\pi}$. $\blacksquare$
