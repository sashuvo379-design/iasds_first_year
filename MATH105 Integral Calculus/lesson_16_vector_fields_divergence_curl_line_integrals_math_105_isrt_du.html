3 Core Theory, Master Formulas & ISRT Exam Traps

1. Gradient, Divergence & Curl (Sec. 15.1)

For scalar $\phi(x,y,z)$ and vector field $\mathbf{F} = f\mathbf{i} + g\mathbf{j} + h\mathbf{k}$:

$$\nabla\phi = \frac{\partial\phi}{\partial x}\mathbf{i} + \frac{\partial\phi}{\partial y}\mathbf{j} + \frac{\partial\phi}{\partial z}\mathbf{k} \quad (\text{steepest ascent, }\perp\text{ level surfaces})$$ $$\text{div}\,\mathbf{F} = \nabla\cdot\mathbf{F} = \frac{\partial f}{\partial x} + \frac{\partial g}{\partial y} + \frac{\partial h}{\partial z} \quad (\text{scalar: source/sink/incompressible})$$ $$\text{curl}\,\mathbf{F} = \nabla\times\mathbf{F} = \begin{vmatrix}\mathbf{i}&\mathbf{j}&\mathbf{k}\\ \partial_x&\partial_y&\partial_z\\ f&g&h\end{vmatrix} \quad (\text{vector: rotation; }\mathbf{0}=\text{irrotational})$$

2. Scalar Line Integrals w.r.t. Arc Length $ds$

Integrates a scalar function (e.g., wire density $\delta$ or curtain height $f$) along $\mathbf{r}(t) = x(t)\mathbf{i} + y(t)\mathbf{j}$, $a \le t \le b$:

$$\int_C f(x,y)\,ds = \int_a^b f\big(x(t), y(t)\big)\|\mathbf{r}'(t)\|\,dt$$ $$ds = \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt, \qquad \int_{-C} f\,ds = +\int_C f\,ds$$

Key property: Completely independent of orientation! Used for wire mass $M = \int_C \delta\,ds$ and vertical curtain area.

3. Vector / Coordinate Line Integrals (Work)

Measures total work done by force field $\mathbf{F} = \langle f, g, h\rangle$ along an oriented curve $C$:

$$\int_C \mathbf{F}\cdot d\mathbf{r} = \int_C f\,dx + g\,dy + h\,dz = \int_a^b \mathbf{F}(\mathbf{r}(t))\cdot\mathbf{r}'(t)\,dt$$ $$\int_{-C} \mathbf{F}\cdot d\mathbf{r} = -\int_C \mathbf{F}\cdot d\mathbf{r}$$

Key property: Reversing direction ($-C$) negates the integral!

4. Standard Parametrization Cheat Sheet

Line segment $\mathbf{r}_0 \to \mathbf{r}_1$: $\;\mathbf{r}(t) = (1-t)\mathbf{r}_0 + t\mathbf{r}_1,\quad 0 \le t \le 1$
Circle / Semicircle ($x^2+y^2=a^2$): $\;x = a\cos t,\; y = a\sin t$ (CCW: $0\to\pi$ for upper semicircle, $0\to 2\pi$ full)
Function graph $y = f(x)$: $\;x = t,\; y = f(t),\; a \le t \le b$
Vertical line $x = c$: $\;x = c,\; y = t\; (dx = 0,\; dy = dt)$

⚠ 4 High-Yield ISRT Exam Traps

Trap 1: Confusing $ds$ with $dx, dy$ Scalar $ds$ requires multiplying by the speed $\|\mathbf{r}'(t)\|$ and is independent of orientation. Coordinate integrals $f\,dx + g\,dy$ use $x'(t)\,dt$ and $y'(t)\,dt$ (no square root!) and flip sign on $-C$.
Trap 2: Computing Curl as a Scalar in 3D In 3D, $\text{div}\,\mathbf{F}$ is a scalar, whereas $\text{curl}\,\mathbf{F}$ is ALWAYS a vector computed via the $3\times 3$ determinant!
Trap 3: Dropping the Minus Sign on $\mathbf{j}$ in Curl In the $3\times 3$ curl determinant, the middle component is $-\left(\frac{\partial h}{\partial x} - \frac{\partial f}{\partial z}\right)\mathbf{j} = \left(\frac{\partial f}{\partial z} - \frac{\partial h}{\partial x}\right)\mathbf{j}$. Watch this sign in Final 2024 Q8(a)!
Trap 4: Backwards Triangle Leg Parametrization For the return leg $(1,2)\to(0,0)$ of a triangle, using $x = t, y = 2t$ from $0$ to $1$ walks backwards! Always use $\mathbf{r}(t) = (1-t)\mathbf{r}_0 + t\mathbf{r}_1 = \langle 1-t, 2-2t\rangle$ for $0 \le t \le 1$ (or integrate from $t = 1$ down to $0$).
