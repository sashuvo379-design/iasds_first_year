3. Core Theory, Reference Tables & Exam Traps

Keep these parity rules, Weierstrass identities, partial fraction templates, and ISRT exam traps at your fingertips.

1. Trig Integrals Parity Rules Table

Form Parity Condition Factor to Peel Off Identity & Substitution
$\displaystyle \int \sin^m x\cos^n x\,dx$ $n$ odd ($\cos$ odd) Peel $\cos x\,dx$ $\cos^2 x = 1 - \sin^2 x$, let $u = \sin x$
$m$ odd ($\sin$ odd) Peel $\sin x\,dx$ $\sin^2 x = 1 - \cos^2 x$, let $u = \cos x$
Both $m, n$ even None (power reduction) $\sin^2 x = \frac{1-\cos 2x}{2}$, $\cos^2 x = \frac{1+\cos 2x}{2}$
$\displaystyle \int \tan^m x\sec^n x\,dx$ $n$ even ($\sec$ even, $n \ge 2$) Peel $\sec^2 x\,dx$ $\sec^2 x = 1 + \tan^2 x$, let $u = \tan x$
$m$ odd ($\tan$ odd, $n \ge 1$) Peel $\sec x\tan x\,dx$ $\tan^2 x = \sec^2 x - 1$, let $u = \sec x$

2. Weierstrass Half-Angle Substitution

Converts any rational function of $\sin x$ and $\cos x$ (e.g., $\int \frac{dx}{2+\cos x}$ or $\int \frac{dx}{2+3\sin x}$) into a pure rational integral in $t$:

$$t = \tan\!\left(\frac{x}{2}\right) \quad \Longleftrightarrow \quad x = 2\tan^{-1}t$$ $$\sin x = \frac{2t}{1 + t^2}, \qquad \cos x = \frac{1 - t^2}{1 + t^2}, \qquad dx = \frac{2\,dt}{1 + t^2}$$

Exam Tip: Always multiply numerator & denominator by $(1+t^2)$ immediately—it clears all inner fractions in one line!

3. Partial Fractions 4-Case Template

Denominator / Case Required Action / Template
Improper ($\deg P \ge \deg Q$) Long Division first: $\frac{P}{Q} = S(x) + \frac{R(x)}{Q(x)}$
Distinct Linear $(x - r)$ $\dfrac{A}{x - r}$
Repeated Linear $(x - r)^k$ $\dfrac{A_1}{x-r} + \dfrac{A_2}{(x-r)^2} + \dots + \dfrac{A_k}{(x-r)^k}$
Irreducible Quad $ax^2+bx+c$ $\dfrac{Ax + B}{ax^2 + bx + c}$ (linear numerator!)

⚠ 4 High-Yield ISRT Exam Traps

Trap 1: Skipping Polynomial Long Division

Whenever $\deg(P) \ge \deg(Q)$ (like $\frac{3x^3+2x^2-3x+8}{x+2}$ in 2nd Incourse 2022), you must divide first. Applying partial fractions directly to an improper fraction gives wrong constants!

Trap 2: Missing "$x$" on Quadratic Numerator

For an irreducible quadratic factor like $(x^2+1)$, writing $\frac{A}{x^2+1}$ instead of $\frac{Ax+B}{x^2+1}$ causes an inconsistent system. Always use a linear numerator $Ax + B$.

Trap 3: Forgetting $\theta \to x$ or Limit Updates

In indefinite Trig Sub, draw the reference triangle to convert $\theta$ back to $x$. In definite Trig Sub (like $\int_{\sqrt{2}}^2$), convert $x$-limits to $\theta$-limits immediately so you never have to back-substitute!

Trap 4: Dropping $\frac{1}{a}$ or $\frac{1}{2a}$ Constants

Never drop the leading factor in standard formulas: $\int \frac{dx}{x^2+a^2} = \mathbf{\frac{1}{a}}\tan^{-1}\!\left(\frac{x}{a}\right)+C$ and $\int \frac{dx}{x^2-a^2} = \mathbf{\frac{1}{2a}}\ln\!\left|\frac{x-a}{x+a}\right|+C$.

Final 2024 Q2b(i) & 1st Incourse 2023 Q5(b) Partial Fractions • 3–3.5 Marks
Evaluate $\displaystyle \int \frac{2x}{(x + 1)(x^2 + 1)}\,dx$.
Hint: Decompose as $\frac{A}{x+1} + \frac{Bx+C}{x^2+1}$. Plug $x = -1$ to find $A = -1$ immediately, then compare coefficients of $x^2$ and constants.
Step 1: Set up the partial fraction decomposition
$$\frac{2x}{(x+1)(x^2+1)} = \frac{A}{x+1} + \frac{Bx+C}{x^2+1} \implies 2x = A(x^2+1) + (Bx+C)(x+1).$$
Step 2: Solve for $A, B, C$
• Set $x = -1$: $-2 = 2A \implies A = -1$.
• Compare $x^2$ terms: $0 = A + B \implies B = 1$.
• Compare constants ($x=0$): $0 = A + C \implies C = 1$.
Step 3: Integrate term-by-term
$$\int \left(\frac{-1}{x+1} + \frac{x}{x^2+1} + \frac{1}{x^2+1}\right)dx = -\ln|x+1| + \frac{1}{2}\ln(x^2+1) + \tan^{-1}x + C.$$
Final 2024 Q2b(ii) Weierstrass • 3 Marks
Evaluate $\displaystyle \int \frac{1}{2 + \cos x}\,dx$.
Hint: Use $t = \tan(x/2)$ with $\cos x = \frac{1-t^2}{1+t^2}$ and $dx = \frac{2\,dt}{1+t^2}$. Clear $(1+t^2)$ to get $\int \frac{2\,dt}{3+t^2}$.
Step 1: Apply Weierstrass substitution $t = \tan(x/2)$
$$\int \frac{1}{2 + \frac{1-t^2}{1+t^2}}\cdot\frac{2\,dt}{1+t^2} = \int \frac{2\,dt}{2(1+t^2) + (1-t^2)} = \int \frac{2\,dt}{t^2 + 3}.$$
Step 2: Apply $\int \frac{dt}{t^2+a^2} = \frac{1}{a}\tan^{-1}(t/a)$ with $a = \sqrt{3}$
$$= \frac{2}{\sqrt{3}}\tan^{-1}\!\left(\frac{t}{\sqrt{3}}\right) + C = \frac{2}{\sqrt{3}}\tan^{-1}\!\left(\frac{\tan(x/2)}{\sqrt{3}}\right) + C.$$
2nd Incourse 2022 Q1(b) Partial Fractions • 3 Marks
Evaluate $\displaystyle \int \frac{3x^3 + 2x^2 - 3x + 8}{x + 2}\,dx$ (using partial fractions / division).
Hint: Since $\deg(P)=3 \ge \deg(Q)=1$, perform polynomial (or synthetic) division by $(x+2)$ first!
Step 1: Polynomial Long Division
Dividing $3x^3 + 2x^2 - 3x + 8$ by $x + 2$: $$\frac{3x^3 + 2x^2 - 3x + 8}{x + 2} = 3x^2 - 4x + 5 - \frac{2}{x + 2}.$$
Step 2: Integrate term-by-term
$$\int \left(3x^2 - 4x + 5 - \frac{2}{x+2}\right)dx = x^3 - 2x^2 + 5x - 2\ln|x+2| + C.$$
2nd Incourse 2018 Q3(ii) Trig Integrals • 2 Marks
Evaluate $\displaystyle \int \tan^5 x \sec^4 x\,dx$.
Hint: Since $\sec x$ has an even power ($4$), peel off $\sec^2 x\,dx$, rewrite the remaining $\sec^2 x = 1 + \tan^2 x$, and set $u = \tan x$.
Step 1: Peel $\sec^2 x\,dx$ and convert remaining $\sec^2 x$
$$\int \tan^5 x \sec^4 x\,dx = \int \tan^5 x(1 + \tan^2 x)\sec^2 x\,dx.$$
Step 2: Substitute $u = \tan x$, $du = \sec^2 x\,dx$
$$= \int (u^5 + u^7)\,du = \frac{u^6}{6} + \frac{u^8}{8} + C = \frac{1}{6}\tan^6 x + \frac{1}{8}\tan^8 x + C.$$
2nd Incourse 2018 Q3(iii) Trig Sub • 2 Marks
Evaluate $\displaystyle \int_{\sqrt{2}}^{2} \frac{dx}{x^2\sqrt{x^2 - 1}}$.
Hint: For $\sqrt{x^2-1}$, set $x = \sec\theta$. Update limits: $x = \sqrt{2} \to \theta = \frac{\pi}{4}$ and $x = 2 \to \theta = \frac{\pi}{3}$.
Step 1: Trig Substitution $x = \sec\theta$ & Limit Conversion
Let $x = \sec\theta \implies dx = \sec\theta\tan\theta\,d\theta$ and $\sqrt{x^2-1} = \tan\theta$ (positive on $[\frac{\pi}{4}, \frac{\pi}{3}]$).
Limits: $x = \sqrt{2} \implies \theta = \frac{\pi}{4}$; $x = 2 \implies \theta = \frac{\pi}{3}$.
Step 2: Simplify and integrate
$$\int_{\pi/4}^{\pi/3} \frac{\sec\theta\tan\theta\,d\theta}{\sec^2\theta\tan\theta} = \int_{\pi/4}^{\pi/3} \cos\theta\,d\theta = \big[\sin\theta\big]_{\pi/4}^{\pi/3} = \frac{\sqrt{3} - \sqrt{2}}{2}.$$
Final 2023 Q3a(iv) Trig Integrals • 3 Marks
Evaluate $\displaystyle \int \frac{\sqrt{\sin x}}{\sqrt{\cos^9 x}}\,dx$.
Hint: Split $\cos^{9/2}x = \cos^{1/2}x \cdot \cos^4 x$ to reveal $\int \tan^{1/2}x \sec^4 x\,dx$, then substitute $u = \tan x$.
Step 1: Rewrite in terms of $\tan x$ and $\sec x$
$$\int \frac{\sin^{1/2}x}{\cos^{1/2}x \cdot \cos^4 x}\,dx = \int \tan^{1/2}x \sec^4 x\,dx = \int \tan^{1/2}x (1 + \tan^2 x)\sec^2 x\,dx.$$
Step 2: Substitute $u = \tan x$, $du = \sec^2 x\,dx$
$$= \int \left(u^{1/2} + u^{5/2}\right)du = \frac{2}{3}u^{3/2} + \frac{2}{7}u^{7/2} + C = \frac{2}{3}\tan^{3/2}x + \frac{2}{7}\tan^{7/2}x + C.$$
Final 2023 Q3b(ii) Trig Sub • 3 Marks
Evaluate $\displaystyle \int_{e^{-6}}^{e^6} \frac{\sqrt{36 - (\ln x)^2}}{x}\,dx$.
Hint: First let $u = \ln x$ ($du = \frac{dx}{x}$). The limits become $[-6, 6]$, giving the area of a semicircle of radius $6$!
Step 1: $u$-Substitution $u = \ln x$
Let $u = \ln x \implies du = \frac{dx}{x}$. Limits: $x = e^{-6} \implies u = -6$ and $x = e^6 \implies u = 6$: $$\int_{-6}^{6} \sqrt{36 - u^2}\,du.$$
Step 2: Geometric Semicircle (or Trig Sub $u = 6\sin\theta$)
• Geometry: $y = \sqrt{36 - u^2}$ on $[-6, 6]$ is the upper semicircle of radius $r = 6$, so $\text{Area} = \frac{1}{2}\pi(6)^2 = 18\pi$.
• Trig Sub check: $u = 6\sin\theta \implies 36\int_{-\pi/2}^{\pi/2} \cos^2\theta\,d\theta = 18\big[\theta + \frac{1}{2}\sin 2\theta\big]_{-\pi/2}^{\pi/2} = 18\pi$.
Final 2017 Q6b(ii) Trig Sub • 3 Marks
Evaluate $\displaystyle \int_1^2 \frac{dx}{\sqrt{4x - x^2}}$.
Hint: Complete the square: $4x - x^2 = 4 - (x - 2)^2$, then set $x - 2 = 2\sin\theta$.
Step 1: Complete the square under the radical
$$4x - x^2 = -(x^2 - 4x + 4) + 4 = 4 - (x - 2)^2.$$
Step 2: Substitute $x - 2 = 2\sin\theta$ and update limits
$dx = 2\cos\theta\,d\theta$ and $\sqrt{4 - (x-2)^2} = 2\cos\theta$.
Limits: $x = 1 \implies \sin\theta = -\frac{1}{2} \implies \theta = -\frac{\pi}{6}$; $x = 2 \implies \sin\theta = 0 \implies \theta = 0$. $$\int_{-\pi/6}^{0} \frac{2\cos\theta\,d\theta}{2\cos\theta} = \big[\theta\big]_{-\pi/6}^{0} = 0 - \left(-\frac{\pi}{6}\right) = \frac{\pi}{6}.$$
