Section 3 • Exam-Ready Foundations

3. Core Theory, Definitions & ISRT Exam Traps

Exact formal limit definitions for First Kind (Type I), Second Kind (Type II), and Mixed Improper Integrals, plus the 4 deadliest exam traps.

1. Type I (First Kind): Infinite Intervals

If $f$ is continuous on the respective unbounded interval, we replace $\pm\infty$ with a finite limit parameter:

$$\int_a^\infty f(x)\,dx = \lim_{b\to\infty} \int_a^b f(x)\,dx$$ $$\int_{-\infty}^b f(x)\,dx = \lim_{a\to -\infty} \int_a^b f(x)\,dx$$ $$\int_{-\infty}^\infty f(x)\,dx = \int_{-\infty}^c f(x)\,dx + \int_c^\infty f(x)\,dx$$

Convergence Rule: $\int_{-\infty}^\infty$ converges if and only if BOTH independent splits $\int_{-\infty}^c$ and $\int_c^\infty$ converge to finite numbers!

2. Type II (Second Kind): Vertical Asymptotes

If $f$ has an infinite discontinuity (vertical asymptote) on $[a, b]$:

At left endpoint $a$: $\displaystyle \int_a^b f(x)\,dx = \lim_{k\to a^+} \int_k^b f(x)\,dx$
At right endpoint $b$: $\displaystyle \int_a^b f(x)\,dx = \lim_{k\to b^-} \int_a^k f(x)\,dx$
At interior point $c \in (a,b)$: $\displaystyle \int_a^b f = \int_a^c f + \int_c^b f$

For an interior singularity $c \in (a, b)$, both $\lim_{k\to c^-}\int_a^k f$ and $\lim_{k\to c^+}\int_k^b f$ must converge independently.

3. Mixed Improper Integrals (Type I + Type II)

When an integral has both an infinite limit and a vertical asymptote (like Final 2017 Q8b: $\int_0^\infty \frac{dx}{\sqrt{x}(x+1)}$):

$$\int_0^\infty f(x)\,dx = \underbrace{\int_0^1 f(x)\,dx}_{\text{Type II at } 0^+} + \underbrace{\int_1^\infty f(x)\,dx}_{\text{Type I at } +\infty}$$

Split at any convenient interior point (usually $c = 1$) so each piece has exactly one improper point. If a clean substitution (like $u = \sqrt{x}$) removes the Type II singularity, verify limits carefully!

⚠ 4 High-Yield ISRT Exam Traps

Trap 1: Hidden Interior Asymptote

Blindly applying FTC to $\int_{-1}^1 x^{-2}\,dx$ gives $\big[-1/x\big]_{-1}^1 = -2$ (a negative answer for a positive integrand!). Because $x^{-2}$ blows up at $x = 0$, splitting at $0$ reveals $+\infty + \infty$ → Diverges!

Trap 2: Symmetric Limit (Cauchy Principal Value)

Even though $\lim_{b\to\infty}\int_{-b}^b x\,dx = 0$ and $\lim_{b\to\infty}\int_{-b}^b \sin x\,dx = 0$, neither integral converges! You must split at $c = 0$ and take two independent limits ($a \to -\infty$ and $b \to +\infty$).

Trap 3: $p$-Test Direction Reversal

Never confuse the two $p$-tests:
• At $\infty$: $\int_1^\infty x^{-p}\,dx$ converges for $p > 1$ (steep tail).
• At $0$: $\int_0^1 x^{-p}\,dx$ converges for $p < 1$ (mild spike).

Trap 4: One Divergent Split Kills the Whole

In $\int_1^4 \frac{dx}{(x-1)(x-2)(x-3)}$, once the first split $I_1 = \int_1^{1.5} f(x)\,dx$ diverges to $+\infty$, you can stop immediately and declare the entire integral divergent!

Final 2018 Q6(c) Type I • Doubly Infinite
Define improper integral of the First Kind. Evaluate $\displaystyle \int_{-\infty}^{\infty} \frac{1}{1 + x^2}\,dx$.
Hint: Split at $c = 0$ into two independent limits $\lim_{a\to-\infty}\int_a^0$ and $\lim_{b\to\infty}\int_0^b$, then recall $\lim_{x\to\pm\infty}\tan^{-1}x = \pm\frac{\pi}{2}$.
Step 1: Definition of First Kind (Type I) Improper Integral
An integral over an unbounded interval $[a,\infty)$, $(-\infty,b]$, or $(-\infty,\infty)$ is an improper integral of the First Kind, defined via limits: $$\int_a^\infty f(x)\,dx = \lim_{b\to\infty}\int_a^b f(x)\,dx, \quad \int_{-\infty}^b f(x)\,dx = \lim_{a\to-\infty}\int_a^b f(x)\,dx,$$ and $\int_{-\infty}^\infty f = \int_{-\infty}^c f + \int_c^\infty f$ (convergent iff both parts converge).
Step 2: Split at $c = 0$ and evaluate both halves independently
$$\int_{-\infty}^{0} \frac{dx}{1+x^2} = \lim_{a\to-\infty}\big[\tan^{-1}x\big]_a^0 = 0 - \left(-\frac{\pi}{2}\right) = \frac{\pi}{2}.$$ $$\int_{0}^{\infty} \frac{dx}{1+x^2} = \lim_{b\to\infty}\big[\tan^{-1}x\big]_0^b = \frac{\pi}{2} - 0 = \frac{\pi}{2}.$$
Step 3: Combine
Since both halves converge independently, $\displaystyle \int_{-\infty}^{\infty} \frac{dx}{1+x^2} = \frac{\pi}{2} + \frac{\pi}{2} = \pi$.
Final 2017 Q8(b) Mixed Type I + Type II
Evaluate the mixed improper integral $\displaystyle \int_0^\infty \frac{1}{\sqrt{x}(x + 1)}\,dx$.
Hint: Notice it is improper at both $x = 0^+$ (Type II) and $x = \infty$ (Type I). Split at $x = 1$, then substitute $u = \sqrt{x} \implies dx = 2\sqrt{x}\,du$!
Step 1: Split into Type II + Type I at $x = 1$
$$\int_0^\infty \frac{dx}{\sqrt{x}(x+1)} = \lim_{k\to 0^+}\int_k^1 \frac{dx}{\sqrt{x}(x+1)} + \lim_{b\to\infty}\int_1^b \frac{dx}{\sqrt{x}(x+1)}.$$
Step 2: Antiderivative via $u = \sqrt{x}$
Let $u = \sqrt{x} \implies x = u^2$ and $\frac{dx}{\sqrt{x}} = 2\,du$: $$\int \frac{dx}{\sqrt{x}(x+1)} = \int \frac{2\,du}{u^2 + 1} = 2\tan^{-1}(\sqrt{x}) + C.$$
Step 3: Evaluate both limits
$$I_1 = \lim_{k\to 0^+}\big[2\tan^{-1}\sqrt{x}\big]_k^1 = 2\left(\frac{\pi}{4} - 0\right) = \frac{\pi}{2}.$$ $$I_2 = \lim_{b\to\infty}\big[2\tan^{-1}\sqrt{x}\big]_1^b = 2\left(\frac{\pi}{2} - \frac{\pi}{4}\right) = \frac{\pi}{2}.$$ $$\therefore\; \int_0^\infty \frac{dx}{\sqrt{x}(x+1)} = \frac{\pi}{2} + \frac{\pi}{2} = \pi.$$
2nd Incourse 2022 Q5 Type II • Arc Length Singularity
Find the arc length of the curve $y = (4 - x^{2/3})^{3/2}$ over the interval $[0, 2]$, and explain why the improper integral concept is necessary to solve this problem.
Hint: Compute $y' = -\frac{\sqrt{4 - x^{2/3}}}{x^{1/3}}$. Note that $y'$ has a vertical tangent (infinite discontinuity) at $x = 0$, and $1 + (y')^2$ simplifies miraculously to $4x^{-2/3}$!
Step 1: Compute $y'$ and explain why an improper integral is needed
$$y' = \frac{3}{2}(4 - x^{2/3})^{1/2}\cdot\left(-\frac{2}{3}x^{-1/3}\right) = -\frac{\sqrt{4 - x^{2/3}}}{x^{1/3}}.$$ Since $\lim_{x\to 0^+} y' = -\infty$, the curve has a vertical tangent at $x = 0$, making the arc-length integrand $\sqrt{1+(y')^2}$ unbounded at $x = 0$. Therefore, a Type II improper integral is required.
Step 2: Simplify the arc-length integrand
$$1 + (y')^2 = 1 + \frac{4 - x^{2/3}}{x^{2/3}} = \frac{4}{x^{2/3}} \implies \sqrt{1 + (y')^2} = 2x^{-1/3}.$$
Step 3: Evaluate as $k \to 0^+$
$$L = \lim_{k\to 0^+}\int_k^2 2x^{-1/3}\,dx = \lim_{k\to 0^+}\left[3x^{2/3}\right]_k^2 = 3\cdot 2^{2/3} - 0 = 3\cdot 2^{2/3} \approx 4.7622.$$
2nd Incourse 2024 / Class Notes Type I • IBP + L'Hôpital
Evaluate $\displaystyle \int_0^\infty (1 - x)e^{-x}\,dx$ using Integration by Parts and L'Hôpital's Rule.
Hint: Set $u = 1 - x$, $dv = e^{-x}\,dx \implies v = -e^{-x}$. The antiderivative simplifies cleanly to $xe^{-x}$!
Step 1: Find the antiderivative via IBP
With $u = 1 - x$ ($du = -dx$) and $dv = e^{-x}\,dx$ ($v = -e^{-x}$): $$\int (1-x)e^{-x}\,dx = -(1-x)e^{-x} - \int e^{-x}\,dx = -(1-x)e^{-x} + e^{-x} = x e^{-x} + C.$$
Step 2: Apply limit $b \to \infty$ and L'Hôpital's Rule
$$\int_0^\infty (1-x)e^{-x}\,dx = \lim_{b\to\infty}\big[x e^{-x}\big]_0^b = \lim_{b\to\infty} \frac{b}{e^b} - 0.$$ Since $\frac{b}{e^b}$ has form $\frac{\infty}{\infty}$, L'Hôpital's Rule gives $\lim_{b\to\infty}\frac{1}{e^b} = 0$. Thus the integral converges to $0$!
Class Notes • Theorem 7.8 Type I $p$-Integral Proof
For what values of $p$ does $\displaystyle \int_1^\infty \frac{dx}{x^p}$ converge? Derive all three cases ($p = 1$, $p > 1$, $p < 1$).
Hint: Treat $p = 1$ separately (since $\int x^{-1}\,dx = \ln x$). For $p \ne 1$, examine $\lim_{b\to\infty} b^{1-p}$ depending on the sign of $(1 - p)$.
Case 1: $p = 1$
$$\int_1^\infty \frac{dx}{x} = \lim_{b\to\infty}\big[\ln x\big]_1^b = \lim_{b\to\infty} \ln b = +\infty \implies \textbf{Diverges}.$$
Case 2: $p \ne 1$
$$\int_1^\infty x^{-p}\,dx = \lim_{b\to\infty}\left[\frac{x^{1-p}}{1-p}\right]_1^b = \lim_{b\to\infty}\frac{b^{1-p} - 1}{1 - p}.$$ • If $p > 1$, then $1 - p < 0$, so $b^{1-p} \to 0$: Converges to $\dfrac{1}{p - 1}$.
• If $p < 1$, then $1 - p > 0$, so $b^{1-p} \to +\infty$: Diverges.
Class Notes • Log Singularity Type II • IBP + L'Hôpital
Evaluate $\displaystyle \int_0^1 \ln x\,dx$ using Integration by Parts and L'Hôpital's Rule.
Hint: $\ln x \to -\infty$ as $x \to 0^+$. Use $\int \ln x\,dx = x\ln x - x$, then resolve $\lim_{k\to 0^+} k\ln k$ by rewriting it as $\frac{\ln k}{1/k}$.
Step 1: Write as Type II limit and integrate via IBP
$$\int_0^1 \ln x\,dx = \lim_{k\to 0^+}\int_k^1 \ln x\,dx = \lim_{k\to 0^+}\big[x\ln x - x\big]_k^1 = \lim_{k\to 0^+}\big(-1 - k\ln k + k\big).$$
Step 2: Resolve $\lim_{k\to 0^+} k\ln k$ via L'Hôpital's Rule
$$\lim_{k\to 0^+} k\ln k = \lim_{k\to 0^+} \frac{\ln k}{1/k} \;\stackrel{\text{L'H}}{=}\; \lim_{k\to 0^+} \frac{1/k}{-1/k^2} = \lim_{k\to 0^+}(-k) = 0.$$ $$\therefore\; \int_0^1 \ln x\,dx = -1 - 0 + 0 = -1.$$
Class Notes • Multi-Asymptote Type II • Partial Fractions
Determine whether $\displaystyle \int_1^4 \frac{dx}{(x - 1)(x - 2)(x - 3)}$ converges or diverges using partial fractions.
Hint: There are vertical asymptotes at $x = 1, 2, 3$. Decompose into partial fractions and test just the first split $I_1 = \int_1^{1.5} f(x)\,dx$!
Step 1: Partial Fraction Decomposition
$$\frac{1}{(x-1)(x-2)(x-3)} = \frac{1/2}{x-1} - \frac{1}{x-2} + \frac{1/2}{x-3}.$$ Antiderivative: $F(x) = \frac{1}{2}\ln|x-1| - \ln|x-2| + \frac{1}{2}\ln|x-3|$.
Step 2: Test the first split $I_1 = \int_1^{1.5} f(x)\,dx$
$$I_1 = \lim_{k\to 1^+} \Big[F(1.5) - \big(\tfrac{1}{2}\ln(k-1) - \ln|k-2| + \tfrac{1}{2}\ln|k-3|\big)\Big].$$ As $k \to 1^+$, $\ln(k-1) \to -\infty$, so $-\frac{1}{2}\ln(k-1) \to +\infty$. Thus $I_1 = +\infty$.
Conclusion
Because one sub-integral diverges, the entire improper integral Diverges (no need to compute the remaining splits!).
Class Notes • Exponential Sub Mixed • $u$-Substitution
Evaluate $\displaystyle \int_0^\infty \frac{e^{-x}}{\sqrt{1 - e^{-x}}}\,dx$ via the substitution $u = 1 - e^{-x}$.
Hint: Set $u = 1 - e^{-x} \implies du = e^{-x}\,dx$. As $x \to 0^+$, $u \to 0^+$; as $x \to \infty$, $u \to 1^-$. You get a convergent Type II $p$-integral ($p = \frac{1}{2} < 1$)!
Step 1: Apply $u = 1 - e^{-x}$ and transform limits
$du = e^{-x}\,dx$. When $x = k \to 0^+$, $u = 1 - e^{-k} \to 0^+$. When $x = b \to \infty$, $u = 1 - e^{-b} \to 1^-$. $$\int_0^\infty \frac{e^{-x}}{\sqrt{1 - e^{-x}}}\,dx = \lim_{c\to 0^+}\int_c^1 u^{-1/2}\,du.$$
Step 2: Evaluate the limit
$$= \lim_{c\to 0^+}\big[2\sqrt{u}\big]_c^1 = 2(1) - \lim_{c\to 0^+} 2\sqrt{c} = 2.$$
