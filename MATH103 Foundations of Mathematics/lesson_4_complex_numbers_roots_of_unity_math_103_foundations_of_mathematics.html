Section 01

Complex Numbers, Conjugates & Field Properties

Definition 1.1 · Complex Number & Imaginary Unit

The imaginary unit is defined by $i = \sqrt{-1}$ (so $i^2 = -1$). A complex number $z \in \mathbb{C}$ is an expression of the form: $$z = a + bi \qquad (a, b \in \mathbb{R})$$ where $a = \operatorname{Re}(z)$ is the real part and $b = \operatorname{Im}(z)$ is the imaginary part. Every real number $a = a + 0i$ is a complex number, so $\mathbb{R} \subset \mathbb{C}$.

Complex Arithmetic ($z_1 = a+bi,\; z_2 = c+di$)

  • Addition/Subtraction: $(a \pm c) + (b \pm d)i$
  • Multiplication: $(ac - bd) + (ad + bc)i$
  • Multiplicative Inverse ($z \neq 0$): $$(a+bi)^{-1} = \frac{1}{a+bi} = \frac{a - bi}{a^2 + b^2}$$
  • Division: $\dfrac{z_1}{z_2} = \dfrac{z_1 \bar{z}_2}{z_2 \bar{z}_2} = \dfrac{(ac+bd) + (bc-ad)i}{c^2 + d^2}$

Complex Conjugate ($\bar{z} = a - bi$)

The complex conjugate of $z = a + bi$ is $\bar{z} = a - bi$ (obtained by reflecting across the real axis). Core identities:

• $z + \bar{z} = 2a = 2\operatorname{Re}(z)$
• $z - \bar{z} = 2bi = 2i\operatorname{Im}(z)$
• $z \cdot \bar{z} = a^2 + b^2 = |z|^2 \ge 0$  and  $\overline{\bar{z}} = z$

Let $z = a + bi$ and $w = c + di$ with $a, b, c, d \in \mathbb{R}$, so $\bar{z} = a - bi$ and $\bar{w} = c - di$.

1. Sum: $\overline{z + w} = \overline{(a+c) + (b+d)i} = (a+c) - (b+d)i = (a - bi) + (c - di) = \bar{z} + \bar{w}$.

2. Product: $\overline{zw} = \overline{(ac - bd) + (ad + bc)i} = (ac - bd) - (ad + bc)i$. Meanwhile, $\bar{z}\bar{w} = (a-bi)(c-di) = (ac - bd) - (ad + bc)i$. Thus $\overline{zw} = \bar{z}\bar{w}$.

3. Quotient ($w \neq 0$): Let $q = z/w$, so $z = qw$. Taking conjugates via property (2) gives $\bar{z} = \overline{qw} = \bar{q}\bar{w}$. Dividing by $\bar{w} \neq 0$ yields $\bar{q} = \bar{z}/\bar{w}$, i.e., $\overline{z/w} = \bar{z}/\bar{w}$. $\blacksquare$

The 9 Field Properties of $(\mathbb{C}, +, \times)$ (RJT Slides)

F1. Additive Closure: $z_1 + z_2 \in \mathbb{C}$
F2. Multiplicative Closure: $z_1 z_2 \in \mathbb{C}$
F3. Commutativity: $z_1+z_2=z_2+z_1$, $z_1z_2=z_2z_1$
F4. Associativity: $(z_1+z_2)+z_3 = z_1+(z_2+z_3)$ & same for $\times$
F5. Distributivity: $z_1(z_2+z_3) = z_1z_2 + z_1z_3$
F6. Additive Identity: $z + 0 = 0 + z = z$
F7. Multiplicative Identity: $z \cdot 1 = 1 \cdot z = z$
F8. Additive Inverse: $\exists (-z) \in \mathbb{C}$ s.t. $z + (-z) = 0$
F9. Multiplicative Inverse: $\forall z \neq 0,\; z \cdot z^{-1} = 1$
Section 02

Argand Plane, Modulus & Polar Form

On the Argand Plane (complex plane), every complex number $z = a + bi$ corresponds uniquely to the point $P(a, b)$ (and its conjugate $\bar{z} = a - bi$ is its reflection $(a, -b)$ across the horizontal real axis).

Modulus ($r = |z|$)

The Euclidean distance from the origin $O(0,0)$ to $P(a, b)$: $$r = |z| = \sqrt{a^2 + b^2} \ge 0$$

Argument / Amplitude ($\theta = \arg(z)$)

The directed angle from the positive real axis to ray $OP$. The Principal Argument $\operatorname{Arg}(z)$ lies in: $$-\pi < \theta \le \pi \qquad (-180^\circ < \theta \le 180^\circ)$$

⚠️

ISRT Exam Trap: Never Blindly Use $\tan^{-1}(b/a)$!

A calculator's $\tan^{-1}(b/a)$ only outputs angles in $(-\pi/2, \pi/2)$ (Quadrants I & IV). Always compute the acute reference angle $\alpha = \tan^{-1}\!\left(\left|\frac{b}{a}\right|\right)$ first, then apply the quadrant correction:

Quadrant Signs of $(a, b)$ Principal Argument $\theta \in (-\pi, \pi]$ Example
Q1 $a > 0,\; b > 0$ $\theta = \alpha$ $1 + i \implies \pi/4$
Q2 $a < 0,\; b > 0$ $\theta = \pi - \alpha$ $-1 + i \implies 3\pi/4$
Q3 $a < 0,\; b < 0$ $\theta = -(\pi - \alpha) = \alpha - \pi$ $-1 - i \implies -3\pi/4$
Q4 $a > 0,\; b < 0$ $\theta = -\alpha$ $3 - 2i \implies -\tan^{-1}(2/3)$

Polar & Exponential Form

Since $a = r\cos\theta$ and $b = r\sin\theta$, any nonzero complex number $z = a + bi$ can be written as: $$z = r(\cos\theta + i\sin\theta) = re^{i\theta}$$

Write $z_1 = r_1(\cos\theta_1 + i\sin\theta_1)$ and $z_2 = r_2(\cos\theta_2 + i\sin\theta_2)$.

1. Product: Expanding $z_1 z_2$ gives: $$z_1 z_2 = r_1 r_2\big[(\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2) + i(\sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2)\big] = r_1 r_2\big[\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)\big]$$ Hence $|z_1 z_2| = r_1 r_2$ and $\arg(z_1 z_2) = \theta_1 + \theta_2 = \arg(z_1) + \arg(z_2)$.

2. Quotient ($z_2 \neq 0$): Multiplying numerator and denominator by $(\cos\theta_2 - i\sin\theta_2)$: $$\frac{z_1}{z_2} = \frac{r_1}{r_2}\frac{(\cos\theta_1+i\sin\theta_1)(\cos\theta_2-i\sin\theta_2)}{\cos^2\theta_2 + \sin^2\theta_2} = \frac{r_1}{r_2}\big[\cos(\theta_1-\theta_2) + i\sin(\theta_1-\theta_2)\big]$$ Hence $\arg(z_1 / z_2) = \theta_1 - \theta_2 = \arg(z_1) - \arg(z_2)$. $\blacksquare$

Section 03

Modulus Theorems, Triangle Inequality & Complex Loci

(i) Product Modulus: Using $|w|^2 = w\bar{w}$, we have $|z_1 z_2|^2 = (z_1 z_2)\overline{(z_1 z_2)} = (z_1 \bar{z}_1)(z_2 \bar{z}_2) = |z_1|^2 |z_2|^2$. Taking non-negative square roots yields $|z_1 z_2| = |z_1||z_2|$.

(ii) Triangle Inequality: Expand $|z_1 + z_2|^2$: $$|z_1 + z_2|^2 = (z_1 + z_2)(\bar{z}_1 + \bar{z}_2) = |z_1|^2 + (z_1\bar{z}_2 + \bar{z}_1 z_2) + |z_2|^2 = |z_1|^2 + 2\operatorname{Re}(z_1\bar{z}_2) + |z_2|^2$$ Since $\operatorname{Re}(w) \le |w|$ for any $w \in \mathbb{C}$, we have $\operatorname{Re}(z_1 \bar{z}_2) \le |z_1 \bar{z}_2| = |z_1||\bar{z}_2| = |z_1||z_2|$. Thus: $$|z_1 + z_2|^2 \le |z_1|^2 + 2|z_1||z_2| + |z_2|^2 = (|z_1| + |z_2|)^2 \implies |z_1 + z_2| \le |z_1| + |z_2|$$

(iii) Reverse Triangle Inequality: Write $z_1 = (z_1 - z_2) + z_2$. By (ii), $|z_1| \le |z_1 - z_2| + |z_2| \implies |z_1 - z_2| \ge |z_1| - |z_2|$. Swapping $z_1, z_2$ gives $|z_1 - z_2| \ge |z_2| - |z_1|$. Combining both gives $|z_1 - z_2| \ge \big||z_1| - |z_2|\big|$. $\blacksquare$

Using $|w|^2 = w\bar{w}$:

$|z_1 + z_2|^2 = (z_1 + z_2)(\bar{z}_1 + \bar{z}_2) = |z_1|^2 + z_1\bar{z}_2 + \bar{z}_1 z_2 + |z_2|^2$

$|z_1 - z_2|^2 = (z_1 - z_2)(\bar{z}_1 - \bar{z}_2) = |z_1|^2 - z_1\bar{z}_2 - \bar{z}_1 z_2 + |z_2|^2$

Adding the two equations cancels the cross-terms $\pm(z_1\bar{z}_2 + \bar{z}_1 z_2)$, leaving $|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2(|z_1|^2 + |z_2|^2)$. $\blacksquare$

CIRCLE
$|z - z_0| = R$

All points at distance $R$ from center $z_0 = (x_0, y_0)$.

PERPENDICULAR BISECTOR
$|z - z_1| = |z - z_2|$

Straight line equidistant from $z_1$ and $z_2$ (when $k = m$).

APOLLONIUS CIRCLE (RJT Ex. 6)
$k|z - z_1| = m|z - z_2|\; (k \neq m)$

Example: $3|z-1| = 2|z-2| \implies 5(x^2+y^2) = 2x + 7$.

Square Roots of Complex Numbers

Theorem 4.1 · Closure Under Square Roots

The square root of any complex number $z = a + ib$ ($a, b \in \mathbb{R}$) is also a complex number $x + iy$ ($x, y \in \mathbb{R}$), given explicitly by:

$$\sqrt{a \pm ib} = \pm \frac{1}{\sqrt{2}}\left[\sqrt{\sqrt{a^2+b^2}+a} \;\pm\; i\sqrt{\sqrt{a^2+b^2}-a}\right]$$

Sign-Matching Rule ($2xy = b$): If $b > 0$, then $x$ and $y$ have the same sign ($+$ with $+$, $-$ with $-$). If $b < 0$, then $x$ and $y$ have opposite signs ($+$ with $-$, $-$ with $+$).

Step 1: Suppose $\sqrt{a + ib} = x + iy$ where $x, y \in \mathbb{R}$. Squaring both sides gives $a + ib = (x^2 - y^2) + i(2xy)$.

Step 2: Equating real and imaginary parts: $$x^2 - y^2 = a \quad \text{(1)}, \qquad 2xy = b \quad \text{(2)}$$

Step 3: Use the identity $(x^2 + y^2)^2 = (x^2 - y^2)^2 + (2xy)^2 = a^2 + b^2$. Since $x^2 + y^2 \ge 0$, taking the positive square root yields: $$x^2 + y^2 = \sqrt{a^2 + b^2} \quad \text{(3)}$$

Step 4: Add (3) and (1), and subtract (1) from (3): $$2x^2 = \sqrt{a^2 + b^2} + a \implies x = \pm\sqrt{\frac{\sqrt{a^2+b^2}+a}{2}}, \qquad 2y^2 = \sqrt{a^2 + b^2} - a \implies y = \pm\sqrt{\frac{\sqrt{a^2+b^2}-a}{2}}$$ Since $\sqrt{a^2+b^2} \ge |a|$, both expressions inside the radicals are $\ge 0$, proving $x, y \in \mathbb{R}$!

Step 5 (Pairing Signs): From (2), $2xy = b$. If $b > 0$, $x$ and $y$ share the same sign; if $b < 0$, $x$ and $y$ have opposite signs. Thus $\sqrt{a \pm ib} = \pm\frac{1}{\sqrt{2}}\left[\sqrt{\sqrt{a^2+b^2}+a} \pm i\sqrt{\sqrt{a^2+b^2}-a}\right] \in \mathbb{C}$. $\blacksquare$

Section 05

De Moivre's Theorem & Powers of Complex Numbers

Theorem 5.1 · De Moivre's Theorem

For every integer $n \in \mathbb{Z}$ and every real angle $\theta$: $$(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)$$ More generally, for $z = r(\cos\theta + i\sin\theta) = re^{i\theta}$, we have $z^n = r^n\big[\cos(n\theta) + i\sin(n\theta)\big] = r^n e^{in\theta}$.

Geometric Interpretation: Raising $z$ to the $n$-th power scales its distance from the origin to $r^n$ and rotates its ray counterclockwise by angle $n\theta$.

Worked Example (RJT Exercise 7): Powers of $\rho = \dfrac{1}{\sqrt{2}} + \dfrac{1}{\sqrt{2}}i$

Unit Circle Rotation

First convert $\rho$ to polar form: $r = \sqrt{\left(\frac{1}{\sqrt{2}}\right)^2 + \left(\frac{1}{\sqrt{2}}\right)^2} = 1$, and $\theta = \tan^{-1}(1) = \frac{\pi}{4}$ (Q1). Thus $\rho = \cos\frac{\pi}{4} + i\sin\frac{\pi}{4} = e^{i\pi/4}$.

$\rho^2 = e^{i\pi/2}$
$= i$
$\rho^3 = e^{i3\pi/4}$
$= -\frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}}i$
$\rho^4 = e^{i\pi}$
$= -1$
$\rho^{25} = (\rho^8)^3 \cdot \rho$
$= 1^3 \cdot \rho = \rho$

Cube Roots of Unity ($1, \omega, \omega^2$) & Algebraic Identities

Solving $x^3 = 1 \iff x^3 - 1 = 0 \iff (x - 1)(x^2 + x + 1) = 0$ gives three cube roots of unity, forming the vertices of an equilateral triangle inscribed in the unit circle $|z| = 1$: $$x = 1, \qquad \omega = \frac{-1 + i\sqrt{3}}{2} = e^{i 2\pi/3}, \qquad \omega^2 = \frac{-1 - i\sqrt{3}}{2} = e^{i 4\pi/3} = e^{-i 2\pi/3}$$

CUBIC CYCLE
$\omega^3 = 1$

$\omega^{3k+r} = \omega^r$

ZERO SUM
$1 + \omega + \omega^2 = 0$

Any 3 consecutive powers sum to $0$

CONJUGATE PAIR
$\bar{\omega} = \omega^2 = \omega^{-1}$

Each imaginary root is the square of the other

FACTORIZATION TRICK
$p^3 + q^3 = (p+q)(p+q\omega)(p+q\omega^2)$

ISRT 2nd Incourse 2024 · AST 103, Q2 [1 + 2 + 2 Marks]

1. Consider an Argand diagram showing point $P(3, -2)$ in Quadrant IV. (a) Represent point $P$ as a complex number $z$. (b) Find the modulus and principal argument of $z$. (c) Divide $z$ by $(1 - 2i)$.

Hint: $P(3, -2)$ lies in Q4, so $\theta = -\tan^{-1}(2/3)$. For division, multiply numerator and denominator by the conjugate $(1 + 2i)$.

(a) $z = 3 - 2i$.

(b) Modulus: $|z| = \sqrt{3^2 + (-2)^2} = \sqrt{9 + 4} = \sqrt{13}$. Since $(3, -2)$ is in Quadrant IV, the principal argument is $\theta = -\tan^{-1}\!\left(\frac{2}{3}\right) \approx -0.5880\text{ rad} \approx -33.69^\circ$.

(c) Multiply top and bottom by $\overline{1 - 2i} = 1 + 2i$: $$\frac{3 - 2i}{1 - 2i} = \frac{(3 - 2i)(1 + 2i)}{1^2 + (-2)^2} = \frac{3 + 6i - 2i - 4i^2}{1 + 4} = \frac{7 + 4i}{5} = \mathbf{\frac{7}{5} + \frac{4}{5}i}$$

ISRT Final 2020, 2024 & 2025 · MATH 103, Q2 [2 + 4 Marks]

2. Define modulus and argument of a complex number. If $a + b + c = 0$ and $\omega$ is an imaginary cube root of unity, prove that $(a + b\omega + c\omega^2)^3 + (a + b\omega^2 + c\omega)^3 = 27abc$.

Hint: Set $p = a + b\omega + c\omega^2$ and $q = a + b\omega^2 + c\omega$. Factor $p^3 + q^3 = (p+q)(p+q\omega)(p+q\omega^2)$ and use $1 + \omega + \omega^2 = 0$ together with $a + b + c = 0$!

Definitions: For $z = x + iy$, modulus is $|z| = \sqrt{x^2 + y^2}$ and argument is the angle $\theta$ that the ray from $(0,0)$ to $(x,y)$ makes with the positive real axis.

Proof: Let $p = a + b\omega + c\omega^2$ and $q = a + b\omega^2 + c\omega$. Recall $p^3 + q^3 = (p+q)(p+q\omega)(p+q\omega^2)$.

• $p + q = 2a + (b+c)(\omega + \omega^2) = 2a - (b+c) = 2a - (-a) = 3a$ (since $\omega+\omega^2 = -1$ and $b+c = -a$).

• $p + q\omega = a(1+\omega) + b(\omega+\omega^3) + c(\omega^2+\omega^2) = a(-\omega^2) + b(\omega+1) + 2c\omega^2 = -a\omega^2 - b\omega^2 + 2c\omega^2 = \omega^2(2c - a - b) = 3c\omega^2$.

• $p + q\omega^2 = a(1+\omega^2) + 2b\omega + c(\omega^2+\omega^4) = -a\omega + 2b\omega - c\omega = \omega(2b - a - c) = 3b\omega$.

Multiplying all three factors: $p^3 + q^3 = (3a)(3c\omega^2)(3b\omega) = 27abc\omega^3 = 27abc$. $\blacksquare$

ISRT Final 2019 (AST 104, Q3a) & 2023 (MATH 103, Q4d) [3–6 Marks]

3. Define complex conjugate. Show that the square root of a complex number is also a complex number.

Hint: Set $\sqrt{a+ib} = x+iy$, square both sides to get $x^2-y^2=a$ and $2xy=b$, find $x^2+y^2=\sqrt{a^2+b^2}$, and show $x, y \in \mathbb{R}$.

Complex Conjugate: For $z = a + ib$ ($a,b \in \mathbb{R}$), its conjugate is $\bar{z} = a - ib$.

Proof: Let $\sqrt{a+ib} = x + iy$. Squaring gives $x^2 - y^2 = a$ and $2xy = b$. Then $(x^2+y^2)^2 = (x^2-y^2)^2 + 4x^2y^2 = a^2 + b^2 \implies x^2+y^2 = \sqrt{a^2+b^2}$.

Solving yields $x = \pm\sqrt{\frac{\sqrt{a^2+b^2}+a}{2}}$ and $y = \pm\sqrt{\frac{\sqrt{a^2+b^2}-a}{2}}$. Since $\sqrt{a^2+b^2} \ge |a|$, both $x$ and $y$ are real numbers (with signs matched according to $2xy = b$). Hence $\sqrt{a+ib} = x + iy \in \mathbb{C}$. $\blacksquare$

RJT Lecture Slides · Example 5 [Core Proof]

4. Prove the Parallelogram Law for any two complex numbers $z_1, z_2 \in \mathbb{C}$: $|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2(|z_1|^2 + |z_2|^2)$.

Hint: Expand both $|z_1 + z_2|^2 = (z_1+z_2)(\bar{z}_1+\bar{z}_2)$ and $|z_1 - z_2|^2 = (z_1-z_2)(\bar{z}_1-\bar{z}_2)$, then add them.

$|z_1 + z_2|^2 + |z_1 - z_2|^2 = (z_1 + z_2)(\bar{z}_1 + \bar{z}_2) + (z_1 - z_2)(\bar{z}_1 - \bar{z}_2)$

$= (z_1\bar{z}_1 + z_1\bar{z}_2 + z_2\bar{z}_1 + z_2\bar{z}_2) + (z_1\bar{z}_1 - z_1\bar{z}_2 - z_2\bar{z}_1 + z_2\bar{z}_2)$

$= 2z_1\bar{z}_1 + 2z_2\bar{z}_2 = 2(|z_1|^2 + |z_2|^2)$. $\blacksquare$

RJT Lecture Slides · Example 6 [Complex Locus]

5. If $z = x + iy$ and $3|z - 1| = 2|z - 2|$, prove that $5(x^2 + y^2) = 2x + 7$.

Hint: Substitute $z = x + iy$, square both sides to remove the square roots, and collect like terms.

Substituting $z = x + iy$: $3|(x - 1) + iy| = 2|(x - 2) + iy|$.

Squaring both sides: $9\big[(x - 1)^2 + y^2\big] = 4\big[(x - 2)^2 + y^2\big]$.

Expanding: $9(x^2 - 2x + 1 + y^2) = 4(x^2 - 4x + 4 + y^2) \implies 9x^2 - 18x + 9 + 9y^2 = 4x^2 - 16x + 16 + 4y^2$.

Rearranging terms: $5x^2 + 5y^2 = 2x + 7 \implies 5(x^2 + y^2) = 2x + 7$. $\blacksquare$

RJT Lecture Slides · Example 7 & Exercise 7 [Polar & De Moivre]

6. (a) Express $1 + i\sqrt{3}$ in polar form $r(\cos\theta + i\sin\theta)$.  (b) For $\rho = \dfrac{1}{\sqrt{2}} + \dfrac{1}{\sqrt{2}}i$, compute $\rho^2, \rho^3, \rho^4$, and $\rho^{25}$.

Hint: In (a), $r = \sqrt{1+3}=2$ and $\theta = \pi/3$. In (b), $\rho = e^{i\pi/4}$, so $\rho^8 = e^{i2\pi} = 1$, making $\rho^{25} = (\rho^8)^3 \rho$.

(a) For $1 + i\sqrt{3}$ (Q1): $r = \sqrt{1^2 + (\sqrt{3})^2} = 2$ and $\theta = \tan^{-1}(\sqrt{3}) = \frac{\pi}{3}$. Thus $1 + i\sqrt{3} = \mathbf{2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right)}$.

(b) $\rho = \cos\frac{\pi}{4} + i\sin\frac{\pi}{4}$. By De Moivre's Theorem:

• $\rho^2 = \cos\frac{\pi}{2} + i\sin\frac{\pi}{2} = \mathbf{i}$  |  • $\rho^3 = \cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4} = \mathbf{-\frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}}i}$  |  • $\rho^4 = \cos\pi + i\sin\pi = \mathbf{-1}$.

• $\rho^{25} = \cos\frac{25\pi}{4} + i\sin\frac{25\pi}{4} = \cos\left(6\pi + \frac{\pi}{4}\right) + i\sin\left(6\pi + \frac{\pi}{4}\right) = \frac{1}{\sqrt{2}} + \frac{1}{\sqrt{2}}i = \rho$.
