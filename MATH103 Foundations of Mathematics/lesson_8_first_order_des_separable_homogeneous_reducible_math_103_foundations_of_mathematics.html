Section 8.1 ISRT Final 2020 Q7(b) — 6 Marks

Geometric Interpretation & Direction (Slope) Fields

Reading…

Consider a general first-order, first-degree ordinary differential equation written in normal form: $$\frac{dy}{dx} = f(x, y)$$ Even before solving the equation analytically, it carries a rich geometric meaning in the $xy$-plane:

1. Lineal Elements & Direction Field

At every point $(x, y)$ where $f(x, y)$ is defined, the equation prescribes a numerical slope $m = f(x, y)$. Drawing a tiny line segment of slope $m$ centered at $(x, y)$ creates a lineal element; the collection of all such segments across the plane is the direction field (slope field).

2. Integral Curves & One-Parameter Family

A solution $y = \phi(x)$ is a smooth curve whose tangent line at every point $(x, \phi(x))$ aligns with the lineal element there. The general solution $F(x, y, C) = 0$ represents a one-parameter family of integral curves filling the plane.

3. Initial Condition $y(x_0) = y_0$

Geometrically, specifying an initial condition $y(x_0) = y_0$ pins down a single point $(x_0, y_0)$ and selects the unique integral curve from the family that passes through $(x_0, y_0)$ (provided $f$ and $\partial f/\partial y$ are continuous nearby).

4. Isoclines ($f(x, y) = k$)

An isocline (literally "equal slope") is the curve $f(x, y) = k$ along which every lineal element has the exact same constant slope $k$. Setting $k = 0$ gives the nullcline (where integral curves have horizontal tangents).

  1. Write Standard Form (1 mark): State $\frac{dy}{dx} = f(x, y)$ and identify $\frac{dy}{dx} = m$ as the slope of the tangent to a solution curve at $(x, y)$.
  2. Define Lineal Element & Direction Field (1.5 marks): Explain how attaching a short segment of slope $f(x,y)$ at grid points builds the direction field.
  3. Explain Integral Curves & One-Parameter Family (1.5 marks): State that any solution curve is everywhere tangent to the field, and the general solution $F(x, y, C) = 0$ forms a 1-parameter family of non-intersecting curves (where regular).
  4. Role of Initial Condition & Isoclines (1 mark): Explain how $y(x_0) = y_0$ picks one particular curve, and define isoclines $f(x,y) = k$ as a sketching aid.
  5. Include a Clean Sketch (1 mark): Draw a quick labeled diagram (e.g., $\frac{dy}{dx} = -\frac{x}{y}$ producing concentric circles $x^2 + y^2 = C$, or $\frac{dy}{dx} = \frac{y}{x}$ producing rays $y = Cx$)!

Section 8.2

Variable Separable Differential Equations

Reading…

Standard Form & Integration Recipe

A first-order ODE is variable separable if it can be rearranged into either: $$M(x)\,dx + N(y)\,dy = 0 \qquad \text{or} \qquad \frac{dy}{dx} = g(x)\,h(y)$$ Separating $y$ terms onto the left and $x$ terms onto the right and integrating both sides gives the general solution: $$\int \frac{dy}{h(y)} = \int g(x)\,dx + C$$

💡 The Log-Constant Trick

Whenever all integrated terms contain logarithms (e.g., $\ln|y| + \ln|x|$), write the arbitrary constant as $\ln C$ (or $\frac{1}{2}\ln C$) instead of $C$ so you can collapse logs cleanly via $\ln A + \ln B = \ln(AB)$!

⚠️ Trap: Lost Singular Solutions ($h(y) = 0$)

Dividing $\frac{dy}{dx} = g(x)h(y)$ by $h(y)$ implicitly assumes $h(y) \neq 0$. Always check whether any constant root $y = y_0$ of $h(y) = 0$ is a valid solution not already captured by the general formula!

Worked Example (ISRT 1st Incourse 2022 & 2024): $x(1 + y^2)\,dx + y(1 + x^2)\,dy = 0$

Separable

Step 1 (Separate): Since $(1+x^2)(1+y^2) > 0$ everywhere on $\mathbb{R}$, divide through by $(1+x^2)(1+y^2)$: $$\frac{x}{1 + x^2}\,dx + \frac{y}{1 + y^2}\,dy = 0$$

Step 2 (Integrate with Log-Constant): Multiply by $2$ and integrate term-by-term: $$\int \frac{2x}{1 + x^2}\,dx + \int \frac{2y}{1 + y^2}\,dy = \ln C \implies \ln(1 + x^2) + \ln(1 + y^2) = \ln C$$

Step 3 (Simplify): $\ln\big[(1 + x^2)(1 + y^2)\big] = \ln C \implies \mathbf{(1 + x^2)(1 + y^2) = C}$. $\blacksquare$

Section 8.3

Equations Reducible to Variable Separable (Linear Substitutions)

Reading…

If an equation is not directly separable, but $x$ and $y$ appear strictly inside a single linear combination $ax + by + c$, i.e., $$\frac{dy}{dx} = f(ax + by + c)$$ set $z = ax + by + c$. Differentiating with respect to $x$ gives $\dfrac{dz}{dx} = a + b\dfrac{dy}{dx} = a + b\,f(z)$, which is always variable separable in $z$ and $x$!

Worked Example: Solve $\dfrac{dy}{dx} = (x + y + 1)^2$

Substitution $z = x + y + 1$

1. Substitute: Let $z = x + y + 1 \implies \dfrac{dz}{dx} = 1 + \dfrac{dy}{dx} \implies \dfrac{dy}{dx} = \dfrac{dz}{dx} - 1$.

2. Separate & Integrate: $\dfrac{dz}{dx} - 1 = z^2 \implies \dfrac{dz}{1 + z^2} = dx \implies \tan^{-1}(z) = x + C$.

3. Back-Substitute: $z = \tan(x + C) \implies \mathbf{x + y + 1 = \tan(x + C)}$ (or $y = \tan(x + C) - x - 1$). $\blacksquare$

Section 8.4

Homogeneous Differential Equations

Reading…
Homogeneous Function of Degree $n$

A function $f(x, y)$ is homogeneous of degree $n$ if for every $t > 0$: $$f(tx, ty) = t^n f(x, y)$$

Homogeneous First-Order DE

$M(x, y)\,dx + N(x, y)\,dy = 0$ is homogeneous if both $M$ and $N$ are homogeneous functions of the exact same degree $n$ (equivalently $\frac{dy}{dx} = \phi(y/x)$).

Since $M(x, y)$ and $N(x, y)$ are both homogeneous of degree $n$, factor out $x^n$ using $t = 1/x$: $$M(x, y) = x^n M\!\left(1, \frac{y}{x}\right), \qquad N(x, y) = x^n N\!\left(1, \frac{y}{x}\right)$$

Thus $\dfrac{dy}{dx} = -\dfrac{M(x,y)}{N(x,y)} = -\dfrac{M(1, y/x)}{N(1, y/x)} = \phi\!\left(\dfrac{y}{x}\right)$.

Now set $y = vx$ (so $v = y/x$). Differentiating by the product rule gives $\dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$. Substituting into $\frac{dy}{dx} = \phi(v)$:

$$v + x\frac{dv}{dx} = \phi(v) \implies x\frac{dv}{dx} = \phi(v) - v \implies \frac{dx}{x} = \frac{dv}{\phi(v) - v} \quad \blacksquare$$
⚠️

Two Smart Exam Tricks for Homogeneous DEs

1. When to use $x = vy$ instead of $y = vx$: If $M(x,y)$ has fewer terms than $N(x,y)$ or the equation contains expressions like $e^{x/y}$ or $\cos(x/y)$, substitute $x = vy$ (so $dx = v\,dy + y\,dv$) to avoid messy integrals!

2. Watch $\sqrt{x^2} = |x|$: In problems like ISRT 2020 Q6(a-ii) with $\sqrt{x^2 + 4y^2}$, factoring out $x^2$ gives $|x|\sqrt{1 + 4v^2}$ (which equals $x\sqrt{1 + 4v^2}$ for $x > 0$).

Equations Reducible to Homogeneous Form (Non-Homogeneous Linear Fractional)

Reading…

Consider a non-homogeneous first-order equation with linear numerator and denominator: $$\frac{dy}{dx} = \frac{a_1 x + b_1 y + c_1}{a_2 x + b_2 y + c_2}$$ The constants $c_1, c_2$ break homogeneity! To solve it, compute the determinant $\Delta = a_1 b_2 - a_2 b_1$, which splits the problem into two mutually exclusive geometric cases:

Case 1 · Intersecting Lines $\Delta = a_1 b_2 - a_2 b_1 \neq 0$

The two lines $L_1: a_1 x + b_1 y + c_1 = 0$ and $L_2: a_2 x + b_2 y + c_2 = 0$ intersect at a unique point $(h, k)$.

  1. Solve $a_1 h + b_1 k + c_1 = 0$ and $a_2 h + b_2 k + c_2 = 0$ for $(h, k)$.
  2. Shift the origin: $x = X + h$, $y = Y + k$ (so $dx = dX$, $dy = dY$).
  3. Constants cancel, yielding a homogeneous DE: $$\frac{dY}{dX} = \frac{a_1 X + b_1 Y}{a_2 X + b_2 Y}$$
  4. Solve via $Y = vX$, then substitute back $X = x - h$, $Y = y - k$.
Case 2 · Parallel Lines $\Delta = a_1 b_2 - a_2 b_1 = 0$

Since $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \lambda$, the lines are parallel—no finite intersection $(h, k)$ exists!

  1. Factor out the common linear part $a_1 x + b_1 y$ (so $a_2 x + b_2 y = \frac{1}{\lambda}(a_1 x + b_1 y)$).
  2. Substitute $z = a_1 x + b_1 y$ directly (as in Section 8.3).
  3. Differentiate: $\dfrac{dz}{dx} = a_1 + b_1\dfrac{dy}{dx}$, which immediately yields a variable separable equation in $z$ and $x$!

ISRT 1st Incourse 2022 Q3(a) & 2024 Q2(b) [2.5 Marks]

1. Solve the differential equation: $x(1 + y^2)\,dx + y(1 + x^2)\,dy = 0$.

Hint: Divide both sides by $(1 + x^2)(1 + y^2)$, multiply by $2$, and integrate using $\int \frac{f'(u)}{f(u)}\,du = \ln|f(u)|$.

Dividing by $(1 + x^2)(1 + y^2) > 0$: $\dfrac{x}{1 + x^2}\,dx + \dfrac{y}{1 + y^2}\,dy = 0$.

Multiplying by $2$ and integrating: $\int \dfrac{2x}{1 + x^2}\,dx + \int \dfrac{2y}{1 + y^2}\,dy = \ln C \implies \ln(1 + x^2) + \ln(1 + y^2) = \ln C$.

Answer: $(1 + x^2)(1 + y^2) = C$. $\blacksquare$

ISRT 1st Incourse 2022 Q3(b) & 2024 Q2(a) [2.5 Marks]

2. Solve the homogeneous differential equation: $(x^2 + y^2)\,dx - 2xy\,dy = 0$.

Hint: Rewrite as $\frac{dy}{dx} = \frac{x^2 + y^2}{2xy}$, substitute $y = vx$, and simplify $x\frac{dv}{dx} = \frac{1 - v^2}{2v}$.

Rewrite as $\dfrac{dy}{dx} = \dfrac{x^2 + y^2}{2xy}$ (homogeneous of degree $2$). Put $y = vx \implies \dfrac{dy}{dx} = v + x\dfrac{dv}{dx}$:

$$v + x\frac{dv}{dx} = \frac{1 + v^2}{2v} \implies x\frac{dv}{dx} = \frac{1 - v^2}{2v} \implies \frac{2v}{1 - v^2}\,dv = \frac{dx}{x}$$

Integrating: $-\ln|1 - v^2| = \ln|x| - \ln|C| \implies x(1 - v^2) = C$. Substituting $v = y/x$ gives $x\left(1 - \frac{y^2}{x^2}\right) = C$.

Answer: $x^2 - y^2 = Cx$. $\blacksquare$

ISRT Final 2020 · Q6(a-ii) [4 Marks]

3. Solve: $2x\,dy - 2y\,dx - \sqrt{x^2 + 4y^2}\,dx = 0$.

Hint: Put $y = vx$ (homogeneous of degree $1$). The $v$ terms cancel, leaving $\frac{2\,dv}{\sqrt{1 + (2v)^2}} = \frac{dx}{x}$; recall $\int \frac{du}{\sqrt{1+u^2}} = \ln|u + \sqrt{1+u^2}|$.

Rewrite as $\dfrac{dy}{dx} = \dfrac{2y + \sqrt{x^2 + 4y^2}}{2x}$. Put $y = vx$ ($x > 0$ so $\sqrt{x^2} = x$):

$$v + x\frac{dv}{dx} = \frac{2vx + x\sqrt{1 + 4v^2}}{2x} = v + \frac{\sqrt{1 + 4v^2}}{2} \implies \frac{2\,dv}{\sqrt{1 + (2v)^2}} = \frac{dx}{x}$$

Let $u = 2v \implies du = 2\,dv$. Integrating gives $\ln\left|2v + \sqrt{1 + 4v^2}\right| = \ln|x| + \ln C \implies 2v + \sqrt{1 + 4v^2} = Cx$.

Substituting $v = y/x$: $\dfrac{2y}{x} + \dfrac{\sqrt{x^2 + 4y^2}}{x} = Cx$.

Answer: $2y + \sqrt{x^2 + 4y^2} = Cx^2$. $\blacksquare$

ISRT 1st Incourse 2022 Q4(b), 2024 Q3(b) & 2025 Q5 (Triple Repeat!) [4 Marks]

4. Solve $2(x + y - 1)\,dx = (3x + y - 5)\,dy$ by reducible to homogeneous form.

Hint: Shift $x = X + 2$, $y = Y - 1$ to get $\frac{dY}{dX} = \frac{2X + 2Y}{3X + Y}$. Put $Y = vX$ and use partial fractions $\frac{v+3}{(v+2)(v-1)} = \frac{4/3}{v-1} - \frac{1/3}{v+2}$.

Step 1 (Shift Origin): Rewrite as $\dfrac{dy}{dx} = \dfrac{2x + 2y - 2}{3x + y - 5}$. Solving $2h + 2k - 2 = 0$ and $3h + k - 5 = 0$ gives $h = 2, k = -1$. Set $x = X + 2,\; y = Y - 1$: $$\frac{dY}{dX} = \frac{2X + 2Y}{3X + Y}$$

Step 2 (Homogeneous Substitution $Y = vX$): $$v + X\frac{dv}{dX} = \frac{2 + 2v}{3 + v} \implies X\frac{dv}{dX} = \frac{2 - v - v^2}{3 + v} = -\frac{(v + 2)(v - 1)}{v + 3} \implies \frac{v + 3}{(v + 2)(v - 1)}\,dv = -\frac{dX}{X}$$

Step 3 (Partial Fractions & Integrate): $\left(\dfrac{4/3}{v - 1} - \dfrac{1/3}{v + 2}\right)dv = -\dfrac{dX}{X} \implies 4\ln|v - 1| - \ln|v + 2| = -3\ln|X| + \ln C$.

Combining logs: $\dfrac{X^3(v - 1)^4}{v + 2} = C \implies \dfrac{X^4(v - 1)^4}{X(v + 2)} = C \implies \dfrac{(Y - X)^4}{Y + 2X} = C$.

Step 4 (Back-Substitute $X = x - 2,\; Y = y + 1$): $(y - x + 3)^4 = C(2x + y - 3)$. $\blacksquare$

ISRT Final 2020 · Q6(a-iii) [4 Marks]

5. Solve: $(2x + y + 3)\,dy = (x + 2y + 3)\,dx$.

Hint: Intersection of $x + 2y + 3 = 0$ and $2x + y + 3 = 0$ is $h = -1, k = -1$. Shift $x = X - 1, y = Y - 1$, then put $Y = vX$.

Step 1 (Shift): $\dfrac{dy}{dx} = \dfrac{x + 2y + 3}{2x + y + 3}$. Solving $h + 2k + 3 = 0$ and $2h + k + 3 = 0$ yields $h = -1, k = -1$. Set $x = X - 1,\; y = Y - 1$: $$\frac{dY}{dX} = \frac{X + 2Y}{2X + Y}$$

Step 2 (Put $Y = vX$): $v + X\dfrac{dv}{dX} = \dfrac{1 + 2v}{2 + v} \implies X\dfrac{dv}{dX} = \dfrac{1 - v^2}{2 + v} \implies \dfrac{2 + v}{(1 - v)(1 + v)}\,dv = \dfrac{dX}{X}$.

Step 3 (Partial Fractions): $\left(\dfrac{3/2}{1 - v} + \dfrac{1/2}{1 + v}\right)dv = \dfrac{dX}{X} \implies -3\ln|1 - v| + \ln|1 + v| = 2\ln|X| + \ln C$.

Thus $\dfrac{1 + v}{(1 - v)^3} = CX^2 \implies \dfrac{X(1 + v)}{X^3(1 - v)^3} = C \implies X + Y = C(X - Y)^3$.

Step 4 (Back-Substitute $X = x + 1,\; Y = y + 1$): $x + y + 2 = C(x - y)^3$. $\blacksquare$

ISRT Final 2020 · Q7(b) [6 Marks]

6. Briefly explain the geometric interpretation of a first-order differential equation.

Hint: Hit all 5 keywords: lineal element, direction/slope field, integral curves & 1-parameter family, isoclines $f(x,y)=k$, and unique IVP curve through $(x_0, y_0)$.

A first-order DE $\frac{dy}{dx} = f(x, y)$ assigns to each regular point $(x, y)$ in the plane a specific tangent slope $m = f(x, y)$. Drawing a tiny line segment of slope $m$ at each point produces a lineal element, and the entire array of segments forms the direction field (slope field).

Curves of constant slope $f(x, y) = k$ are called isoclines and help sketch the field. Any solution $y = \phi(x)$ is an integral curve that is everywhere tangent to the lineal elements it passes through.

The general solution $F(x, y, C) = 0$ represents a one-parameter family of integral curves. Imposing an initial condition $y(x_0) = y_0$ selects the unique curve in this family passing through $(x_0, y_0)$ (for example, $\frac{dy}{dx} = -\frac{x}{y}$ generates the concentric circle family $x^2 + y^2 = C$, and $(3, 4)$ selects the single circle $x^2 + y^2 = 25$). $\blacksquare$
