Section 01

Spearman's Rank Correlation Coefficient (rs)

Pearson's r requires numerical data and assumes a linear relationship. When characteristics are qualitative/unmeasurable (honesty, beauty, voice, taste) but individuals can be ordered by merit—or when variables are measurable but a linear relationship cannot be assumed—we use Spearman's Rank Correlation Coefficient (rs), a non-parametric measure of similarity between two rankings.

3 Valid Situations
  1. Both variables are quantitative.
  2. Both variables are qualitative ordinal.
  3. One is quantitative and the other is qualitative ordinal (e.g., Income vs. Education Level).
Merits
  • Same [−1, +1] interpretation as Pearson's r.
  • Easy to understand & compute for small n.
  • No linearity or normality assumptions required.
  • Works on ordinal/qualitative rankings.
Demerits
  • Cannot be computed from a grouped bivariate frequency table (unlike Pearson's r).
  • Becomes time-consuming to rank by hand when n is large.
rs = 1 − [ 6 Σ di² ] / [ n(n² − 1) ],    where   di = R(xi) − R(yi)

Interpretation: rs = +1 means perfect agreement (identical rankings); rs = 0 means completely independent rankings; rs = −1 means perfect disagreement (one ranking is the exact reverse of the other).

Section 02

Adjusting Spearman's rs for Tied Ranks

The basic formula assumes all ranks are distinct (1, 2, ..., n). When two or more observations share the exact same value in either X or Y, they are tied:

  1. Assign every tied observation the average (common) rank of the positions they occupy (e.g., if two items tie for positions 3 and 4, both get (3+4)/2 = 3.5).
  2. For every tied group of size m in both variables X and Y, add the correction factor CF = m(m² − 1) / 12 to Σdi²:
rs = 1 − 6 · [ Σ di² + Σ mj(mj² − 1)/12 ] / [ n(n² − 1) ]
Quick Correction Factor Cheat Sheet m = 2 ⇒ 2(3)/12 = 0.5  |  m = 3 ⇒ 3(8)/12 = 2.0  |  m = 4 ⇒ 4(15)/12 = 5.0  |  m = 5 ⇒ 5(24)/12 = 10.0.
Slide Example 2 (Education vs. Income, n = 7): Education has two ties of size 2 (University ×2, Secondary ×2) and Income has two ties of size 2 (10 ×2, 15 ×2) → Total CF = 0.5 + 0.5 + 0.5 + 0.5 = 2.0; Σd² = 52 ⇒ rs = 1 − 6(52 + 2) / (7 × 48) = 1 − 324/336 = 0.0357 (very weak, almost no correlation).

Somers' D-Statistic & Coefficient of Concurrent Deviation

1. Somers' D-Statistic (Asymmetric Ordinal Measure)

Somers' D measures the strength and direction of association between two ordinal variables (or one ordinal and one quantitative) when one variable is treated as independent (X) and the other as dependent (Y). For every pair of observations (i, j), classify the pair into one of four types:

  • Concordant (NC): Both variables move in the same direction (xi < xj and yi < yj, or both >).
  • Discordant (ND): Variables move in opposite directions (xi < xj and yi > yj, or vice versa).
  • Tied on Y only (TY): xi ≠ xj but yi = yj.
  • Tied on X only (TX): xi = xj but yi ≠ yj.
Somers' D (Y dependent on X):   DY|X = (NC − ND) / (NC + ND + TY)
Somers' D (X dependent on Y):   DX|Y = (NC − ND) / (NC + ND + TX)
Why Somers' D is Asymmetric (2nd Incourse 2025 Q5b) Look at the denominators: DY|X penalizes ties in the dependent variable Y (TY), whereas DX|Y penalizes ties in X (TX). Because generally TY ≠ TX, reversing the roles of X and Y changes the value: DY|X ≠ DX|Y! Thus Somers' D is strictly asymmetric. Range: [−1, +1] (+1 = all untied-in-X pairs concordant, −1 = all discordant, 0 = no ordinal association).

2. Coefficient of Concurrent Deviation (rc) 2nd Incourse 2025 Q5(a)

The simplest casual measure of correlation that considers only the direction of change (upward +, downward −, or no change 0) from each observation to the next—ignoring exact magnitudes.

Steps to Compute rc

  1. Compare each value with its preceding value for both X and Y to assign signs (+ if increased, − if decreased, 0 if equal). This yields m = n − 1 pairs of signs.
  2. Multiply the signs of X and Y for each pair.
  3. Count c = number of positive (+) products (called concurrent deviations).
  4. Plug c and m into the formula.

Formula & Sign Rule

rc = ± √[ ± (2c − m) / m ]

If (2c − m) > 0, take + inside and outside the square root (rc > 0). If (2c − m) < 0, take − inside (to keep the radicand positive) and − outside (rc < 0). If 2c = m, rc = 0.

Section 05 • High-Yield Proofs

Proofs & Derivations Vault (3 Core Theorems)

Theorem 1 2nd Incourse '21, '25 & Final '19 Derive Spearman's Formula from Pearson's r
Let R(x) and R(y) be permutations of the first n natural numbers {1, 2, ..., n} (no ties).
Step 1 (Means & Variances of Ranks):
Mean: r̄(x) = r̄(y) = (1 + 2 + ... + n) / n = (n + 1) / 2.
Variance (from Lesson 3 Theorem 4): Var[R(x)] = Var[R(y)] = (n² − 1) / 12.
Step 2 (Variance of Rank Differences di = R(xi) − R(yi)):
Notice d̄ = r̄(x) − r̄(y) = 0, so Var[R(x) − R(y)] = (1/n) Σ(di − 0)² = (1/n) Σdi².
Step 3 (Solve for Covariance):
Var[R(x) − R(y)] = Var[R(x)] + Var[R(y)] − 2 Cov[R(x), R(y)]
⇒ Cov[R(x), R(y)] = ½ { (n² − 1)/12 + (n² − 1)/12 − (1/n) Σdi² } = (n² − 1)/12 − [1 / (2n)] Σdi².
Step 4 (Compute Pearson's r on the Ranks):
rs = Cov[R(x), R(y)] / √(Var[R(x)] · Var[R(y)]) = { (n² − 1)/12 − [1/(2n)] Σdi² } / { (n² − 1)/12 }
= 1 − [ (1/(2n)) Σdi² ] / [ (n² − 1)/12 ] = 1 − [ 6 Σdi² ] / [ n(n² − 1) ]. [Proved]
Theorem 2 2nd Incourse '22 Q5c & '25 Q4b Prove rs = +1 Under Perfect Agreement
Under perfect agreement, every individual receives the exact same rank in both variables: R(xi) = R(yi) for all i = 1, ..., n.
Therefore di = R(xi) − R(yi) = 0 for every i ⇒ Σdi² = 0.
Substituting into Spearman's formula: rs = 1 − [6(0)] / [n(n² − 1)] = 1 − 0 = +1. [Proved]
Theorem 3 Final '19 Q6d, Final '24 Q7d & 2nd Incourse '25 Q4b Prove rs = −1 Under Exact Opposite Rankings
Order observations so R(xi) = i (for i = 1, 2, ..., n). Under exact opposite rankings, R(yi) = n + 1 − i.
Then di = R(xi) − R(yi) = i − (n + 1 − i) = 2i − (n + 1).
Square and sum from i = 1 to n:
Σdi² = Σ[ 4i² − 4(n + 1)i + (n + 1)² ]
= 4 · [n(n + 1)(2n + 1)/6] − 4(n + 1) · [n(n + 1)/2] + n(n + 1)²
Combine the last two terms: −2n(n + 1)² + n(n + 1)² = −n(n + 1)².
Σdi² = [2n(n + 1)(2n + 1) / 3] − n(n + 1)² = [n(n + 1)/3] · [ 2(2n + 1) − 3(n + 1) ]
= [n(n + 1)/3] · (4n + 2 − 3n − 3) = [n(n + 1)(n − 1)] / 3 = n(n² − 1) / 3.
Substitute into Spearman's formula:
rs = 1 − [ 6 · n(n² − 1)/3 ] / [ n(n² − 1) ] = 1 − 2 = −1. [Proved]
