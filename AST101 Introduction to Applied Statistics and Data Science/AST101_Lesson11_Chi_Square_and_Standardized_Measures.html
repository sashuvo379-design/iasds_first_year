Section 01

Observed Counts, Expected Counts, Degrees of Freedom & χ²

For any r × c contingency table with observed cell counts Oij, row totals Ri, column totals Cj, and grand total N = ΣΣ Oij, we test independence by asking: "What counts would we expect in each cell if the two variables were completely unrelated?"

Under statistical independence, the joint probability equals the product of the marginal probabilities: P(A = Aj, B = Bi) = (Cj / N) × (Ri / N). Multiplying by N gives the Expected Count:

Expected Frequency:   Eij = (Ri × Cj) / N   =   (Row Total × Column Total) / Grand Total
Chi-Square Statistic:   χ² = Σi=1r Σj=1c [ (Oij − Eij)² / Eij ]
Degrees of Freedom (Final 2019 Q8c):   df = (r − 1)(c − 1)
Interpreting χ² & Degrees of Freedom
  • χ² = 0: Every observed count equals its expected count (Oij = Eij) → supports no association.
  • Larger χ² > 0: Stronger evidence that the two categorical variables are associated.
  • Why df = (r − 1)(c − 1)? Once the row and column totals are fixed, you can freely fill only (r − 1)(c − 1) cells—the remaining last cell in every row and column is uniquely forced by subtraction from the marginal totals!
Section 02 • Final 2020 Q8(b) [6 Marks]

Limitations of χ² & The Four Standardized Measures (Φ, C, T, V)

Limitations of Raw χ² as a Measure of Association (Final 2020 Q8b)
  1. Depends heavily on sample size N: If you double every cell count in a table (exact same proportions!), χ² doubles even though the underlying strength of association hasn't changed!
  2. No fixed upper bound: Ranges from 0 to N · (min(r, c) − 1), so a raw value like χ² = 22.15 cannot be judged as "weak" or "strong" without knowing N and table size.
  3. Depends on table dimensions (r × c): Tables with more rows/columns naturally accumulate larger sums.
  4. No direction: Since differences are squared, χ² never indicates positive vs. negative direction.

To overcome these limitations, statisticians standardize χ² into four bounded measures of strength:

1. Phi Coefficient (Φ)
Φ = √(χ² / n)

Best for: Strictly 2×2 tables (ranges 0 to 1; signed form ±(ad−bc)/√(...) gives −1 to +1). Can exceed 1 for tables larger than 2×2!

2. Pearson's C
C = √[ χ² / (χ² + n) ]

Limitation: Never reaches 1! Max is √[(k−1)/k]: 0.707 for 2×2, 0.870 for 4×4. Never compare C across tables of different sizes.

3. Tschuprow's T
T = √[ (χ²/n) / √((r−1)(c−1)) ]

Range: [0, 1]. Reaches 1 only for square tables (r = c). For 2×2 tables, T = Φ.

4. Cramér's V (Best General)
V = √[ χ² / (n(k − 1)) ]
k = min(r, c)

Range: [0, 1] inclusive for ANY table size (even non-square!). For 2×2 tables (k = 2), V = Φ = T.

Watch Out for k = min(r, c)! In Cramér's V, k is always the smaller of the number of rows and columns. For a 2 × 3 table (like Party Affiliation vs. Tax Reform), k = min(2, 3) = 2 (so k − 1 = 1, giving V = √(22.15 / 500) = 0.2105). Always double-check that you pick the minimum, not the maximum!

Proofs & Derivations Vault

Theorem 1 Prove the 2×2 Chi-Square Shortcut: χ² = n(ad − bc)² / [(a+b)(c+d)(a+c)(b+d)]
Let n = a + b + c + d. Expected frequencies under independence are:
E11 = (a+b)(a+c)/n,   E12 = (a+b)(b+d)/n,   E21 = (c+d)(a+c)/n,   E22 = (c+d)(b+d)/n.
Step 1 (Compute O11 − E11):
a − (a+b)(a+c)/n = [ a(a+b+c+d) − (a²+ac+ab+bc) ] / n = (ad − bc) / n.
By identical algebra: O12 − E12 = −(ad−bc)/n,   O21 − E21 = −(ad−bc)/n,   O22 − E22 = +(ad−bc)/n.
Thus ALL FOUR squared numerators equal (ad − bc)² / n²!
Step 2 (Divide each by Eij and factor out (ad−bc)² / n):
χ² = [(ad−bc)² / n] · { 1/[(a+b)(a+c)] + 1/[(a+b)(b+d)] + 1/[(c+d)(a+c)] + 1/[(c+d)(b+d)] }
Step 3 (Combine over common denominator (a+b)(c+d)(a+c)(b+d)):
Numerator inside braces = (c+d)(b+d) + (c+d)(a+c) + (a+b)(b+d) + (a+b)(a+c)
= (c+d)[(b+d)+(a+c)] + (a+b)[(b+d)+(a+c)] = (a+b+c+d)(a+b+c+d) = n².
Final Step: χ² = [(ad − bc)² / n] · [ n² / {(a+b)(c+d)(a+c)(b+d)} ] = n(ad − bc)² / [(a+b)(c+d)(a+c)(b+d)]. [Proved]
Theorem 2 Direct Cell Formula for Phi (Φ) & Equivalence Φ = T = V in a 2×2 Table
Direct Phi: Φ = √(χ² / n) = √[ (ad − bc)² / {(a+b)(c+d)(a+c)(b+d)} ] = ±(ad − bc) / √[(a+b)(c+d)(a+c)(b+d)].
For a 2×2 table (r = 2, c = 2, k = min(2, 2) = 2):
Tschuprow's T = Φ / [(2−1)(2−1)]1/4 = Φ / 1 = Φ.
Cramér's V = Φ / √(2−1) = Φ / 1 = Φ.
Thus for any 2×2 table, |Φ| = T = V! [Proved]

Final 2019 • Q8(b),(c) [8 Marks] Father's vs. Son's Eye Color χ² Test & Degrees of Freedom

Data (N = 1,000): Father Black & Son Black (a = 230), Father Black & Son Not Black (b = 148), Father Not Black & Son Black (c = 151), Both Not Black (d = 471).

  • Row & Col Totals: R₁ = 378, R₂ = 622, C₁ = 381, C₂ = 619, N = 1000.
  • Expected Counts: E₁₁ = 144.02, E₁₂ = 233.98, E₂₁ = 236.98, E₂₂ = 385.02.
  • Chi-Square (2×2 Shortcut):
    ad − bc = (230 × 471) − (148 × 151) = 108,330 − 22,348 = 85,982.
    χ² = 1000 × (85982)² / (378 × 622 × 381 × 619) = 133.33.
  • Decision (df = (2−1)(2−1) = 1): From the exam table, critical values at df = 1 are 3.842 (α = 0.05) and 6.635 (α = 0.01). Since 133.33 >> 6.635, we reject independence and conclude there is a highly significant association between father's and son's eye color (Φ = V = 0.365, moderate positive association).
Final 2020 • Q8(b) [6 Marks] Limitations of χ² & Standardized Alternatives

Model Answer Outline:

  1. Limitations of χ²: Directly proportional to sample size N, has no fixed upper bound (varies with N and table size), gives no direction of association, and cannot compare association strength across tables of different sizes/samples.
  2. Standardized Alternatives: Present (i) Phi (Φ = √(χ²/n)) for 2×2 tables, (ii) Pearson's C = √(χ²/(χ²+n)) (noting its table-dependent upper limit < 1), (iii) Tschuprow's T for square tables, and (iv) Cramér's V = √[χ²/(n(k−1))] with k = min(r, c), which cleanly spans [0, 1] for any table size.
