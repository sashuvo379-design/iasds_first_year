Section 01

Raw Data & Organizing Qualitative Data

Raw data are observations recorded in the exact sequence in which they are collected, before any sorting, ranking, or grouping. The most convenient way to organize raw data is a Frequency Distribution—a table listing each category (or class) alongside the number of observations (f) belonging to it.

Relative Frequency = f / Σf   |   Percentage = (Relative Frequency) × 100   |   Pie Angle = (Relative Frequency) × 360°

Graphs for Qualitative (Categorical) Data

Bar Diagram

Separated vertical/horizontal bars whose heights represent category frequencies. Limitation: Poor when bar heights vary wildly (highly heterogeneous).

Pie Chart

A 360° circle sliced proportionally to relative frequencies. Limitation: Poor when there are too many categories or highly uneven slices.

Clustered / Stacked Bar

Displays two or more interrelated categorical sets in one chart (derived from an r × c cross table / contingency table).

Pareto Chart

A categorical bar chart whose vertical bars are strictly arranged in descending order (highest frequency to lowest).

Section 02

Quantitative Frequency Distributions & Class Construction

When quantitative observations are organized into intervals, the result is called grouped data. Mastering the exact terminology prevents costly mistakes in later lessons (mean, median, mode, ogives):

Core Terminology

  • Class Interval: Range of values between a lower and upper limit (e.g., 801–1000).
  • Class Limits: Stated endpoints of a class (Lower Limit = 801, Upper Limit = 1000).
  • Class Boundaries: Exact cut-points that eliminate gaps between adjacent classes (subtract 0.5 from lower limit and add 0.5 to upper limit for integers → 800.5 to 1000.5; for 1-decimal data like 7.8–8.8, subtract/add 0.05).
  • Class Width (Size): Upper Boundary − Lower Boundary (e.g., 1000.5 − 800.5 = 200).
  • Class Midpoint (Mark): (Lower + Upper) / 2.

3 Decisions When Building a Table

  1. Number of Classes (usually 5 to 20):
    • 2k Rule: Pick smallest integer k such that 2k ≥ n. (For n = 40: 25 = 32 < 40 ≤ 64 = 26 → 6 classes).
    • Sturges' Formula: k = 1 + 3.3 × log10(n). (For n = 40: 1 + 3.3(1.602) = 6.29 ≈ 6).
  2. Approximate Class Width: (Max − Min) / Number of classes, rounded up to a convenient number.
  3. Starting Point: Any convenient number ≤ Minimum value.
Exam Trap (Final 2017 Q1c, Final 2019 Q1g & Final 2025 Q2a) When are class limits and class boundaries the same? When classes are written as continuous / overlapping intervals (exclusive form), such as 10–20, 20–30, 30–40 (meaning 10 to less than 20, etc.)—there are no gaps to bridge! For inclusive intervals like 10–19, 20–29, you must use class boundaries (9.5–19.5, 19.5–29.5) so histogram bars touch with no gaps.

Special Frequency Table Types

Single-Valued Classes

Used for discrete data taking only a few distinct integers (e.g., 0, 1, 2, 3, 4, 5 vehicles owned per household).

Open-Ended Classes

First class has no lower limit ("Below 110") or last class has no upper limit ("54 and above"). Useful for extreme tails, but prevents computing an exact arithmetic mean.

Unequal Class Intervals

Used when data are very unevenly distributed (e.g., absentee days: 0–6, 6–10, 10–14, 14–20, 20–28, 28–30, 30–40). Requires Frequency Density for graphing!

Section 03

Histograms, Frequency Polygons, Unequal-Width Density & Shapes

FeatureBar DiagramHistogram
Variable TypeQualitative (categorical) or discrete single-valuedQuantitative continuous (grouped class intervals)
Gaps Between BarsEqual gaps between barsNo gaps — bars are drawn adjacent at class boundaries
Bar WidthUniform & arbitrary (height alone carries info)Proportional to class width (area represents frequency)
Reordering X-axisCategories can be reordered (e.g., Pareto chart)Strictly fixed numerical order

Frequency Polygon: Formed by plotting points at each class midpoint against its frequency (or density) and joining successive points with straight lines (anchored to the x-axis at the midpoints of one extra empty class on each end). As n grows large and class width shrinks, the polygon smooths into a Frequency Curve.

Why Relative Frequency Histograms? When comparing two populations of vastly different sizes (e.g., Philadelphia's 1.48M vs. Erie's 105K adults), raw frequencies dwarf the smaller city; relative frequencies put both on the same 0–1 proportion scale.

Unequal Class Intervals & Frequency Density High-Yield Exam Topic

In a histogram, the area of each rectangle must be proportional to the class frequency (or relative frequency). If class widths differ, plotting raw frequency on the y-axis visually exaggerates wider classes! Instead, compute Class Density:

Class Density = Relative Frequency / Class Width = (f / N) / w   ⇒   Area of bar = Density × w = Relative Frequency
Reverse Formula (1st Incourse 2023):   f = N × (Class Density × Class Width)

Section 04

Cumulative Frequency Distributions & Ogives

A Cumulative Frequency Distribution gives the running total of observations falling below the upper boundary of each class. Dividing by total observations N yields the Cumulative Relative Frequency (and ×100 gives Cumulative Percentage).

How to Draw an Ogive (Final 2019 Q3a)
  1. Find the exact class boundaries and compute cumulative frequencies (cf).
  2. Mark class boundaries on the horizontal (X) axis and cumulative frequency (0 to N) on the vertical (Y) axis.
  3. Start with a dot at (First Lower Boundary, 0).
  4. Plot dots above each Upper Class Boundary at height equal to its cumulative frequency.
  5. Connect successive dots with straight line segments.
Reading Values from an Ogive (Final 2019 Q3b)
  • Median (Q2): Locate N/2 (or 50%) on the Y-axis → move horizontally to the ogive → drop vertically to the X-axis.
  • Q1 & Q3: Same process starting at N/4 (25%) and 3N/4 (75%).
  • Count between a and b: Read cf(b) and cf(a) from the curve, then subtract: cf(b) − cf(a).

Section 06 • Concept + Interactive Lab 2

Stem-and-Leaf Displays, Split Stems & Dotplots

In a Stem-and-Leaf Display, each number is split into a leading stem and a trailing leaf. Unlike a histogram, it preserves the exact original observations while simultaneously revealing distribution shape.

Histogram vs. Stem-and-Leaf (Final 2024 Q3a)
  • Stem-and-Leaf: Best for small quantitative datasets where keeping exact values matters. Not suitable for huge n or highly heterogeneous data.
  • Histogram: Preferable for large quantitative datasets because grouping into classes scales cleanly to thousands of observations.
Multiple Rows Per Stem Notation
  • 2 Rows/Stem: . holds leaves 0–4; * holds leaves 5–9.
  • 5 Rows/Stem: . (0–1), t (2–3), f (4–5), s (6–7), * (8–9).
  • Left Depth Column: Cumulative counts inward from both ends toward the row containing the median (shown in parentheses, e.g., (18)).

Dotplot: Plots each observation as a dot above a horizontal number line—especially handy for quickly spotting outliers (extreme values) in small datasets.

          1st Incourse 2023 • Q3(b) [4.5 Marks] Reverse-Engineering an Unequal-Width Density Histogram
          

            
Question: A teacher studied the number of A+ secured by N = 50 students. The graph shows Class Interval on X-axis and Class Density on Y-axis: 0–6 (0.05), 6–10 (0.075), 10–14 (0.04), 14–20 (0.02), 20–28 (0.01), 28–30 (0.02). (i) Name the graph & what is special? (ii) Construct the frequency table. (iii) Compute the mean.

            
Worked Solution:

            
    
              
  • (i) It is a Density Histogram (Histogram for Unequal Class Intervals). Its special feature is that class widths vary (6, 4, 4, 6, 8, 2), so the Y-axis plots Class Density = Relative Frequency / Class Width, making each bar's area equal to its relative frequency.
    • 
              
  • (ii) Frequency Table using Rel. Freq = Density × Width and f = 50 × Rel. Freq:
                
      
                  
    • 0–6 (w=6, m=3): rf = 0.05 × 6 = 0.30 → f = 15 (f·m = 45)
      • 
                  
    • 6–10 (w=4, m=8): rf = 0.075 × 4 = 0.30 → f = 15 (f·m = 120)
      • 
                  
    • 10–14 (w=4, m=12): rf = 0.04 × 4 = 0.16 → f = 8 (f·m = 96)
      • 
                  
    • 14–20 (w=6, m=17): rf = 0.02 × 6 = 0.12 → f = 6 (f·m = 102)
      • 
                  
    • 20–28 (w=8, m=24): rf = 0.01 × 8 = 0.08 → f = 4 (f·m = 96)
      • 
                  
    • 28–30 (w=2, m=29): rf = 0.02 × 2 = 0.04 → f = 2 (f·m = 58)
      • 
                  
    • Check: Σrf = 1.00, Σf = 50 ✓
      • 
                
    
              
    • 
              
  • (iii) Mean: x̄ = Σ(f·m) / N = (45 + 120 + 96 + 102 + 96 + 58) / 50 = 517 / 50 = 10.34 A+ grades per student.
    • 
            

          

        


        

          Final 2017 • Q2(d) [5 Marks] Drawing an Ogive & Finding Observations Between 255 and 547
          

            
Data: Classes 100–200 (100), 200–300 (500), 300–400 (700), 400–500 (800), 500–600 (700), 600–700 (500), 700–800 (100). Total N = 3,400.

            
Worked Solution:

            
    
              
  • Cumulative Frequencies (cf): (100, 0), (200, 100), (300, 600), (400, 1300), (500, 2100), (600, 2800), (700, 3300), (800, 3400).
    • 
              
  • Linear Interpolation (matches exact reading from straight-line Ogive):
                
      
                  
    • At X = 255 (inside 200–300): cf(255) = 100 + [(255 − 200)/100] × 500 = 100 + 275 = 375.
      • 
                  
    • At X = 547 (inside 500–600): cf(547) = 2100 + [(547 − 500)/100] × 700 = 2100 + 329 = 2429.
      • 
                
    
              
    • 
              
  • Observations between 255 and 547: 2429 − 375 = 2,054 observations (verify this live in Interactive Lab 1 above!).
    • 
            

          

        


        

          1st Incourse 2022 • Q1 [2 Marks] Reading a Stem-and-Leaf Plot with Leaf Unit = 0.1
          

            
Plot (Leaf Unit = 0.1): 1 | 12  ;  2 | 23559  ;  3 | 34455778  ;  4 | 3456778899  ;  5 | 223346667778889

            
Worked Solution:

            
    
              
  • (a) Total observations (n): 2 + 5 + 8 + 10 + 15 = 40.
    • 
              
  • (b) Maximum value: Stem 5, leaf 9 with Leaf Unit 0.1 → 5.9.
    • 
              
  • (c) Median: Average of 20th and 21st ordered values. Row 1–3 have 2 + 5 + 8 = 15 values. Counting into Row 4 (3,4,5,6,7,7,8,8,9,9): 20th is 4.7, 21st is 4.7 → Median = 4.7.
    • 
              
  • (d) Shape: Frequencies rise steadily from 2 → 5 → 8 → 10 → 15, with a long tail toward smaller values → Negatively (Left) Skewed.

          1st Incourse 2023 • Q2(b) [2 Marks] Constructing a Split Stem-and-Leaf Plot
          

            
Data (n = 20): 57, 58, 44, 55, 52, 54, 45, 51, 52, 54, 58, 48, 51, 58, 47, 50, 52, 53, 52, 49.

            
Worked Solution: Because all 20 values fall into only two stems (4 and 5), a 1-row stem plot would be too cramped. Use 2 rows per stem (Stem width = 10, Leaf unit = 1; . for 0–4, * for 5–9):

4 * | 5 7 8 9
5 . | 0 1 1 2 2 2 2 3 4 4
5 * | 5 7 8 8 8

          Final 2025 • Radar Chart & Q2(a) Interpreting a Radar Chart & Class Boundaries
          

            
    
              
  • Radar Chart (Final 2025): Shows scores across 5 subjects (Stats ≈ 80, Math ≈ 72, Economics ≈ 72, CS ≈ 65, English ≈ 60). Highest performance is in Stats; overall performance is fairly balanced (scores cluster between 60 and 80 without extreme collapse in any subject, though slightly stronger in quantitative subjects).
    • 
              
  • Why Class Boundaries over Class Limits (Final 2025 Q2a): Continuous variables can take values between integer limits (e.g., 19.6 lies between 10–19 and 20–29). Class boundaries close those gaps so histogram bars touch seamlessly and every possible real measurement falls uniquely into a class.
