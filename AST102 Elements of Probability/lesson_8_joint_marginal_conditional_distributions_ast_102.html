Lesson 8: Joint, Marginal & Conditional Distributions

Moving from single variables to pairs $(X, Y)$: reading 2D probability surfaces, summing or integrating out variables, slicing conditional distributions, and testing independence.

Section 01 • Core Theory

Core Concepts & Intuition

Ross Ch. 6 · AST 102 Lecture 12+ & Past Papers (2018–2025)

01 Joint PMF, Joint PDF & Joint CDF

Year Final 2022 Q8(a) · Ross Ch. 6.1
Discrete Pair $(X, Y)$ $p(x,y) = P(X=x, Y=y)$

Assigns probability mass to each lattice pair $(x,y)$ in a 2D table. Must satisfy:

$$p(x,y) \ge 0 \qquad \text{and} \qquad \sum_x \sum_y p(x,y) = 1$$ $$P\big((X,Y) \in A\big) = \sum_{(x,y)\in A} p(x,y)$$
Continuous Pair $(X, Y)$ $f(x,y)$

A non-negative 2D density surface whose total volume equals $1$. Event probability is the volume over region $A$:

$$f(x,y) \ge 0 \qquad \text{and} \qquad \int_{-\infty}^{\infty}\!\int_{-\infty}^{\infty} f(x,y)\,dx\,dy = 1$$ $$P\big((X,Y) \in A\big) = \iint_A f(x,y)\,dx\,dy$$
Joint Cumulative Distribution Function (Joint CDF)

Accumulates all probability in the lower-left quadrant $(-\infty, x] \times (-\infty, y]$. For continuous $(X, Y)$, $f(x,y) = \dfrac{\partial^2}{\partial x\,\partial y} F(x,y)$.

$$F(x,y) = P(X \le x,\; Y \le y)$$

02 Marginal Distributions ("Summing / Integrating Out")

Year Final 2019 Q4(c) · Lecture 12

To recover the individual distribution of $X$ alone (ignoring $Y$), sum or integrate the joint distribution over all possible values of $Y$ (and vice versa for $Y$):

Discrete Marginals (Row / Column Sums)
$$p_X(x) = \sum_{\text{all } y} p(x,y), \qquad p_Y(y) = \sum_{\text{all } x} p(x,y)$$
Continuous Marginals (Integrating Out)
$$f_X(x) = \int_{-\infty}^{\infty} f(x,y)\,dy, \qquad f_Y(y) = \int_{-\infty}^{\infty} f(x,y)\,dx$$
!
Exam Trap Spotlight · Triangular vs. Rectangular Support Limits

On a rectangular support like $0 < x < 1, 0 < y < 1$, the integration bounds are constant ($0$ to $1$). On a triangular support such as $0 < x < y < 1$, the bounds depend on the variable you hold fixed:

Finding $f_X(x)$ (Fix $x$, integrate $y$):

Since $x < y < 1$, $y$ runs from $x$ to $1$ (NOT $0$ to $1$):

$f_X(x) = \int_{x}^{1} f(x,y)\,dy$
Finding $f_Y(y)$ (Fix $y$, integrate $x$):

Since $0 < x < y$, $x$ runs from $0$ to $y$ (NOT $0$ to $1$):

$f_Y(y) = \int_{0}^{y} f(x,y)\,dx$

03 Independence of Random Variables

Ross Ch. 6.2

Random variables $X$ and $Y$ are independent if and only if their joint distribution factors into the product of their marginals for every $(x,y)$:

$$f_{X,Y}(x,y) = f_X(x)\,f_Y(y) \qquad \forall\,(x,y) \in \mathbb{R}^2$$

(Equivalently, $p(x,y) = p_X(x)p_Y(y)$ for discrete RVs, or $F(x,y) = F_X(x)F_Y(y)$ for all $x,y$.)

✕ Quick Visual Shortcut · Non-Rectangular Support

If the support region where $f(x,y) > 0$ is NOT a rectangle (for instance, the triangle $0 < x < y < 1$), then $X$ and $Y$ can NEVER be independent!

ISRT Exam Tip: Use this shortcut to know the answer instantly—but still derive both marginals $f_X(x), f_Y(y)$ and show $f_X(x)f_Y(y) \neq f(x,y)$ for full credit.

04 Conditional Distributions

Final 2025 Q5(c)

When we observe $Y = y$ (with $p_Y(y) > 0$ or $f_Y(y) > 0$), the conditional distribution of $X$ given $Y = y$ is:

$$p_{X|Y}(x \mid y) = \frac{p(x,y)}{p_Y(y)} \qquad \text{(Discrete)}$$ $$f_{X|Y}(x \mid y) = \frac{f(x,y)}{f_Y(y)} \qquad \text{(Continuous, } f_Y(y) > 0\text{)}$$
Geometric Slicing Intuition

Imagine cutting the 3D density surface $z = f(x,y)$ with a vertical knife along the fixed line $y = y_0$. That cross-sectional ribbon has area $\int f(x, y_0)\,dx = f_Y(y_0)$. Dividing the ribbon's height by $f_Y(y_0)$ rescales it so the conditional slice integrates to exactly $1$.

Section 03 • Exam Proofs

Proofs & Derivations Drawer

4 core AST 102 bivariate derivations — click any card to expand

Step 1 — Verify Valid Joint PDF: $f(x,y) = 6x \ge 0$ on $0 < x < y < 1$, and: $$\int_0^1 \int_x^1 6x\,dy\,dx = \int_0^1 6x(1 - x)\,dx = \left[3x^2 - 2x^3\right]_0^1 = 3 - 2 = 1 \;\checkmark$$

Step 2 — Marginal PDF of $X$: Hold $x \in (0,1)$ fixed; $y$ ranges from $x$ to $1$: $$f_X(x) = \int_x^1 6x\,dy = 6x\,[y]_x^1 = \mathbf{6x(1 - x)}, \quad 0 < x < 1$$

Step 3 — Marginal PDF of $Y$: Hold $y \in (0,1)$ fixed; $x$ ranges from $0$ to $y$: $$f_Y(y) = \int_0^y 6x\,dx = \left[3x^2\right]_0^y = \mathbf{3y^2}, \quad 0 < y < 1$$

Step 4 — Independence Check: $$f_X(x)f_Y(y) = 6x(1-x)\cdot 3y^2 = 18x(1-x)y^2 \neq 6x = f(x,y)$$ Hence $X$ and $Y$ are not independent (dependent). $\blacksquare$

Suppose for contradiction that $X$ and $Y$ are independent, so $f_{X,Y}(x,y) = f_X(x)f_Y(y)$ for all $(x,y) \in \mathbb{R}^2$.

Let $S_X = \{x : f_X(x) > 0\}$ and $S_Y = \{y : f_Y(y) > 0\}$ be the marginal supports. Under independence, $f_{X,Y}(x,y) > 0$ if and only if $f_X(x) > 0$ AND $f_Y(y) > 0$—meaning the joint support must be the exact Cartesian product (rectangle) $S_X \times S_Y$.

Now suppose the support is not a rectangle (e.g., $0 < x < y < 1$). Then there exists a "missing corner" point $(x_0, y_0)$ outside the support (such as $x_0 = 0.7, y_0 = 0.3$) where $x_0 \in S_X$ ($f_X(x_0) > 0$) and $y_0 \in S_Y$ ($f_Y(y_0) > 0$), yet $(x_0, y_0)$ lies outside the joint support so $f_{X,Y}(x_0, y_0) = 0$.

$$f_{X,Y}(x_0, y_0) = 0 \;\neq\; f_X(x_0)\,f_Y(y_0) > 0 \quad (\text{Contradiction!}) \quad \blacksquare$$

The event $X + Y < 1$ intersected with the unit square $(0,1) \times (0,1)$ is the lower-left triangle where $0 < x < 1$ and $0 < y < 1 - x$:

$$P(X + Y < 1) = \int_0^1 \int_0^{1-x} (x + y)\,dy\,dx = \int_0^1 \left[xy + \frac{y^2}{2}\right]_0^{1-x} dx$$ $$= \int_0^1 \left(x(1-x) + \frac{(1-x)^2}{2}\right) dx = \int_0^1 \frac{1 - x^2}{2}\,dx$$
$$= \frac{1}{2}\left[x - \frac{x^3}{3}\right]_0^1 = \frac{1}{2}\left(1 - \frac{1}{3}\right) = \mathbf{\frac{1}{3}} \quad \blacksquare$$

Fix any real number $y$ such that the marginal density satisfies $f_Y(y) > 0$. By definition, $f_{X|Y}(x \mid y) = \dfrac{f(x,y)}{f_Y(y)} \ge 0$.

Integrating over $x \in (-\infty, \infty)$ while treating $f_Y(y)$ as a positive constant with respect to $x$:

$$\int_{-\infty}^{\infty} f_{X|Y}(x \mid y)\,dx = \int_{-\infty}^{\infty} \frac{f(x,y)}{f_Y(y)}\,dx = \frac{1}{f_Y(y)} \underbrace{\int_{-\infty}^{\infty} f(x,y)\,dx}_{=\,f_Y(y)} = \frac{f_Y(y)}{f_Y(y)} = 1 \quad \blacksquare$$

Thus $f_{X|Y}(x \mid y)$ is a bona fide univariate PDF in $x$ for every fixed $y$ with $f_Y(y) > 0$.

Year Final 2025 • Q5(b),(c) • 9 Marks AST 102 · ISRT, University of Dhaka

(b) Let $f(x,y) = 1$ for $0 < x < 1, 0 < y < 1$ ($0$ otherwise). (i) Are $X$ and $Y$ independent? (ii) Find $P(X + Y < 1)$.

(c) Given $f_{X,Y}(x,y) = 2$ for $0 \le y \le x \le 1$ ($0$ elsewhere), find the conditional PDF $f_{X|Y}(x \mid y)$.

Solution to (b):

(i) $f_X(x) = \int_0^1 1\,dy = 1$ ($0 < x < 1$) and $f_Y(y) = \int_0^1 1\,dx = 1$ ($0 < y < 1$). Since $f_X(x)f_Y(y) = 1\cdot 1 = 1 = f(x,y)$ on $(0,1)^2$, $X$ and $Y$ are independent.

(ii) $P(X + Y < 1) = \int_0^1 \int_0^{1-x} 1\,dy\,dx = \int_0^1 (1 - x)\,dx = \left[x - \frac{x^2}{2}\right]_0^1 = \mathbf{\frac{1}{2}}$.

Solution to (c):

First find the marginal $f_Y(y)$ for $0 \le y \le 1$ (since $y \le x \le 1$, integrate $x$ from $y$ to $1$):

$$f_Y(y) = \int_y^1 2\,dx = 2(1 - y), \quad 0 \le y < 1$$ $$f_{X|Y}(x \mid y) = \frac{f_{X,Y}(x,y)}{f_Y(y)} = \frac{2}{2(1 - y)} = \mathbf{\frac{1}{1 - y}}, \quad y \le x \le 1$$

Thus $X \mid (Y = y) \sim \text{Uniform}(y, 1)$.

Year Final 2024 • Q4(c) • 6 Marks Discrete Joint PMF · ISRT, DU

The joint PMF of discrete random variables $X$ and $Y$ is $f(x,y) = \dfrac{2x + y}{48}$ for $x = 0, 1, 2, 3$ and $y = 0, 1, 2$. (i) Show that $E(X + Y) = E(X) + E(Y)$. (ii) Are $X$ and $Y$ independent? (iii) Find the conditional PMF of $X$ given $Y$. (iv) Find $E(X \mid Y = 2)$.

Marginals: $p_X(x) = \sum_{y=0}^2 \frac{2x+y}{48} = \frac{6x+3}{48} = \mathbf{\frac{2x+1}{16}}$ ($x=0,1,2,3$);   $p_Y(y) = \sum_{x=0}^3 \frac{2x+y}{48} = \frac{12+4y}{48} = \mathbf{\frac{3+y}{12}}$ ($y=0,1,2$).

(i) Verify $E(X+Y) = E(X) + E(Y)$: $E(X) = \frac{0(1)+1(3)+2(5)+3(7)}{16} = \frac{34}{16} = \mathbf{\frac{17}{8} = 2.125}$;   $E(Y) = \frac{0(3)+1(4)+2(5)}{12} = \frac{14}{12} = \mathbf{\frac{7}{6}}$. Sum: $E(X) + E(Y) = \frac{17}{8} + \frac{7}{6} = \frac{51 + 28}{24} = \mathbf{\frac{79}{24}}$. Directly: $E(X+Y) = \sum_x \sum_y (x+y)\frac{2x+y}{48} = \frac{158}{48} = \mathbf{\frac{79}{24}}$. Verified!

(ii) Independence: At $(0,0)$, $f(0,0) = 0 \neq p_X(0)p_Y(0) = \frac{1}{16}\cdot\frac{3}{12} = \frac{1}{64}$. Hence not independent.

(iii) Conditional PMF: $p_{X|Y}(x \mid y) = \dfrac{(2x+y)/48}{(3+y)/12} = \mathbf{\dfrac{2x + y}{4(3 + y)}}$ for $x = 0, 1, 2, 3$.

(iv) Conditional Mean at $Y = 2$: $p_{X|Y}(x \mid 2) = \frac{2x+2}{20} = \frac{x+1}{10}$. Thus: $$E(X \mid Y = 2) = 0\left(\frac{1}{10}\right) + 1\left(\frac{2}{10}\right) + 2\left(\frac{3}{10}\right) + 3\left(\frac{4}{10}\right) = \frac{0 + 2 + 6 + 12}{10} = \mathbf{2}$$

Year Final 2022 • Q8(b) • 5 Marks AST 102 · ISRT, University of Dhaka

The joint density function of $X$ and $Y$ is $f(x,y) = x + y$ for $0 < x < 1, 0 < y < 1$ ($0$ otherwise). (i) Are $X$ and $Y$ independent? (ii) Find $P(X + Y < 1)$.

(i) Marginals & Independence: $f_X(x) = \int_0^1 (x + y)\,dy = \left[xy + \frac{y^2}{2}\right]_0^1 = x + \frac{1}{2}$ ($0 < x < 1$). By symmetry, $f_Y(y) = y + \frac{1}{2}$ ($0 < y < 1$). Since $f_X(x)f_Y(y) = (x + \frac{1}{2})(y + \frac{1}{2}) = xy + \frac{1}{2}(x+y) + \frac{1}{4} \neq x + y$, $X$ and $Y$ are not independent.

(ii) $P(X + Y < 1)$: $$P(X + Y < 1) = \int_0^1 \int_0^{1-x} (x + y)\,dy\,dx = \int_0^1 \frac{1 - x^2}{2}\,dx = \mathbf{\frac{1}{3}}$$

Year Final 2019 Q4(c) & 2nd Midterm Q2(b) • 3 Marks Triangular Support · ISRT, DU

The joint density of $X$ and $Y$ is $f(x,y) = 6x$ for $0 < x < y < 1$ ($0$ elsewhere). Find the marginal PDFs of $X$ and $Y$. Are $X$ and $Y$ independent?

Marginal of $X$: $f_X(x) = \int_x^1 6x\,dy = \mathbf{6x(1 - x)}$, for $0 < x < 1$.

Marginal of $Y$: $f_Y(y) = \int_0^y 6x\,dx = \mathbf{3y^2}$, for $0 < y < 1$.

Independence: $f_X(x)f_Y(y) = 18x(1-x)y^2 \neq 6x$, and the support is triangular ($0 < x < y < 1$), so $X$ and $Y$ are dependent.

Mid-term II 2018 • Q2(a) • 4 Marks Conditional Densities & Mean · ISRT, DU

Given the joint PDF $f(x,y) = x^2 + \dfrac{xy}{3}$ for $0 < x < 1, 0 < y < 2$ ($0$ otherwise), find the conditional densities of $X$ and $Y$, and then find $E\left(Y \mid X = \dfrac{1}{2}\right)$.

Marginals: $f_X(x) = \int_0^2 \left(x^2 + \frac{xy}{3}\right)dy = 2x^2 + \frac{2x}{3} = \frac{2x(3x+1)}{3}$ ($0 < x < 1$);   $f_Y(y) = \int_0^1 \left(x^2 + \frac{xy}{3}\right)dx = \frac{1}{3} + \frac{y}{6} = \frac{2 + y}{6}$ ($0 < y < 2$).

Conditional Densities: $$f_{Y|X}(y \mid x) = \frac{x^2 + xy/3}{2x(3x+1)/3} = \mathbf{\frac{3x + y}{2(3x + 1)}} \;\;(0 < y < 2), \qquad f_{X|Y}(x \mid y) = \mathbf{\frac{6x^2 + 2xy}{2 + y}} \;\;(0 < x < 1)$$

Evaluating $E(Y \mid X = 1/2)$: Plugging $x = \frac{1}{2}$ gives $f_{Y|X}(y \mid 1/2) = \dfrac{3/2 + y}{2(5/2)} = \dfrac{3 + 2y}{10}$ ($0 < y < 2$). Hence: $$E\!\left(Y \mid X = \frac{1}{2}\right) = \int_0^2 y\left(\frac{3 + 2y}{10}\right)dy = \frac{1}{10}\left[\frac{3y^2}{2} + \frac{2y^3}{3}\right]_0^2 = \frac{1}{10}\left(6 + \frac{16}{3}\right) = \frac{34}{30} = \mathbf{\frac{17}{15} \approx 1.1333}$$
