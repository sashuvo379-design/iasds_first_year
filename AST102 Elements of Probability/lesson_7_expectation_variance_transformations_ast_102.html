Core Concepts & Intuition

Ross Ch. 4.3–4.5, 5.2, 5.7 · ISRT AST 102 Class Notes & Finals

01 · Center of Mass Mean $\mu = E[X]$

Mathematical Expectation ($E[X]$)

The expected value $E[X]$ is the probability-weighted average of all possible values of $X$. Physically, if you place mass $p(x)$ (or density $f(x)$) along a weightless rod, $\mu = E[X]$ is the exact balance point (center of mass).

$$E[X] = \begin{cases} \displaystyle \sum_{x} x \, p(x) & \text{(Discrete)} \\[10pt] \displaystyle \int_{-\infty}^{\infty} x \, f(x)\,dx & \text{(Continuous)} \end{cases}$$
02 · Expectation of $g(X)$ Ross Prop. 4.1

LOTUS (Law of the Unconscious Statistician)

To compute $E[g(X)]$ (such as $E[X^2]$, $E[e^X]$, or $E[e^{2X}]$), you do NOT need to derive the distribution of $Y = g(X)$ first. Simply replace $x$ with $g(x)$ inside the sum or integral using $X$'s original distribution:

$$E[g(X)] = \begin{cases} \displaystyle \sum_{x} g(x)\,p(x) & \text{(Discrete)} \\[10pt] \displaystyle \int_{-\infty}^{\infty} g(x)\,f(x)\,dx & \text{(Continuous)} \end{cases}$$

03 Variance, Standard Deviation & The Minimum MSE Property

Year Final 2023 Q1(h) · Year Final 2024 Q1(b)
Variance & Shortcut
$$\text{Var}(X) = E[(X - \mu)^2] = E[X^2] - (E[X])^2$$

Standard deviation $\sigma_X = \sqrt{\text{Var}(X)}$ restores the original units of $X$. Always $\text{Var}(X) \ge 0$.

Minimum MSE (Final 2024 Q1b)
$$E[(X - a)^2] = (\mu - a)^2 + \sigma^2$$

Because $(\mu - a)^2 \ge 0$, the mean squared error $E[(X - a)^2]$ is uniquely minimized when $a = \mu = E[X]$, with minimum value $\sigma^2$.

Zero-Mean Deviation (Final 2023 Q1h)
$$E\big[X - E(X)\big] = E[X] - E[X] = 0$$

Positive and negative deviations from $\mu$ cancel out completely—which is why variance squares $(X - \mu)$.

04 Linear Transformations ($Y = a + bX$)

Year Final 2019 Q1(d) · Year Final 2023 Q5(c)
Summary Measure Transformation Law ($Y = a + bX$) Effect of Shift ($a$) Effect of Scale ($b$)
Mean (Expectation) $E[a + bX] = a + b\,E[X]$ Shifts mean by $+a$ Scales (and flips if $b < 0$) by $b$
Variance $\text{Var}(a + bX) = b^2\,\text{Var}(X)$ Vanishes (shift does not change spread) Multiplies by $b^2 \ge 0$ (always non-negative!)
Standard Deviation $\sigma_{a+bX} = |b|\,\sigma_X$ Vanishes Multiplies by $|b|$ (absolute value!)
!
ISRT Exam Trap · Year Final 2019 Q1(d) & 2023 Q5(c)

1. Negative Slopes Square to Positive: For $Y = 2 - 3X$ or $Y = -2X + 5$, variance multiplies by $(-3)^2 = \mathbf{+9}$ (NEVER $-9$), and standard deviation multiplies by $|-3| = \mathbf{+3}$ (NEVER $-3$).

2. Independent Differences STILL ADD Variances: For independent $X$ and $Y$, $\text{Var}(aX - bY + c) = a^2\text{Var}(X) + (-b)^2\text{Var}(Y) = \mathbf{a^2\text{Var}(X) + b^2\text{Var}(Y)}$. Subtracting two independent random variables increases total uncertainty!

05 Distribution of a Function of a Random Variable ($Y = g(X)$)

2nd Incourse 2021 Q1 · Year Final Q4(b,c)
Case A · Discrete

Direct Mapping & Merging

Map each support point $x_i \mapsto y_i = g(x_i)$. Sum probabilities of all $x_i$ that map to the same $y$:

$$p_Y(y) = \sum_{\{x \,:\, g(x)=y\}} p_X(x)$$
Case B · Continuous Monotone

Jacobian / Change-of-Variable

If $y = g(x)$ is strictly increasing or strictly decreasing with inverse $x = g^{-1}(y)$:

$$f_Y(y) = f_X\!\big(g^{-1}(y)\big)\left|\frac{dx}{dy}\right|$$

Always transform the support endpoints too!

Case C · Non-Monotone

The Universal CDF Method

When $g(x)$ is not 1-to-1 (e.g., $Y = X^2$ on $(-1, 2)$), start from the CDF, split $y$-intervals by branch count, and differentiate:

$$F_Y(y) = P(g(X) \le y) \implies f_Y(y) = \frac{d}{dy}F_Y(y)$$

Section 03 • Exam Proofs

Proofs & Derivations Drawer

4 essential AST 102 proofs — click any card to expand

Let $\mu = E[X]$ (a constant). By linearity of expectation and $E[\mu] = \mu$:

$$E[X - E(X)] = E[X - \mu] = E[X] - \mu = \mu - \mu = 0$$

For the variance shortcut, expand $(X - \mu)^2$ inside the expectation:

$$\text{Var}(X) = E[(X - \mu)^2] = E[X^2 - 2\mu X + \mu^2] = E[X^2] - 2\mu E[X] + \mu^2$$ $$= E[X^2] - 2\mu^2 + \mu^2 = E[X^2] - \mu^2 = E[X^2] - (E[X])^2 \quad \blacksquare$$

Add and subtract $\mu = E[X]$ inside the square:

$$E[(X - a)^2] = E\big[((X - \mu) + (\mu - a))^2\big]$$ $$= E[(X - \mu)^2] + 2(\mu - a)\underbrace{E[X - \mu]}_{=\,0} + (\mu - a)^2$$

Since $E[X - \mu] = 0$ and $E[(X - \mu)^2] = \sigma^2$, the cross-term vanishes completely:

$$E[(X - a)^2] = (\mu - a)^2 + \sigma^2$$

Because $(\mu - a)^2 \ge 0$ for all real $a$ and equals $0$ if and only if $a = \mu$, $E[(X - a)^2]$ achieves its unique minimum value $\sigma^2$ at $a = \mu$. $\blacksquare$

1. Expectation (shown for continuous; discrete replaces $\int$ with $\sum$):

$$E[a + bX] = \int_{-\infty}^{\infty} (a + bx)f(x)\,dx = a\underbrace{\int_{-\infty}^{\infty} f(x)\,dx}_{=\,1} + b\underbrace{\int_{-\infty}^{\infty} xf(x)\,dx}_{=\,E[X]} = a + bE[X]$$

2. Variance & Standard Deviation: Let $Y = a + bX$ and $\mu_Y = a + b\mu_X$. Then $Y - \mu_Y = (a + bX) - (a + b\mu_X) = b(X - \mu_X)$ (notice $a$ cancels!). Hence:

$$\text{Var}(Y) = E[(Y - \mu_Y)^2] = E\big[b^2(X - \mu_X)^2\big] = b^2 E[(X - \mu_X)^2] = b^2\text{Var}(X)$$ $$\sigma_Y = \sqrt{b^2 \sigma_X^2} = |b|\,\sigma_X \quad \blacksquare$$

Let $Y = g(X)$ where $g$ is differentiable and strictly monotone with inverse $x = g^{-1}(y)$:

Case 1 — Strictly Increasing ($g'(x) > 0$, so $\frac{dx}{dy} > 0$):

$$F_Y(y) = P(g(X) \le y) = P(X \le g^{-1}(y)) = F_X(g^{-1}(y))$$ $$f_Y(y) = \frac{d}{dy}F_X(g^{-1}(y)) = f_X(g^{-1}(y))\,\frac{dx}{dy}$$

Case 2 — Strictly Decreasing ($g'(x) < 0$, so $\frac{dx}{dy} < 0$): Applying $g^{-1}$ reverses the inequality sign:

$$F_Y(y) = P(g(X) \le y) = P(X \ge g^{-1}(y)) = 1 - F_X(g^{-1}(y))$$ $$f_Y(y) = \frac{d}{dy}\big[1 - F_X(g^{-1}(y))\big] = -f_X(g^{-1}(y))\,\frac{dx}{dy} = f_X(g^{-1}(y))\left|\frac{dx}{dy}\right|$$

Combining both cases yields the unified Jacobian formula $f_Y(y) = f_X(g^{-1}(y))\left|\frac{dx}{dy}\right|$. $\blacksquare$

ISRT Year Final 2023 · Q5(b) & Q5(c) [9 Marks] LOTUS + Linear Variance · AST 102

Q5(b): Given $f(x) = 1$ for $0 \le x \le 1$ ($0$ otherwise), find $E[e^{2X}]$.

Q5(c): A discrete RV $X$ has PMF $P(X=x) = kx$ for $x = 2, 4, 6$, and $P(X=8) = k(8 - 2) = 6k$. Find (i) $k$, (ii) $F(5)$, (iii) $E[X]$, and (iv) $\text{Var}(2 - 3X)$.

Q5(b): By LOTUS: $$E[e^{2X}] = \int_0^1 e^{2x} \cdot 1\,dx = \left[\frac{e^{2x}}{2}\right]_0^1 = \mathbf{\frac{e^2 - 1}{2} \approx 3.1945}$$

Q5(c):

(i) $2k + 4k + 6k + 6k = 18k = 1 \implies k = \mathbf{\frac{1}{18}}$.

(ii) $F(5) = P(X \le 5) = p(2) + p(4) = \frac{2}{18} + \frac{4}{18} = \frac{6}{18} = \mathbf{\frac{1}{3}}$.

(iii) $E[X] = \frac{2(2) + 4(4) + 6(6) + 8(6)}{18} = \frac{4 + 16 + 36 + 48}{18} = \frac{104}{18} = \mathbf{\frac{52}{9} \approx 5.7778}$.

(iv) $E[X^2] = \frac{4(2) + 16(4) + 36(6) + 64(6)}{18} = \frac{8 + 64 + 216 + 384}{18} = \frac{672}{18} = \frac{112}{3}$. Thus: $$\text{Var}(X) = \frac{112}{3} - \left(\frac{52}{9}\right)^2 = \frac{3024 - 2704}{81} = \frac{320}{81}$$ $$\text{Var}(2 - 3X) = (-3)^2 \text{Var}(X) = 9 \cdot \frac{320}{81} = \mathbf{\frac{320}{9} \approx 35.5556}$$

ISRT Year Final 2024 · Q4(b) & Q5(c) [7 Marks] Symbolic Summation + LOTUS · AST 102

Q4(b): A discrete RV $X$ has PMF $f(x) = \dfrac{2(2r - x)}{3r(r+1)}$ for $x = 0, 1, 2, \dots, r$. Find $E[X]$ and $V(X)$.

Q5(c): Given $f(x) = 1$ for $0 \le x \le 1$ ($0$ otherwise), find $E[e^X]$.

Q4(b): Using $\sum_{x=0}^r x = \frac{r(r+1)}{2}$, $\sum_{x=0}^r x^2 = \frac{r(r+1)(2r+1)}{6}$, and $\sum_{x=0}^r x^3 = \left[\frac{r(r+1)}{2}\right]^2$:

$$E[X] = \frac{2}{3r(r+1)}\sum_{x=0}^{r} (2rx - x^2) = \frac{2}{3r(r+1)}\left[2r\cdot\frac{r(r+1)}{2} - \frac{r(r+1)(2r+1)}{6}\right] = \frac{2}{3}\left(r - \frac{2r+1}{6}\right) = \mathbf{\frac{4r - 1}{9}}$$ $$E[X^2] = \frac{2}{3r(r+1)}\sum_{x=0}^{r} (2rx^2 - x^3) = \frac{2}{3r(r+1)}\left[\frac{r^2(r+1)(2r+1)}{3} - \frac{r^2(r+1)^2}{4}\right] = \frac{r(5r + 1)}{18}$$ $$V(X) = \frac{r(5r+1)}{18} - \frac{(4r-1)^2}{81} = \frac{9r(5r+1) - 2(16r^2 - 8r + 1)}{162} = \mathbf{\frac{13r^2 + 25r - 2}{162}}$$

Q5(c): $E[e^X] = \int_0^1 e^x \cdot 1\,dx = \left[e^x\right]_0^1 = \mathbf{e - 1 \approx 1.7183}$.

ISRT Year Final · Q4(b) & Q4(c) [8 Marks] Continuous & Discrete Linear Transformations

Q4(b) [3 Marks]: Given $f(x) = 2x$ for $0 < x < 1$ ($0$ elsewhere), let $Y = 3X + 1$. Find the PDF of $Y$.

Q4(c) [5 Marks]: An urn contains 4 red chips and 3 white chips. Two are drawn at random without replacement. Let $X$ be the number of red chips in the sample. Find the probability distribution of $Y = 2X - 1$, along with its mean and variance.

Q4(b): Inverse: $x = \frac{y - 1}{3}$, Jacobian: $\left|\frac{dx}{dy}\right| = \frac{1}{3}$. Support: $0 < x < 1 \implies 1 < y < 4$. $$f_Y(y) = f_X\!\left(\frac{y-1}{3}\right)\cdot\frac{1}{3} = 2\left(\frac{y-1}{3}\right)\cdot\frac{1}{3} = \mathbf{\frac{2(y - 1)}{9}}, \quad 1 < y < 4 \;\; (0 \text{ elsewhere})$$

Q4(c): Total draws $= \binom{7}{2} = 21$. Distribution of $X \in \{0, 1, 2\}$ and $Y = 2X - 1 \in \{-1, 1, 3\}$:

  • X = 0 ⇒ Y = -1 : P = C(4,0)C(3,2)/21 = 3/21 = 1/7
  • X = 1 ⇒ Y = 1 : P = C(4,1)C(3,1)/21 = 12/21 = 4/7
  • X = 2 ⇒ Y = 3 : P = C(4,2)C(3,0)/21 = 6/21 = 2/7

$E[X] = \frac{0(1) + 1(4) + 2(2)}{7} = \frac{8}{7}$, $E[X^2] = \frac{0 + 4 + 8}{7} = \frac{12}{7}$, $\text{Var}(X) = \frac{12}{7} - \frac{64}{49} = \frac{20}{49}$.

Therefore: $E[Y] = 2\left(\frac{8}{7}\right) - 1 = \mathbf{\frac{9}{7}}$ and $\text{Var}(Y) = 2^2\left(\frac{20}{49}\right) = \mathbf{\frac{80}{49}}$.

ISRT 2nd Incourse 2018 · Q1(b) & Q2(b) [6 Marks] Solving PMF from Moments + Expected Gain

Q1(b): A discrete RV $X$ takes only values $-1, 0, 1$. (i) Given $f(0) = \frac{1}{2}$, find $E[X^2]$. (ii) If also $E[X] = \frac{1}{6}$, find $f(-1)$ and $f(1)$.

Q2(b): Three fair coins are tossed. A player wins $\$5$ if all heads or all tails appear, and loses $\$3$ otherwise. Find the expected gain.

Q1(b)(i): Since $f(-1) + f(0) + f(1) = 1$ and $f(0) = \frac{1}{2}$, we have $f(-1) + f(1) = \frac{1}{2}$. Now: $$E[X^2] = (-1)^2 f(-1) + 0^2 f(0) + (1)^2 f(1) = f(-1) + f(1) = \mathbf{\frac{1}{2}}$$

Q1(b)(ii): $E[X] = -f(-1) + f(1) = \frac{1}{6}$. Adding this to $f(-1) + f(1) = \frac{1}{2}$ gives $2f(1) = \frac{2}{3} \implies f(1) = \mathbf{\frac{1}{3}}$ and $f(-1) = \frac{1}{2} - \frac{1}{3} = \mathbf{\frac{1}{6}}$.

Q2(b): $P(\text{all H or all T}) = \frac{2}{8} = \frac{1}{4}$; $P(\text{otherwise}) = \frac{6}{8} = \frac{3}{4}$. $$E[\text{Gain}] = 5\left(\frac{1}{4}\right) + (-3)\left(\frac{3}{4}\right) = \frac{5 - 9}{4} = \mathbf{-\$1}$$

ISRT 2nd Incourse 2021 · Q1 & Q3 [8 Marks] Non-Monotone $Y=X^2$ + Independent Linear Combo

Q1: Let $X \sim \text{Uniform}(-1, 2)$ with $f_X(x) = \frac{1}{3}$ on $(-1, 2)$. Find the PDF of $Y = X^2$.

Q3: Let $X$ and $Y$ be independent with $\mu_X = 10, \mu_Y = 7, \sigma_X^2 = 5, \sigma_Y^2 = 3$. For $Z = -2X + 4Y - 3$, find $E[Z]$ and $\text{Var}(Z)$.

Q1 (CDF Method): Support of $Y = X^2$ is $[0, 4)$. Split into two regimes:

  • Regime 1 ($0 < y < 1$): Both $-\sqrt{y}$ and $+\sqrt{y}$ lie in $(-1, 2)$, so $F_Y(y) = P(-\sqrt{y} \le X \le \sqrt{y}) = \int_{-\sqrt{y}}^{\sqrt{y}} \frac{1}{3}\,dx = \frac{2\sqrt{y}}{3} \implies f_Y(y) = F_Y'(y) = \mathbf{\dfrac{1}{3\sqrt{y}}}$.
  • Regime 2 ($1 \le y < 4$): Lower bound clips at $x = -1$, so $F_Y(y) = P(-1 < X \le \sqrt{y}) = \int_{-1}^{\sqrt{y}} \frac{1}{3}\,dx = \frac{\sqrt{y} + 1}{3} \implies f_Y(y) = F_Y'(y) = \mathbf{\dfrac{1}{6\sqrt{y}}}$.

Q3: By linearity and independence: $$E[Z] = -2(10) + 4(7) - 3 = -20 + 28 - 3 = \mathbf{5}$$ $$\text{Var}(Z) = (-2)^2\text{Var}(X) + 4^2\text{Var}(Y) = 4(5) + 16(3) = 20 + 48 = \mathbf{68}$$
