01 What is a Random Variable? (RV vs. Algebraic Variable)

Year Final 2022 Q2(a) · Year Final 2023 Q3(a)

Formally, a random variable $X$ is a real-valued function defined on the sample space $S$ of a random experiment: $$X : S \longrightarrow \mathbb{R}$$ It assigns a numerical value $X(\omega)$ to every elementary outcome $\omega \in S$. For example, when tossing 3 fair coins ($S = \{HHH, HHT, \dots, TTT\}$), letting $Y(\omega) = \text{number of heads}$ maps $S \to \{0, 1, 2, 3\}$.

Dimension Random Variable ($X, Y$) Algebraic Variable ($x, y$)
Mathematical Nature A function mapping sample space outcomes to real numbers ($X: S \to \mathbb{R}$). A placeholder / symbol representing a fixed unknown or varying real number.
How Values Arise Determined by the outcome of a random experiment; governed by a probability distribution. Determined deterministically by solving an equation (e.g., $2x + 3 = 7 \implies x = 2$).
Standard Notation Uppercase letters ($X, Y, Z$) denote the random variable itself. Lowercase letters ($x, y, z$) denote specific realized values (e.g., $P(X = x)$).
Discrete Random Variable

Takes on at most a finite or countably infinite set of distinct isolated values (typically counts).

Examples: Number of heads in 3 coin tosses ($0,1,2,3$), defective bulbs in a sample of 3, rolls until a 6 appears ($1,2,3,\dots$).

Continuous Random Variable

Takes on an uncountably infinite continuum of values across one or more real intervals (typically measurements).

Examples: Train waiting time $X \in [0, 4]$ minutes, lifetime of a transistor $X \ge 0$, length of a metal rod.

Discrete Case PMF: $p(x) = P(X = x)$

Probability Mass Function (PMF)

Assigns a direct probability mass to each isolated value $x$ in the discrete support $R_X$.

  1. 1. Non-negativity: $p(x) \ge 0$ for all $x$ (and $p(x) \le 1$)
  2. 2. Normalization: $\displaystyle \sum_{\text{all } x} p(x) = 1$
  3. 3. Interval Probability: $\displaystyle P(a \le X \le b) = \sum_{x=a}^{b} p(x)$
Continuous Case PDF: $f(x)$

Probability Density Function (PDF)

Describes probability per unit length; probabilities are obtained by integrating the area under the curve $f(x)$.

  1. 1. Non-negativity: $f(x) \ge 0$ for all $x \in (-\infty, \infty)$
  2. 2. Normalization: $\displaystyle \int_{-\infty}^{\infty} f(x)\,dx = 1$
  3. 3. Interval Probability: $\displaystyle P(a < X < b) = \int_{a}^{b} f(x)\,dx$
!
ISRT Exam Trap · Year Final 2023 Q1(j)

$f(x)$ is a Density (Height), NOT a Probability!

  • Can $f(x) > 1$? YES! For example, $f(x) = 2$ on $[0, 0.5]$ (and $0$ elsewhere) is a perfectly valid PDF because $f(x) \ge 0$ and $\int_0^{0.5} 2\,dx = 1$.
  • Single-Point Probability is Zero: For any continuous RV and any exact real number $c$, $P(X = c) = \int_c^c f(x)\,dx = 0$.
  • Endpoints Do Not Matter (Continuous Only): Because individual endpoints carry zero probability, $P(a < X < b) = P(a \le X < b) = P(a < X \le b) = P(a \le X \le b)$.

03 Cumulative Distribution Function (CDF): $F(x) = P(X \le x)$

1st Incourse 2020 Q6 · Year Final 2019 Q4a & 2022 Q4a

Defined uniformly for both discrete and continuous random variables, the CDF accumulates all probability mass/area up to and including $x$: $$F(x) = P(X \le x) = \begin{cases} \displaystyle \sum_{t \le x} p(t) & \text{(discrete)} \\[10pt] \displaystyle \int_{-\infty}^{x} f(t)\,dt & \text{(continuous)} \end{cases}$$

1. Boundedness
$0 \le F(x) \le 1$

Since $F(x)$ is itself a probability, it never drops below $0$ or exceeds $1$.

2. Non-Decreasing
$a < b \implies F(a) \le F(b)$

Monotone non-decreasing: the curve can stay flat or climb, never go down.

3. Limits at $\pm\infty$
$\lim_{x\to-\infty} F(x)=0,\; \lim_{x\to+\infty} F(x)=1$

Starts at $0$ on the far left and reaches $1$ on the far right.

4. Right-Continuous
$\lim_{h\to 0^+} F(x+h) = F(x)$

At any discrete jump, $F(x)$ equals the upper (closed-dot) value.

Right-Tail Rule
$P(X > a) = 1 - F(a)$
Interval Difference Rule
$P(a < X \le b) = F(b) - F(a)$
PDF from CDF (Continuous)
$f(x) = \dfrac{d}{dx}F(x)$

Let $a$ and $b$ be any two real numbers such that $a < b$. Partition the event $\{X \le b\}$ into two mutually exclusive events:

$$\{X \le b\} = \{X \le a\} \cup \{a < X \le b\}, \qquad \{X \le a\} \cap \{a < X \le b\} = \emptyset$$

Applying Axiom 3 (additivity for disjoint events):

$$P(X \le b) = P(X \le a) + P(a < X \le b) \implies F(b) = F(a) + P(a < X \le b)$$

By Axiom 1 (non-negativity of probability), $P(a < X \le b) \ge 0$. Therefore:

$$F(b) \ge F(a) \quad \text{i.e.,} \quad F(a) \le F(b) \quad \blacksquare$$

Part (a): From the disjoint decomposition $\{X \le b\} = \{X \le a\} \cup \{a < X \le b\}$ (for $a < b$), Axiom 3 gives:

$$F(b) = F(a) + P(a < X \le b) \implies P(a < X \le b) = F(b) - F(a)$$

Part (b): The events $\{X \le a\}$ and $\{X > a\}$ are complementary ($\{X > a\} = \{X \le a\}^c$). By the Complement Rule:

$$P(X > a) = 1 - P(X \le a) = 1 - F(a) \quad \blacksquare$$

Method 1 (Direct Integration): By definition of a continuous PDF $f(x)$, the probability of any interval $[a, b]$ is $\int_a^b f(x)\,dx$. Setting $a = b = c$ gives:

$$P(X = c) = P(c \le X \le c) = \int_{c}^{c} f(x)\,dx = 0$$

Method 2 (Nested Intervals & Continuity of $F$): Express $\{X = c\} = \bigcap_{n=1}^{\infty} \left\{c - \frac{1}{n} < X \le c\right\}$. By continuity of probability for decreasing nested events and the continuity of $F(x)$ for a continuous RV:

$$P(X = c) = \lim_{n \to \infty} P\!\left(c - \frac{1}{n} < X \le c\right) = \lim_{n \to \infty} \left[F(c) - F\!\left(c - \frac{1}{n}\right)\right] = F(c) - F(c) = 0 \quad \blacksquare$$

To verify that $f(x)$ is a valid probability mass function, we check the two defining conditions:

Condition 1 (Non-negativity): For every $x \in \{0,1,2,3,4\}$, $\binom{4}{x} > 0$, $(0.6)^x > 0$, and $(0.4)^{4-x} > 0$. Hence $f(x) \ge 0$ for all $x$.

Condition 2 (Normalization): Sum over the support using the Binomial Theorem $\sum_{x=0}^{n} \binom{n}{x} p^x q^{n-x} = (p + q)^n$:

$$\sum_{x=0}^{4} f(x) = \sum_{x=0}^{4} \binom{4}{x}(0.6)^x(0.4)^{4-x} = (0.6 + 0.4)^4 = 1^4 = 1 \quad \blacksquare$$

Both conditions hold, so $f(x)$ is a valid PMF (specifically $\text{Binomial}(n=4, p=0.6)$).

Year Final 2025 · Q4 Train Wait Time Piecewise CDF · ISRT, DU

The waiting time $X$ (in minutes) for a train has cumulative distribution function: $$F(x) = \begin{cases} 0, & x \le 0 \\ 0.5x, & 0 < x \le 1 \\ 0.5, & 1 < x \le 2 \\ 0.25x, & 2 < x \le 4 \\ 1, & x > 4 \end{cases}$$ Check whether $X$ is continuous, derive its PDF $f(x)$, and compute (i) $P(X > 3)$, (ii) $P(X < 3)$, (iii) $P(1 < X < 3)$, and (iv) $P(X > 3 \mid X > 1)$.

Continuity Check: Check boundary points $x = 0, 1, 2, 4$: $F(0^-)=0=F(0^+)$; $F(1^-)=0.5=F(1^+)$; $F(2^-)=0.5=0.25(2)=F(2^+)$; $F(4^-)=0.25(4)=1=F(4^+)$. Since $F(x)$ has no jumps, $X$ is a continuous random variable.

PDF Derivation ($f(x) = F'(x)$): $$f(x) = \begin{cases} 0.5, & 0 < x < 1 \\ 0, & 1 < x < 2 \\ 0.25, & 2 < x < 4 \\ 0, & \text{elsewhere} \end{cases}$$

  • (i) $P(X > 3) = 1 - F(3) = 1 - 0.25(3) = 1 - 0.75 = \mathbf{0.25}$.
  • (ii) $P(X < 3) = F(3) = \mathbf{0.75}$ (continuous RV, so $P(X=3)=0$).
  • (iii) $P(1 < X < 3) = F(3) - F(1) = 0.75 - 0.50 = \mathbf{0.25}$.
  • (iv) $P(X > 3 \mid X > 1) = \dfrac{P(X > 3 \cap X > 1)}{P(X > 1)} = \dfrac{P(X > 3)}{1 - F(1)} = \dfrac{0.25}{1 - 0.50} = \mathbf{0.50}$.
1st Incourse 2020 Q7 / 1st Incourse 2017 Q3 [3 Marks] Triangular PDF · ISRT, DU

A function $f(x)$ is defined by: $$f(x) = \begin{cases} 0, & x \le 0 \\ x, & 0 < x \le 1 \\ 2 - x, & 1 < x \le 2 \\ 0, & x > 2 \end{cases}$$ Verify whether $f(x)$ is a valid probability density function. Also find $P(0.6 < X < 1.2)$.

1. Verify PDF: Clearly $f(x) \ge 0$ for all $x \in \mathbb{R}$. Integrating over $(-\infty, \infty)$:

$$\int_0^1 x\,dx + \int_1^2 (2 - x)\,dx = \left[\frac{x^2}{2}\right]_0^1 + \left[2x - \frac{x^2}{2}\right]_1^2 = \frac{1}{2} + \left(2 - \frac{3}{2}\right) = \frac{1}{2} + \frac{1}{2} = 1 \;\checkmark$$

2. Compute $P(0.6 < X < 1.2)$: Split the integral at $x = 1$:

$$P(0.6 < X < 1.2) = \int_{0.6}^{1} x\,dx + \int_{1}^{1.2} (2 - x)\,dx = \frac{1 - 0.36}{2} + \left[\left(2.4 - 0.72\right) - 1.5\right] = 0.32 + 0.18 = \mathbf{0.50}$$
Year Final 2019 · Q4(b) Piecewise PDF → CDF · ISRT, DU

Given the function $f(x) = 2x$ for $0 \le x \le \frac{1}{2}$, $f(x) = 6 - 6x$ for $\frac{1}{2} < x \le 1$, and $0$ elsewhere: verify that $f(x)$ is a valid PDF and derive its piecewise cumulative distribution function $F(x)$.

1. Verify PDF: $f(x) \ge 0$ everywhere, and: $$\int_0^{1/2} 2x\,dx + \int_{1/2}^1 (6 - 6x)\,dx = \left[x^2\right]_0^{1/2} + \left[6x - 3x^2\right]_{1/2}^1 = 0.25 + (3 - 2.25) = 0.25 + 0.75 = 1 \;\checkmark$$

2. Derive Piecewise CDF $F(x) = \int_{-\infty}^x f(t)\,dt$:

  • For $x < 0$: $F(x) = 0$.
  • For $0 \le x \le 1/2$: $F(x) = \int_0^x 2t\,dt = x^2$.
  • For $1/2 < x \le 1$: $F(x) = F(1/2) + \int_{1/2}^x (6 - 6t)\,dt = 0.25 + (6x - 3x^2) - 2.25 = 6x - 3x^2 - 2$.
  • For $x > 1$: $F(x) = 1$.
Year Final 2023 · Q5(c) Discrete PMF & Normalizing Constant · ISRT, DU

A discrete random variable $X$ takes values $2, 4, 6, 8$ with PMF $p(x) = kx$ for $x \in \{2, 4, 6\}$ and $p(8) = k(8 - 2) = 6k$. Show that $k = \dfrac{1}{18}$ and compute $F(5)$.

1. Solve for $k$: By normalization $\sum p(x) = 1$: $$p(2) + p(4) + p(6) + p(8) = 2k + 4k + 6k + 6k = 18k = 1 \implies k = \mathbf{\frac{1}{18}}$$

2. Evaluate $F(5) = P(X \le 5)$: Although $5$ is not in the support $\{2,4,6,8\}$, $F(5)$ sums all probability masses at or below $5$: $$F(5) = P(X \le 5) = p(2) + p(4) = \frac{2}{18} + \frac{4}{18} = \frac{6}{18} = \mathbf{\frac{1}{3}}$$

1st Incourse 2025 · Q7 Two Fair Coins PMF & Step-CDF · ISRT, DU

Two fair coins are tossed simultaneously. Let $Y$ denote the number of heads obtained. Find the probability mass function $p(y)$ and the cumulative distribution function $F(y)$ of $Y$.

Sample space: $S = \{TT, TH, HT, HH\}$ (4 equally likely outcomes). Possible values of $Y$: $\{0, 1, 2\}$.

PMF: $p(0) = \frac{1}{4} = 0.25$, $p(1) = \frac{2}{4} = 0.50$, $p(2) = \frac{1}{4} = 0.25$ (and $0$ otherwise).

Step-CDF $F(y) = P(Y \le y)$: $$F(y) = \begin{cases} 0, & y < 0 \\ 0.25, & 0 \le y < 1 \\ 0.75, & 1 \le y < 2 \\ 1, & y \ge 2 \end{cases}$$
