01 Covariance & Correlation

Ross Ch. 7.4 · 2nd Incourse 2024 Q3
Covariance $\text{Cov}(X,Y)$
$$\text{Cov}(X,Y) = E\big[(X - \mu_X)(Y - \mu_Y)\big] = E[XY] - E[X]E[Y]$$

Measures the direction and scale-dependent strength of linear co-movement. Positive if large $X$ pairs with large $Y$; negative if large $X$ pairs with small $Y$.

Correlation $\rho(X,Y)$
$$\rho(X,Y) = \frac{\text{Cov}(X,Y)}{\sigma_X\,\sigma_Y}, \qquad -1 \le \rho(X,Y) \le 1$$

The dimensionless, standardized covariance. Invariant to positive linear rescaling; $|\rho| = 1$ if and only if $Y = a + bX$ almost surely ($b \neq 0$).

Symmetry
$\text{Cov}(X,Y) = \text{Cov}(Y,X)$
Self-Covariance
$\text{Cov}(X,X) = V(X) = \sigma_X^2$
Bilinearity (Origin-Free)
$\text{Cov}(aX+b,\; cY+d) = ac\,\text{Cov}(X,Y)$
!
Exam Trap Spotlight · Uncorrelated ≠ Independent

Independence $\implies \text{Cov}(X,Y) = 0$,  BUT  $\text{Cov}(X,Y) = 0 \;\not\!\!\implies$ Independence!

Covariance detects linear association only. Classic Ross Counterexample: Let $X \in \{-1, 0, 1\}$ with equal probability $\frac{1}{3}$ each, and set $Y = X^2$.

E[X] = (-1 + 0 + 1)/3 = 0  |  E[XY] = E[X³] = (-1 + 0 + 1)/3 = 0  ⇒  Cov(X,Y) = 0 − 0·(2/3) = 0

Yet $Y = X^2$ is 100% functionally dependent on $X$! For example, $P(X=0, Y=1) = 0 \neq P(X=0)P(Y=1) = \frac{1}{3}\cdot\frac{2}{3} = \frac{2}{9}$.

02 Variance of Linear Combinations & Sums

2nd Incourse 2018 Q3(b) · 2021 Q3
Bivariate Linear Combination
$$V(aX + bY + c) = a^2 V(X) + b^2 V(Y) + 2ab\,\text{Cov}(X,Y)$$

Notice the additive constant $c$ drops out completely, while $a$ and $b$ square.

General Sum of $n$ Random Variables
$$V\!\left(\sum_{i=1}^{n} X_i\right) = \sum_{i=1}^{n} V(X_i) + 2\sum_{1 \le i < j \le n} \text{Cov}(X_i, X_j)$$

If $X_1, \dots, X_n$ are pairwise uncorrelated (or independent), all cross-terms vanish.

Sign Trap When Subtracting ($b = -1$)

$V(X - Y) = V(X) + V(Y) - 2\,\text{Cov}(X,Y)$. Notice that $V(Y)$ is ALWAYS added (because $(-1)^2 = +1$)! When $X$ and $Y$ are independent, $V(X - Y) = V(X) + V(Y)$.

V(X − Y) = V(X) + V(Y) − 2Cov

03 $E[Y \mid X]$ & $V(Y \mid X)$ as Random Variables

A crucial conceptual leap in AST 102 is distinguishing between a number and a random variable:

$g(x) = E[Y \mid X = x]$  (A Fixed Number)

Once you plug in a specific observed value $x$ (like $x = 0.5$), $E[Y \mid X = 0.5] = \frac{17}{15}$ is a deterministic real number.

$E[Y \mid X] = g(X)$  (A Random Variable!)

Before $X$ is observed, $E[Y \mid X]$ is a function of the random variable $X$—so it has its own mean $E[E(Y \mid X)]$ and variance $V(E[Y \mid X])$.

Conditional Variance $V(Y \mid X)$
$$V(Y \mid X) = E\big[(Y - E[Y \mid X])^2 \mid X\big] = E[Y^2 \mid X] - \big(E[Y \mid X]\big)^2$$

04 The Two Tower Laws

2nd Inc. 2024 Q5 · 2025 Q1
Law of Iterated Expectations (Adam's Law)
$$E[Y] = E\big[E(Y \mid X)\big]$$

The overall average of $Y$ equals the probability-weighted average of the group means $E[Y \mid X = x]$.

Law of Total Variance (Eve's Law)
$$V(Y) = \underbrace{E\big[V(Y \mid X)\big]}_{\text{Expected Within-Group}} + \underbrace{V\big(E[Y \mid X]\big)}_{\text{Between-Group}}$$

ANOVA Intuition: Total variability in $Y$ decomposes cleanly into (1) the average variance within each $X$-group plus (2) the variance of the group means between groups.

Section 03 • Mathematical Rigor

Proofs & Derivations Drawer

5 core AST 102 proofs — click any card to expand

Let $\mu_X = E[X]$ and $\mu_Y = E[Y]$. Expanding the product inside expectation and using linearity:

$$\text{Cov}(X,Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY - \mu_Y X - \mu_X Y + \mu_X \mu_Y]$$ $$= E[XY] - \mu_Y E[X] - \mu_X E[Y] + \mu_X \mu_Y = E[XY] - \mu_X \mu_Y = E[XY] - E[X]E[Y]$$

If $X$ and $Y$ are independent: $f(x,y) = f_X(x)f_Y(y)$, so the double integral (or double sum) factors cleanly:

$$E[XY] = \iint xy\,f_X(x)f_Y(y)\,dx\,dy = \left(\int x f_X(x)\,dx\right)\left(\int y f_Y(y)\,dy\right) = E[X]E[Y]$$ $$\implies \text{Cov}(X,Y) = E[X]E[Y] - E[X]E[Y] = 0 \quad \blacksquare$$

Let $Z = aX + bY + c$. By linearity of expectation, $\mu_Z = a\mu_X + b\mu_Y + c$. Subtracting $\mu_Z$ cancels $c$:

$$Z - \mu_Z = a(X - \mu_X) + b(Y - \mu_Y)$$

Squaring and taking expectations:

$$V(Z) = E[(Z - \mu_Z)^2] = a^2 E[(X-\mu_X)^2] + b^2 E[(Y-\mu_Y)^2] + 2ab\,E[(X-\mu_X)(Y-\mu_Y)]$$ $$= a^2 V(X) + b^2 V(Y) + 2ab\,\text{Cov}(X,Y) \quad \blacksquare$$

Discrete Proof: Since $E[Y \mid X = x] = \sum_y y\,p_{Y|X}(y \mid x)$ and $p_{Y|X}(y \mid x)p_X(x) = p(x,y)$:

$$E[E(Y \mid X)] = \sum_x E[Y \mid X=x]\,p_X(x) = \sum_x \sum_y y\,p_{Y|X}(y \mid x)p_X(x) = \sum_y y \sum_x p(x,y) = \sum_y y\,p_Y(y) = E[Y]$$

Continuous Proof: Replacing sums with integrals and using $f_{Y|X}(y \mid x)f_X(x) = f(x,y)$:

$$E[E(Y \mid X)] = \int_{-\infty}^{\infty}\!\left(\int_{-\infty}^{\infty} y\,f_{Y|X}(y \mid x)\,dy\right)f_X(x)\,dx = \int_{-\infty}^{\infty} y \left(\int_{-\infty}^{\infty} f(x,y)\,dx\right)dy = \int_{-\infty}^{\infty} y\,f_Y(y)\,dy = E[Y] \quad \blacksquare$$

Start with the definition of conditional variance: $V(Y \mid X) = E[Y^2 \mid X] - (E[Y \mid X])^2$. Take the expectation of both sides and apply Adam's Law ($E[E(Y^2 \mid X)] = E[Y^2]$):

$$E[V(Y \mid X)] = E\big[E(Y^2 \mid X)\big] - E\big[(E[Y \mid X])^2\big] = E[Y^2] - E\big[(E[Y \mid X])^2\big]$$

Next, expand the variance of the random variable $E[Y \mid X]$ and apply Adam's Law ($E[E(Y \mid X)] = E[Y]$):

$$V\big(E[Y \mid X]\big) = E\big[(E[Y \mid X])^2\big] - \big(E[E(Y \mid X)]\big)^2 = E\big[(E[Y \mid X])^2\big] - (E[Y])^2$$

Add the two equations together—the middle term $E[(E[Y \mid X])^2]$ cancels cleanly:

$$E[V(Y \mid X)] + V\big(E[Y \mid X]\big) = E[Y^2] - (E[Y])^2 = V(Y) \quad \blacksquare$$

Assume $\sigma_X > 0$ and $\sigma_Y > 0$. Define the standardized variables $U = \frac{X}{\sigma_X}$ and $W = \frac{Y}{\sigma_Y}$, so $V(U) = 1$, $V(W) = 1$, and $\text{Cov}(U,W) = \frac{\text{Cov}(X,Y)}{\sigma_X\sigma_Y} = \rho(X,Y)$.

Since variance is always non-negative:

$$0 \le V(W + U) = V(W) + V(U) + 2\,\text{Cov}(W,U) = 1 + 1 + 2\rho = 2(1 + \rho) \implies \rho \ge -1$$ $$0 \le V(W - U) = V(W) + V(U) - 2\,\text{Cov}(W,U) = 1 + 1 - 2\rho = 2(1 - \rho) \implies \rho \le +1$$
$$\therefore \quad -1 \le \rho(X,Y) \le 1 \quad \text{i.e.,} \quad |\rho(X,Y)| \le 1 \quad \blacksquare$$

ISRT 2nd Incourse 2025 · Q1 [6 Marks] Adam's Law & Conditional Variance · AST 102

Given the joint PMF of discrete random variables $X \in \{0, 1\}$ and $Y \in \{0, 1, 2\}$: $p(0,0)=0.1$, $p(1,0)=0.2$, $p(0,1)=0.4$, $p(1,1)=0.1$, $p(0,2)=0.0$, $p(1,2)=0.2$. (i) Calculate the conditional expectation function $E(Y \mid X)$. (ii) Demonstrate the law of iterated expectations $E[E(Y \mid X)] = E(Y)$. (iii) Calculate the conditional variances $V(Y \mid X)$.

Marginals: $p_X(0) = 0.1 + 0.4 + 0.0 = 0.5$, $p_X(1) = 0.2 + 0.1 + 0.2 = 0.5$. For $Y$: $p_Y(0) = 0.3$, $p_Y(1) = 0.5$, $p_Y(2) = 0.2$.

(i) Conditional Expectation $E(Y \mid X)$:

  • For $X = 0$: $p(y \mid 0) = \{0.2, 0.8, 0.0\} \implies E(Y \mid X=0) = 0(0.2) + 1(0.8) + 2(0) = \mathbf{0.8}$.
  • For $X = 1$: $p(y \mid 1) = \{0.4, 0.2, 0.4\} \implies E(Y \mid X=1) = 0(0.4) + 1(0.2) + 2(0.4) = \mathbf{1.0}$.

(ii) Law of Iterated Expectations: $E[E(Y \mid X)] = (0.8)(0.5) + (1.0)(0.5) = 0.4 + 0.5 = \mathbf{0.9}$. Directly: $E(Y) = 0(0.3) + 1(0.5) + 2(0.2) = \mathbf{0.9}$. Hence $E[E(Y \mid X)] = E(Y) = 0.9$ verified!

(iii) Conditional Variance $V(Y \mid X)$:

  • $E(Y^2 \mid X=0) = 0(0.2) + 1(0.8) + 4(0) = 0.8 \implies V(Y \mid X=0) = 0.8 - (0.8)^2 = \mathbf{0.16}$.
  • $E(Y^2 \mid X=1) = 0(0.4) + 1(0.2) + 4(0.4) = 1.8 \implies V(Y \mid X=1) = 1.8 - (1.0)^2 = \mathbf{0.80}$.
ISRT 2nd Incourse 2024 · Q3 Continuous Covariance & Marginals · AST 102

The joint density function of $X$ and $Y$ is $f(x,y) = x + y$ for $0 < x < 1, 0 < y < 1$ ($0$ otherwise). Find $V(X)$, $V(Y)$, and $\text{Cov}(X,Y)$.

Marginals: $f_X(x) = \int_0^1 (x+y)\,dy = x + \frac{1}{2}$ ($0 < x < 1$); by symmetry $f_Y(y) = y + \frac{1}{2}$.

Moments of $X$ (and $Y$): $$E[X] = \int_0^1 \left(x^2 + \frac{x}{2}\right)dx = \frac{1}{3} + \frac{1}{4} = \frac{7}{12}, \qquad E[X^2] = \int_0^1 \left(x^3 + \frac{x^2}{2}\right)dx = \frac{1}{4} + \frac{1}{6} = \frac{5}{12}$$ $$V(X) = V(Y) = \frac{5}{12} - \left(\frac{7}{12}\right)^2 = \frac{60 - 49}{144} = \mathbf{\frac{11}{144}}$$

Cross-Moment & Covariance: $$E[XY] = \int_0^1\!\!\int_0^1 (x^2 y + x y^2)\,dy\,dx = \int_0^1 \left(\frac{x^2}{2} + \frac{x}{3}\right)dx = \frac{1}{6} + \frac{1}{6} = \frac{1}{3} = \frac{48}{144}$$ $$\text{Cov}(X,Y) = E[XY] - E[X]E[Y] = \frac{48}{144} - \frac{49}{144} = \mathbf{-\frac{1}{144}}$$

ISRT 2nd Incourse 2024 · Q4 & Q5 Conditional Mean + Eve's Law Proof · AST 102

Q4: Given $f(x,y) = \dfrac{1}{4}(2x + y)$ for $0 < x < 1, 0 < y < 2$ ($0$ otherwise), find the conditional expectation $E(X \mid Y = y)$.

Q5: Prove the Law of Total Variance: $V(Y) = E[V(Y \mid X)] + V(E[Y \mid X])$.

Solution to Q4:

Marginal of $Y$: $f_Y(y) = \int_0^1 \frac{1}{4}(2x + y)\,dx = \frac{1}{4}\left[x^2 + xy\right]_0^1 = \frac{1 + y}{4}$ for $0 < y < 2$.

Conditional PDF: $f_{X|Y}(x \mid y) = \dfrac{(2x+y)/4}{(1+y)/4} = \dfrac{2x + y}{1 + y}$ for $0 < x < 1$.

$$E(X \mid Y = y) = \int_0^1 x\cdot\frac{2x + y}{1 + y}\,dx = \frac{1}{1+y}\left[\frac{2x^3}{3} + \frac{x^2 y}{2}\right]_0^1 = \frac{\frac{2}{3} + \frac{y}{2}}{1 + y} = \mathbf{\frac{4 + 3y}{6(1 + y)}}$$

Solution to Q5:

$E[V(Y \mid X)] + V(E[Y \mid X]) = \big(E[Y^2] - E[(E[Y \mid X])^2]\big) + \big(E[(E[Y \mid X])^2] - (E[Y])^2\big) = E[Y^2] - (E[Y])^2 = V(Y)$. (See Proof 4 above for full line-by-line justification.)

ISRT 2nd Incourse 2018 · Q2(a) [4] & Q3(b) [3] Conditional Mean & Variance · AST 102

Q2(a): Given $f(x,y) = x^2 + \dfrac{xy}{3}$ ($0 < x < 1, 0 < y < 2$), find the conditional densities of $X$ and $Y$, and then find $E\left(Y \mid X = \dfrac{1}{2}\right)$.

Q3(b): If $X$ and $Y$ are independent with $V(X) = 2$ and $V(Y) = 3$, find the variance of $Z = 5X - 3Y + 7$.

Q2(a): $f_X(x) = \frac{2x(3x+1)}{3}$ and $f_Y(y) = \frac{2+y}{6}$. Thus $f_{Y|X}(y \mid x) = \frac{3x+y}{2(3x+1)}$ ($0<y<2$) and $f_{X|Y}(x \mid y) = \frac{6x^2+2xy}{2+y}$ ($0<x<1$). Integrating $y\,f_{Y|X}(y \mid x)$ over $(0,2)$ gives $E(Y \mid X=x) = \dfrac{9x+4}{9x+3}$. At $x = \frac{1}{2}$: $$E\!\left(Y \mid X = \frac{1}{2}\right) = \frac{4.5 + 4}{4.5 + 3} = \mathbf{\frac{17}{15} \approx 1.1333}$$

Q3(b): Since $X, Y$ are independent ($\text{Cov}(X,Y) = 0$) and $+7$ vanishes: $$V(5X - 3Y + 7) = 5^2 V(X) + (-3)^2 V(Y) = 25(2) + 9(3) = 50 + 27 = \mathbf{77}$$

ISRT 2nd Incourse 2021 · Q3 [2 Marks] Linear Combination Moments · AST 102

Let $X$ and $Y$ be independent random variables with means $\mu_X = 10$ and $\mu_Y = 7$, and variances $\sigma_X^2 = 5$ and $\sigma_Y^2 = 3$. Find the mean and variance of $Z = -2X + 4Y - 3$.

Mean: $E[Z] = -2E[X] + 4E[Y] - 3 = -2(10) + 4(7) - 3 = -20 + 28 - 3 = \mathbf{5}$.

Variance (Independent $\implies \text{Cov}(X,Y) = 0$): $$V(Z) = (-2)^2 V(X) + 4^2 V(Y) = 4(5) + 16(3) = 20 + 48 = \mathbf{68}$$
